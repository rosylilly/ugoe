# タスクを完了させる

手順の正は `docs/workflow/multi-agent.md`。

1. 未コミットの変更をコミットする。コミットメッセージは **英語** の Conventional Commits 形式で、件名の末尾にタスク ID を付ける (`AGENTS.md#コミット`)。フックが失敗したら原因を直す。`--no-verify` は使わない。
2. `git rebase main` で main に追従する。衝突したら、`docs/workflow/multi-agent.md#衝突を避けるための規約` に従って解決する。
3. `just ci` を実行する。失敗したら直す。直せない失敗があれば、その出力をそのまま報告に含める。
4. ランタイム層 (`ugoe-core` から `ugoe-wasm` まで) を触った場合は、`just wasm-check` も実行する。
5. タスクファイルを更新する。
   - `status: review`
   - 受け入れ条件のチェックボックスを、実際に満たしたものだけ埋める
   - 「メモ」に、やったこと・やらなかったこと・後続タスクの候補を書く
   - このファイルの更新もコミットする
6. 報告する: ブランチ名、変更の要約、満たしていない受け入れ条件 (あれば)、仕様書で更新した箇所。リモートがあり、ユーザーが望む場合は PR を作る。
