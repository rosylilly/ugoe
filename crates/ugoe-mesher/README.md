# ugoe-mesher

**層:** T1 素材処理 (依存してよいクレートは `scripts/check-layers.mjs` を参照)

アルファ付き画像から三角形メッシュを自動生成する。

```rust
let mesh = ugoe_mesher::generate(&rgba, width, height, &MeshOptions::default())?;
```

エディタでメッシュを作り直すときは、与えた点群をそのまま三角形分割する
`triangulate_points(&points, &constraints)` を使う (`ugoe-editor-core` の頂点の追加・削除と
三角形の作り直し)。制約辺が空なら凸包全体のドロネー三角形分割、空でなければ制約付きドロネー
三角形分割で、重心が制約辺の内側 (偶奇規則) にある三角形だけを残す。インデックスは入力の添字の
ままで、三角形は画面 (Y 下向き) 上で反時計回り。同じ位置の点があれば `TriangulateError::Duplicate`。

## 守ること

- 決定的であること (同じ画像とオプションからは同じメッシュ。乱数・ハッシュ順・並列処理を使わない)
- 頂点数を u16 の範囲に収める (`MAX_VERTICES` = 65535。インデックス `0xFFFF` は使わない)

## アルゴリズム

1. **二値化:** アルファが `alpha_threshold` 以上の画素を中身とする。`min_island_area` 未満の島
   (8 近傍連結) を捨てる。
2. **膨張:** 中身の画素の中心から `margin` 以内に中心がある画素を「領域」とする (厳密な
   ユークリッド距離変換、Felzenszwalb & Huttenlocher)。輪郭が外に広がり、穴は縮み、
   近い島どうしはつながる。
3. **輪郭抽出:** 領域を marching squares でなぞり、外周と穴の閉じた輪郭をすべて取り出す。
   対角にだけ接する画素 (鞍点) はつなぐ。
4. **簡略化と再サンプリング:** Douglas–Peucker で簡略化し、`edge_spacing` より長い辺を等分する
   (角の点は動かさない)。許容誤差は `min(edge_spacing / 4, 0.45 * clearance)` で、`clearance` は
   中身の画素の中心から膨張後の輪郭までの距離の下限 (`margin` から求める)。このため簡略化しても
   不透明な画素の中心は輪郭の内側に残る。輪郭は `margin` の半分程度まで内側に戻ることがある。
5. **内部点:** 領域の外接矩形の中心に合わせた六角格子 (間隔 `interior_spacing`) の点のうち、
   領域の縁から `edge_spacing / 2` 程度以上離れたものを置く (距離変換で判定)。
6. **三角形分割:** 輪郭の辺を制約辺とした制約付きドロネー三角形分割 (`spade`)。
   外接矩形の外に 4 点の番兵を置いて凸包を広げる。重心が輪郭の内側 (偶奇規則。穴は外) にある
   三角形だけを残す。
7. **安全策:** 中身のすべての画素の中心について、それを含む三角形が残っていなければ残す
   (制約辺どうしが交わって張れなかった場合など。通常の入力では何も足さない)。
8. **出力:** 使われた頂点だけを最初に使われた順に並べる。三角形は画面 (Y 下向き) 上で反時計回り
   (`docs/spec/rendering.md#裏面カリング` の表)。
9. **頂点数の調整:** 頂点数 (番兵を含む) が `MAX_VERTICES` を超えるなら、間隔と許容誤差を 1.5 倍
   にして 4〜7 をやり直す (最大 24 回。それでも収まらなければ `MeshError::TooComplex`)。

## オプション (`MeshOptions`)

| フィールド | 既定値 | 意味 |
| --- | --- | --- |
| `alpha_threshold` | 8 | この値以上のアルファを中身とする |
| `margin` | 4.0 | 輪郭を外に広げる距離 (px)。作業用の格子がこの分だけ大きくなる |
| `edge_spacing` | 24.0 | 輪郭上の頂点間隔の上限の目安 (px)。曲がった箇所ではこれより密になる |
| `interior_spacing` | 48.0 | 内部点の間隔 (px)。0 なら内部点を置かない |
| `min_island_area` | 0 | 画素数がこれ未満の島を捨てる (0 と 1 は捨てない) |

`margin` と `interior_spacing` は 0 以上、`edge_spacing` は 0 より大きい有限の値でなければ
`MeshError::InvalidOptions` になる。

## 保証

- `min_island_area` で捨てた島を除き、アルファが `alpha_threshold` 以上のすべての画素の中心は
  いずれかの三角形に含まれる (境界上を含む)。
- 退化した (面積 0 の) 三角形はない。頂点座標は f32 で表せる値に丸めてから三角形分割するので、
  出力の f32 座標でも向きは変わらない。
- 参照されない頂点はない。インデックスはすべて頂点数未満。
- 中身が 1 画素もなければ `MeshError::Empty`。

## 性能の目安

1024x1024 のレイヤー (半径 420px 前後の波打つ円に穴と小島、既定のオプション) で、
リリースビルドで約 70ms (453 頂点)。
`cargo test -p ugoe-mesher --release -- --ignored --nocapture` で測れる。
