# ugoe-fs

**層:** ツール層 (内部のクレートに依存しない葉。依存してよいクレートは `scripts/check-layers.mjs` を参照)

ファイルの読み書きの補助と、アプリが webview に読み書きを許したパス。エディタ・ビューア・スタジオ (`apps/*/src-tauri`)・MCP サーバ (`ugoe-mcp`)・
エディタの中核 (`ugoe-editor-core`)・ヘッドレス描画 (`ugoe-headless`。外から渡されたテクスチャ・JSON の読み込み。T0035) が同じ実装を使う。公開はしない (`publish = false`)。依存は std だけ。

| 項目 | 内容 |
| --- | --- |
| `write_atomic(path, bytes)` | 同じディレクトリの一時ファイル `.<名前>.<プロセス ID>.<連番>.tmp` に書いて `sync_all` し、閉じてから名前を変えて置き換える。どこで失敗しても一時ファイルを消し、前のファイルは残る |
| `write_atomic_private(path, bytes)` | 同じだが、一時ファイルを作るときから利用者だけが読める権限 (Unix の `0o600`) にする (トークン・鍵を含むファイル) |
| `StagedFile` | 一時ファイルに書くところまでを先に済ませ、`commit` で置き換える。捨てれば一時ファイルを消す (ほかの保存と組にして、両方が書けてから置き換えるとき。MCP の `save` の `bundle`) |
| `read_regular_file(path, max)` | 通常のファイル (リンクは辿る) だけを `max` バイトまで読む。装置・FIFO・ディレクトリは開かずに `ReadError::NotRegularFile`、大きければ `ReadError::TooLarge` (`std::io::Error` へも変えられる) |
| `FileAccess` | アプリ (エディタ・スタジオ) が webview に読み書きを許したパス。開くダイアログで選んだ・ドロップしたパスは読める (`grant_readable`・`is_chosen`。このセッションの間)、保存のダイアログで選んだパスは 1 回だけ書ける (`grant_writable`・`take_writable`)。書けるパスは読めるパスにならない (T0037) |
| `WritablePaths` | 1 回だけ書けるパスだけ (`grant`・`take`)。読めるパスを覚えておくビューアが使う |
| `with_extension(path, extension)` | `.<拡張子>` (ASCII の大文字小文字は区別しない) で終わっていなければ付け足す (保存のダイアログが拡張子を付けずに返したとき)。エディタの画面の `withExtension` と同じくパスの末尾の文字列で見るので、名前が `.json` だけでも付けない |

- 行き先のディレクトリは作らない。呼ぶ側が作る (権限などの作り方が呼ぶ側ごとに違うため)。
- `FileAccess` が持つのは 3 つのアプリに共通の部分だけ。アプリごとの規則 (開いているプロジェクト・プロファイルにあるパスも読める、
  読めるパスをファイルに覚えておく、断るときのエラーのコード) と、Tauri に依存するダイアログの組み立ては各アプリに置く
  (T0037。MIT のこのクレートは Tauri に依存しない)。
- 細かな約束 (Windows の置き換え・権限の引き継ぎ・大きさを見てから読むまでの競合) は各モジュールの説明に書いた。

## 置き場所を決めた理由 (T0025)

一時ファイルを経た置き換えは、エディタ・ビューア・スタジオ・`ugoe-mcp`・`ugoe-editor-core` に別々の写しがあり、
通常のファイルだけを読む処理も 3 つのアプリに写しがあった。1 か所にまとめる場所として、次の 3 つを比べた
(利用者の判断で (b) に決めた。2026-10-05)。

- **(b) 採用: ツール層の小さな葉のクレート (このクレート)。** MIT なので、MIT の `ugoe-mcp`・`ugoe-editor-core` からも
  GPL のアプリからも使える。内部のクレートに依存しないので、ビューア (ランタイム層だけに依存する) やスタジオ
  (エディタの中核に依存しない。ADR 0028 の 1.) に許しても、ツール層の重いクレートを引き込まない。
- (a) `ugoe-editor-core` に置く: ビューアとスタジオが PSD・メッシャ・リギングまで引き込み、上の決めを覆す。
- (c) GPL のアプリだけで共有する場所: MIT の `ugoe-mcp`・`ugoe-editor-core` から使えず、写しが残る。
