# 用語集

コード・文書・コミットではこの表の **ugoe 用語** を使います。Live2D の用語は、対応関係を説明するときにだけ使います。

| ugoe 用語 | コード上の型 | Live2D での近い概念 | 説明 |
| --- | --- | --- | --- |
| モデル | `ugoe_model::Model` | モデル (moc3) | リグ付きキャラクター 1 体分のデータ |
| パラメータ | `Parameter` | パラメータ | モデルを動かす入力となるスカラー値 |
| 標準パラメータ | `ugoe_model::standard` | 標準パラメータ | 意味が決まっている共通のパラメータ ID |
| パーツ | `Part` | パーツ | メッシュやデフォーマをまとめる論理グループ。不透明度を持つ |
| メッシュ | `Mesh` | アートメッシュ | テクスチャ付きの三角形メッシュ。描画の単位 |
| 描画可能要素 | `DrawableState` | Drawable | ランタイムが評価したメッシュの状態 |
| デフォーマ | `Deformer` | デフォーマ | 子の頂点を変形するもの |
| ワープデフォーマ | `WarpDeformer` | ワープデフォーマ | 格子状の制御点による自由変形 |
| 回転デフォーマ | `RotationDeformer` | 回転デフォーマ | 原点を中心とした回転・拡縮 |
| キーフォーム | `KeyformGrid<T>` | キーフォーム | パラメータ空間の格子点ごとに持つ形状などの値 |
| キーフォーム軸 | `KeyformBinding` | パラメータへのキー設定 | 1 つのパラメータと、その上のキーの位置 |
| グルー | `Glue` | グルー | 2 つのメッシュの頂点を引き寄せて継ぎ目を防ぐ |
| マスク | `Mesh::masks` (`MaskRef`) | クリッピング | 他のメッシュの形で描画範囲を制限する。通常マスクと反転マスクがある |
| マスク専用メッシュ | `Mesh::mask_only` | (不透明度 0% のマスク用アートメッシュ) | 色としては描画せず、マスクとしてだけ働くメッシュ |
| 合成モード | `BlendMode` | 合成モード | 通常・加算・乗算 |
| 物理リグ | `PhysicsRig` | 物理演算設定 (グループ) | 入力パラメータ → 振り子 → 出力パラメータ |
| モーション | `Motion` | モーション | パラメータなどの時間変化を表すカーブの集まり |
| 表情 | `Expression` | 表情 (exp3) | パラメータに加算・乗算・上書きする差分 |
| エフェクト | (予定) | 目パチ・呼吸・リップシンク | 常に動く自動アニメーション |
| ポーズ | (予定) | ポーズ (pose3) | 排他的なパーツ切り替え (腕の差分など) |
| 当たり判定 | `HitArea` | 当たり判定 | タップなどの判定に使うメッシュ |
| パペット | `ugoe::Puppet` | CubismUserModel | ランタイム SDK での 1 体分の動作単位 |
| コンパイル済みモデル | `CompiledModel` | CubismMoc | ID を解決し評価用に前処理した、共有可能なモデル |
| モデルインスタンス | `ModelInstance` | CubismModel | パラメータ値と評価結果を持つ実行時状態 |
| ドキュメント | `ugoe_editor_core::Document` | (エディタのモデルファイル) | エディタで編集中のモデルと Undo 履歴 |
| コマンド | `ugoe_editor_core::Command` | — | シリアライズ可能な編集操作。Undo の単位 |
| 提案 | `ugoe_ai::Proposal` | — | AI が出す、まだ適用していない Command 列 |
| バンドル | `.ugoe` | moc3 + model3.json + テクスチャ | ランタイムで配布する単一ファイル |
