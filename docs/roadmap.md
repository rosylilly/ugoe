## M11 移植性 (std の無い環境とホストに依存しない C ABI)

方針は [ADR 0031](adr/0031-no-std-runtime-and-host-neutral-c-abi.md)。特定の言語やエンジンのためではなく、
ゲーム機・組み込み機器 (Rust の `std` が無い環境) と、呼び出しの間で OS のスレッドが変わるホスト (Go・C# の async など) に
同じランタイムを持ち込めるようにする。

**完了の条件:** ランタイム層 (`ugoe-core`〜`ugoe`・`ugoe-ffi`) が `aarch64-unknown-none` で `std` 無しにビルドでき (`just nostd-check`)、
`ugoe-ffi` の静的ライブラリがホストの C ライブラリだけでリンクできる。C ABI のエラーをスレッドに依存せずに読める。

- no_std: 土台と検査 (T0179)、数学関数を libm に (T0180)、評価・物理・モーション (T0181)、形式 (T0182)、SDK (T0183)
- パニックを起こさない (T0184)
- C ABI: 呼び出し側のエラーのオブジェクト (T0489)、毎フレームの描画の状態をまとめて受け取る形に置き換える (T0490)、std の無い静的ライブラリ (T0491)
