# ロードマップ

各マイルストーンのタスクは [tasks/](tasks/README.md) にあります。`just tasks` で状態の一覧を表示できます。

## M0 基盤 ✅

リポジトリの構成、クレートの骨格、規約、CI、仕様書の初版。

## M1 ランタイム MVP ✅

**完了の条件:** コードで組み立てたモデル (デフォーマ・マスク・合成モードを含む) が、仕様どおりに変形・描画され、`ugoe render` で PNG として出力できる。

- モデルの検証の完成 (T0102)
- デフォーマ・パーツ階層・グルーの評価 (T0104)
- `.ugoe` バンドル (T0105)
- 参照レンダラ: パイプラインと描画 (T0201)、マスク (T0202)、GPU テストの CI (T0203)
- CLI でのスナップショット描画 (T0204)
- 評価結果の変更フラグ (T0106)、ポーズとエフェクトのデータ (T0103)
- マスクの意味論 (ADR 0009): データとランタイム (T0107)、参照レンダラ (T0205)
- 後続 (M2 に回したもの): マスクアトラスの縮小 (T0206)、変更フラグによる転送の省略 (T0207)

## 優先度の考え方

- ★ は [vision.md](vision.md#乗り換えの理由になる差別化) の「最優先」の差別化 (キーフォームの推定・動的物理・アバタープロファイル) に関わるタスク。
- ◆ は前方互換 (ADR 0013) の仕組み。以降のすべての機能追加が乗るので、M2 の早い段階で入れる。

## M2 エディタ MVP

**完了の条件:** PSD を読み込み、自動メッシュを作り、デフォーマとパラメータを手で設定して、`.ugoeproj` に保存し、`.ugoe` として書き出せる。**端の形だけを作れば、中間・斜め・左右反転のキーフォームが推定される。**

- ◆ 前方互換: 機能の宣言と未知の値の読み込み (T0109)
- PSD の取り込み (T0501)、自動メッシュ (T0502)
- エディタのコマンド群 (T0601)、ツリー UI (T0602)、型の自動生成 (T0603)
- ビューポート (T0402)
- プロジェクトの保存と読み込み (T0604)
- ★ キーフォームの推定: データ (T0108)、`ugoe-rigging` と加算合成 (T0610)、ミラーと深度からの回転 (T0612)、エディタのコマンド (T0611) と UI (T0613)
- レンダラの後続: マスクアトラスの縮小 (T0206)、変更フラグによる転送の省略 (T0207)
- メッシュの編集、デフォーマのギズモ、キーフォームの編集 (M2 の後半で起票する)

## M3 アニメーションとアバター

**完了の条件:** 物理・モーション・表情・目パチ・呼吸・リップシンク・ポーズが動き、エディタで物理の設定とモーションの編集ができる。**揺れ用パラメータなしで髪が揺れ、体とぶつかる。アバタープロファイルに準拠したモデルを、ARKit のトラッキングで動かせる。**

- 物理 (T0301)、カーブとモーション再生 (T0302)、モーションマネージャとエフェクト (T0303)
- ★ 動的物理: データ (T0304)、2 段階の評価と実装 (T0305)
- ★ アバタープロファイル: データと検証 (T0110)、トラッキングの対応付け (T0306)
- ブレンドシェイプ、当たり判定
- エディタ: タイムライン、物理の設定画面 (衝突体・出力先の編集を含む)

## M4 配布と統合

**完了の条件:** Unity と Web で、同じ `.ugoe` を表示して動かせる。古いランタイムで新しいファイルを読める。

- 単一ランタイム: C ABI (T0401)、crates.io (T0403)、npm と Web Components (T0404)、Unity (T0405)、Godot (T0406)、Unreal (T0407)、適合テスト (T0408)
- 互換性テストの資料と CI (T0115)
- 描画コストの自動最適化: 描画の統合 (T0208)、テクスチャのアトラス化 (T0114)
- 着せ替え: スロットと合成 (T0111)、モジュールのファイル形式 (T0113)
- ライティング: データ (T0112)、参照レンダラ (T0209)、法線マップの生成 (T0506)
- 性能: 1 体を 1ms 以内 (中程度の PC、数千頂点) で評価する

## M5 AI 連携

**完了の条件:** PSD から、顔の角度・目・口・呼吸・髪揺れが動くモデルを、提案を採用するだけで作れる。

- レイヤーの意味分類 (T0503)、自動リギング (T0504)
- ★ 深度推定による振り向きリグ (T0505)
- 提案のプレビュー UI
- MCP サーバ (`ugoe-mcp`)
