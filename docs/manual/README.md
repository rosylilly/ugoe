# ugoe エディタ 操作マニュアル

ugoe エディタでモデルを作る人 (リガー) 向けの、画面の操作の手順書です。
エディタの設計や内部の仕組みは [docs/editor.md](../editor.md) (開発者向け) にあります。

1. [チュートリアル: PSD から動くモデルを作る](tutorial.md) — `character.psd` を使って、取り込みから書き出しまでを順に通します。初めての人はここから読んでください。
2. リファレンス
   - [画面とパネル](screen.md) — ヘッダー・ツリー・ビューポート・インスペクタ・パラメータ

   - [よくある警告とエラー](warnings.md) — 出たメッセージの意味と対処

## エディタの起動

リポジトリの準備 (ルートの [README](../../README.md) の「始め方」) が済んでいれば、次のコマンドで起動します。

```sh
just wasm     # ビューポートの描画に使う wasm を作る (初回と、Rust のコードが変わったとき)
just editor   # エディタを開発モードで起動する
```

インストーラの作り方は [apps/editor/README.md](../../apps/editor/README.md) にあります。

## このマニュアルの表記

- 画面のボタンや欄の名前は、画面に出ている英語のまま「」で書きます (例: 「Import PSD…」)。
- 「ツリーの **顔** を押す」のように、太字はツリーの行やパーツの名前です。
- 「押す」はマウスの左ボタンでのクリックです。Mac では Ctrl を Cmd と読み替えてください。
- 手順は 1 行に 1 つの操作です。番号の順に行ってください。

## 今のエディタの制限 (まとめ)

マニュアルを読む前に知っておくとよいことです。詳しくは各章に書いています。

- **パラメータの左右の対 (`EyeLOpen` と `EyeROpen` など) を画面で設定できません。** ミラーに必要なので、チュートリアルではモデルのファイルを直接書き換えて設定します ([チュートリアルの 9 章](tutorial.md#9-左右のミラー))。
- 要素の ID は自動で決まり、画面では変えられません。日本語の名前のレイヤーは `Layer8` のような ID になります。ID はインスペクタの先頭 (例: `mesh: Layer8`) で確かめられます。
