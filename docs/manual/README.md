# ugoe エディタ 操作マニュアル

エディタの設計や内部の仕組みは [docs/editor.md](../editor.md) (開発者向け) にあります。

## エディタの起動

リポジトリの準備 (ルートの [README](../../README.md) の「始め方」) が済んでいれば、次のコマンドで起動します。

```sh
just wasm     # ビューポートの描画に使う wasm を作る (初回と、Rust のコードが変わったとき)
just editor   # エディタを開発モードで起動する
```

インストーラの作り方は [apps/editor/README.md](../../apps/editor/README.md) にあります。

## このマニュアルの表記

- 画面のボタンや欄の名前は、画面に出ている英語のまま「」で書きます (例: 「Import PSD…」)。
- 「ツリーの **顔** を押す」のように、太字はツリーの行やパーツの名前です。
- 「押す」はマウスの左ボタンでのクリックです。Mac では Ctrl を Cmd と読み替えてください。
- 手順は 1 行に 1 つの操作です。番号の順に行ってください。

## 今のエディタの制限 (まとめ)

マニュアルを読む前に知っておくとよいことです。詳しくは各章に書いています。

- 要素の ID は自動で決まり、画面では変えられません。日本語の名前のレイヤーは `Layer8` のような ID になります。選択欄とインスペクタの先頭には名前と ID が並んで出ます (例: `mesh: 顔 (Layer8)`)。
- タイムラインのプレビュー (再生・シーク) はカーブの値だけで、フェード・目パチ・呼吸・物理は掛かりません ([モーションと表情](motions.md#制限))。それらを掛けて見るには [プレビュー](preview.md) を使います。
