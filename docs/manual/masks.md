# マスク

マスクは、あるメッシュを **別のメッシュの形の中だけ** に描く (クリッピング)、または **形の外だけ** に描く (反転) 仕組みです。
影やハイライトを肌からはみ出させない、瞳を白目の中に収める、といった用途に使います。

- マスクは、メッシュごとに「どのメッシュをマスクにするか」を並べて設定します。
- マスクにするメッシュの不透明度・非表示・合成モードは、マスクの効き方に影響しません。不透明度 0 のメッシュも、形どおりにマスクとして効きます。
- マスクは入れ子になります。たとえば瞳を黒目でクリップし、黒目を白目でクリップすると、瞳も白目からはみ出しません。

## PSD のクリッピング

PSD でクリッピングしたレイヤーは、取り込むと、下のレイヤー (土台) をマスクにしたメッシュになります。

- `character.psd` では、**顔の影** が **顔** をマスクにしています。ツリーで **顔の影** を選ぶと、インスペクタの「Masks」に **顔** が出ます。
- 土台がグループなら、グループの中のすべてのメッシュがマスクになります。
- 土台のレイヤーの不透明度は、クリッピングされた側の不透明度に掛けられます (Photoshop と同じ見た目にするため)。
- 土台が取り込めなかった (空のレイヤーなど) ときや、グループをクリッピングしていたときは、マスクなしで取り込み、警告が出ます ([よくある警告](warnings.md#psd-の取り込みの警告))。

## マスクを設定する

1. ツリーかビューポートで、マスクを掛けたいメッシュを選ぶ。
2. インスペクタの「Mesh」の「Masks」の右の「Add」を押す。マスクの行が 1 つ増えます (まだ使っていない最初のメッシュが入ります)。
3. 行の選択欄で、マスクにするメッシュを選ぶ。

| 項目 | 内容 |
| --- | --- |
| 行の選択欄 | マスクにするメッシュ (表示名で選ぶ) |
| 「Invert」 | 反転マスクにする。そのメッシュの形の **外** だけに描く |
| 「×」 | そのマスクを外す |
| 「Combine」 | マスクを 1 つ以上設定すると出る。通常のマスクが 2 つ以上あるときの結合方法で、「Union」(どれかの中なら描く、和集合) か「Intersection」(すべての中でだけ描く、共通部分)。反転マスクは常に和集合で結合する |

- 1 つのメッシュで、通常のマスクと反転マスクを同時に使えます。
- 自分自身や、互いにマスクにし合う (循環する) 設定はできません (エラーになります)。

## マスク専用のメッシュ

インスペクタの「Mask only」にチェックを入れたメッシュは、色としては描かれず、マスクとしてだけ働きます。
ツリーでは `mask` の印が付きます。

- マスクに使うためだけの形 (目の白目の範囲など) を用意するときに使います。不透明度を 0 にする必要はありません。
- どのメッシュからもマスクとして使われていないマスク専用のメッシュは、何の効果もありません。

## 前後関係が入れ替わる部分の作り方

顔を大きく横に向けると、横髪や耳と輪郭の前後関係が入れ替わります。描画順をキーで切り替えるだけだと、
入れ替わる瞬間にパッと切り替わり、物理で揺れる髪ではちらつきます。
そこで、同じ絵を 2 枚用意して輪郭を **挟み** (奥の 1 枚と手前の 1 枚)、手前の 1 枚をマスクで少しずつ見せます。

エディタの「描画用の複製」を使うと、2 枚目に変形を付け直す必要がありません。複製は元のメッシュと **同じ形** を共有し
(パラメータ・デフォーマ・物理の揺れにそのまま付いていきます)、描画順・不透明度・マスクだけを別に持ちます。

### 複製を作る

1. ツリーかビューポートで、元のメッシュ (たとえば **右耳**) を選ぶ。
2. インスペクタの「Draw clone」の「Create draw clone」を押す。
   元のすぐ手前に **右耳の複製** ができ、それが選ばれます。
3. 「Draw clone」の「Clone of」のボタンで元へ、元の「Clone」のボタンで複製へ、選択を移せます。

- 複製はツリーでは普通のメッシュとして出ます。パラメータを動かしたり物理のプレビューで揺らしたりしても、元とぴったり重なります。
- **形は元で編集します。** 元の頂点を動かす・足す・消す、三角形を作り直す、メッシュを作り直す、親のデフォーマを変える、
  といった編集には、複製が自動で付いていきます。複製の頂点の編集はエラーになります (`… is a draw clone of …`)。
- 元を削除すると、複製は元とのつながりを失い、その時の基準の形のままの普通のメッシュとして残ります。

### 手前の複製をマスクで見せる (反転マスク)

耳を例にします。元の **右耳** は輪郭より奥 (描画順が輪郭より小さい)、複製は輪郭より手前に置きます。

1. 複製を選び、「Draw clone」の「Draw order (this cell)」に輪郭より大きい数を入れる (Enter で確定)。
   キーのない複製なら、すべての姿勢でこの描画順です。
2. 境目の形のマスク専用メッシュを用意する (「Mask only」にチェック、[上](#マスク専用のメッシュ))。
   顔を正面に向けたときに耳の前側を覆い、横を向くにつれて小さくなる (または外へずれる) ように、パラメータのキーで形を付けます。
3. 複製の「Mesh」の「Masks」でそのメッシュを選び、「Invert」にチェックを入れる。
   複製は **マスクの外だけ** に描かれるので、正面では奥の元だけが見え、横を向くとマスクから外れた部分から手前の複製が現れます。

- 入れ替わりがマスクの形の変化で少しずつ起こるので、描画順を切り替える方法よりちらつきません。
- 逆に、輪郭の線のほうを反転マスクで消す作り方もあります (耳を常に手前に置き、横を向いたときだけ輪郭の線の一部を消す)。
  その場合は輪郭の線の複製を作り、複製だけにマスクを掛けます。

### 描画順のキーで切り替える

マスクを使わず、描画順そのものをパラメータで切り替えることもできます (動きの少ない部分向き)。

1. 複製を選び、パラメータの行の「◆」で、切り替えたい軸 (たとえば **AngleX**) にキーを足す。
2. キーの上にスライダーを置き、「Draw order (this cell)」と「Opacity (this cell)」をキーごとに入れる。
   たとえば AngleX = 0 では描画順を輪郭より小さく、AngleX = 30 では大きくします。

- 描画順はキーの間で線形に補間され、輪郭の描画順を越えたところで前後が入れ替わります。
- 複製のキーは描画順と不透明度のためのものです。頂点の位置は元に従うので、複製でフォーム編集をしても見た目は変わりません。

### 「Out of sync with the original」と出たら

ファイルを手で書き換えたときなどに、複製の三角形や親が元と食い違うと、「Draw clone」に
「Out of sync with the original」と「Resync」が出ます。「Resync」を押すと、複製の形とつながりを元に合わせ直します
(描画順・不透明度・マスクはそのまま残ります)。
