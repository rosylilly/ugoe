# マスク

マスクは、あるメッシュを **別のメッシュの形の中だけ** に描く (クリッピング)、または **形の外だけ** に描く (反転) 仕組みです。
影やハイライトを肌からはみ出させない、瞳を白目の中に収める、といった用途に使います。

- マスクは、メッシュごとに「どのメッシュをマスクにするか」を並べて設定します。
- マスクにするメッシュの不透明度・非表示・合成モードは、マスクの効き方に影響しません。不透明度 0 のメッシュも、形どおりにマスクとして効きます。
- マスクは入れ子になります。たとえば瞳を黒目でクリップし、黒目を白目でクリップすると、瞳も白目からはみ出しません。

## PSD のクリッピング

PSD でクリッピングしたレイヤーは、取り込むと、下のレイヤー (土台) をマスクにしたメッシュになります。

- `character.psd` では、**顔の影** が **顔** をマスクにしています。ツリーで **顔の影** を選ぶと、インスペクタの「Masks」に **顔** が出ます。
- 土台がグループなら、グループの中のすべてのメッシュがマスクになります。
- 土台のレイヤーの不透明度は、クリッピングされた側の不透明度に掛けられます (Photoshop と同じ見た目にするため)。
- 土台が取り込めなかった (空のレイヤーなど) ときや、グループをクリッピングしていたときは、マスクなしで取り込み、警告が出ます ([よくある警告](warnings.md#psd-の取り込みの警告))。

## マスクを設定する

1. ツリーかビューポートで、マスクを掛けたいメッシュを選ぶ。
2. インスペクタの「Mesh」の「Masks」の右の「Add」を押す。マスクの行が 1 つ増えます (まだ使っていない最初のメッシュが入ります)。
3. 行の選択欄で、マスクにするメッシュを選ぶ。

| 項目 | 内容 |
| --- | --- |
| 行の選択欄 | マスクにするメッシュ (表示名で選ぶ) |
| 「Invert」 | 反転マスクにする。そのメッシュの形の **外** だけに描く |
| 「×」 | そのマスクを外す |
| 「Combine」 | マスクを 1 つ以上設定すると出る。通常のマスクが 2 つ以上あるときの結合方法で、「Union」(どれかの中なら描く、和集合) か「Intersection」(すべての中でだけ描く、共通部分)。反転マスクは常に和集合で結合する |

- 1 つのメッシュで、通常のマスクと反転マスクを同時に使えます。
- 自分自身や、互いにマスクにし合う (循環する) 設定はできません (エラーになります)。

## マスク専用のメッシュ

インスペクタの「Mask only」にチェックを入れたメッシュは、色としては描かれず、マスクとしてだけ働きます。
ツリーでは `mask` の印が付きます。

- マスクに使うためだけの形 (目の白目の範囲など) を用意するときに使います。不透明度を 0 にする必要はありません。
- どのメッシュからもマスクとして使われていないマスク専用のメッシュは、何の効果もありません。
