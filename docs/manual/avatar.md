# アバタープロファイル

アバタープロファイルは、モデルを VTuber 向けのアプリなどでアバターとして使うための情報です。
どこまでの動き (レベル) に対応しているか、誰がどう使ってよいか (利用許諾) を、モデルに書いておきます。
中身の詳しい約束は [アバタープロファイル仕様](../spec/avatar-profile.md) にあります。

## プロファイルを作る

1. ツリーやビューポートの何もないところを押して、選択を外す。
2. インスペクタの「Avatar profile」の節の「Create avatar profile」を押す。

名前にはモデルの名前が入ります。利用許諾はすべて **最も制限の強い値** (作者だけが使える・個人の非営利だけ・クレジット表記が必要・
改変の禁止・再配布の禁止、暴力的・性的・政治や宗教・反社会的な表現での利用は不可) から始まります。
許す範囲は、自分で確かめてから広げてください。

## メタデータと利用許諾を編集する

欄を変えて、別の欄を押すか Tab キーで離れると反映されます。1 つの欄の変更が、1 回の Ctrl+Z で戻ります。

| 欄 | 内容 |
| --- | --- |
| 「Level」 | 対応を主張するレベル。1 (Basic: 頭の向き・目の開閉・口の開き)、2 (Standard: 視線・眉・口の形・体の向き・呼吸も)、3 (Expressive: 表情のパラメータも 8 つ以上) |
| 「Name」 | アバターの名前 (必須) |
| 「Authors」 | 作者。1 行に 1 人 (1 人以上が必須) |
| 「Version」「Copyright」「Contact」「License URL」 | バージョン・著作権の表示・連絡先・利用規約の URL (空でよい) |
| 「References」 | 原作・参考元。1 行に 1 つ |
| 「Thumbnail」 | サムネイルにするテクスチャ |
| 「Who may use it as an avatar」 | アバターとして使ってよい人: 作者だけ・許諾した人だけ・誰でも |
| 「Commercial use」 | 商用利用: 個人の非営利だけ・個人の営利まで・法人まで |
| 「Credit」 | クレジット表記: 必要・不要 |
| 「Modification」 | 改変: 禁止・許可・許可して改変したものの再配布も許可 |
| 「Allow」 | チェックを付けた使い方を許す: 過度に暴力的な表現・過度に性的な表現・政治や宗教の目的・反社会的や差別的な目的・再配布 |
| 「Third-party licenses」 | 素材などの第三者のライセンス表記 |
| 「Standard hit areas」 | アプリが使う標準の当たり判定 (「Head」「Body」) に、モデルのどの当たり判定を使うか。モデルに当たり判定がなければ出ない |

「Remove avatar profile」でプロファイルを外すと、どのレベルにも対応しないモデルになります (Ctrl+Z で戻せます)。

## 対応の検査を見る

節のいちばん下の「Conformance」に、検査の結果が出ます。編集するたびに調べ直します。

- 緑の枠: 主張したレベルに対応しています。「Satisfies」は、パラメータから見て満たしているレベルです (主張より高いこともあります)。
- 橙の枠: 主張したレベルにエラーがあります。赤い行がエラー、その下の色の付いていない行が警告です (警告があっても対応は妨げません)。

よくあるエラーと対処です。

| エラー | 対処 |
| --- | --- |
| `avatar.meta.name is required` / `avatar.meta.authors is required` | 「Name」「Authors」を埋める |
| `level 2 requires parameter ...` / `level 3 requires at least 8 extended parameters, ...` | パラメータを足すか、「Level」を下げる |
| `... refers to unknown ...` | 消した当たり判定・テクスチャなどを参照している。欄を選び直す |

同じ検査は、書き出した `.ugoe` に対して `ugoe validate --profile avatar <ファイル>` でも行えます。

## 制限

- トラッキングの対応の上書き・視線のパラメータと可動範囲・公開する着せ替えのスロット・当たり判定そのものの作成は、今は画面では編集できません。
