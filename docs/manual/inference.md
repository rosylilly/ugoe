# 推定・ミラー・深度

キーの組み合わせが増えると、手で作る形 (セル) の数は掛け算で増えます。
ugoe では、手で作るのは一部のセルだけにして、残りを **推定** で作れます。推定したセルは、元のセルを直すと自動で作り直されます。

推定の方法は 3 つあります。

| 方法 | 作るもの | 例 |
| --- | --- | --- |
| 加算合成 | 斜めのセル (2 本以上の軸が既定値でないセル) を、端のセルの変化の足し算で作る | 右上を向いた顔 = 右を向いた変化 + 上を向いた変化 |
| ミラー | 左右の対になる要素のセルを、片側を反転して作る | 右目の形を左目から作る |
| 深度からの回転 | 点ごとの深度 (手前への出っ張り) を使い、立体を回したように向きのセルを作る | 顔の振り向き |

内部の規則の詳細は [spec/keyform-inference.md](../spec/keyform-inference.md) (開発者向け) にあります。

## セルの記号

インスペクタの「Keyforms」の格子は、セルがどうやって作られたか (由来) を記号と色で示します。
格子の下に凡例があり、セルにマウスを載せると説明が出ます。

| 記号 | 名前 (凡例) | 意味 | 推定で上書きされるか |
| --- | --- | --- | --- |
| `A` (実線) | Authored | 手で作った・手で直したセル | されない |
| `+` (緑の破線) | Additive | 加算合成で作ったセル | 元のセルが変わると作り直される |
| `R` (橙の破線) | Depth rotation | 深度からの回転で作ったセル | 深度や元のセルが変わると作り直される |
| `M` (青の破線) | Mirror | ミラーで作ったセル | ミラー元が変わるとミラーし直される |
| `D` (紫の破線) | Derived | 推定で作ったが、方法が記録されていないセル (古いファイルなど) | 格子の推定の方法 (「Method」) で作り直される |

- 推定のセル (`A` 以外) を手で編集すると、そのセルは `A` になります。
- キーを追加したときにできるセルは、見た目が変わらないように補間した形で埋まります。
  中立 (既定値) のキーがある軸に端のキーを加えると、斜めのセルは `+` になり、端のセルは `A` になります。
  **既定値のキーを先に追加する** のがこつです ([チュートリアルの 6 章](tutorial.md#6-キーを追加する))。
- 目安: 形を手で作るセルは `A`、それ以外は推定に任せます。

## Inference の節

インスペクタの「Inference」には、選んでいる要素の格子について次の操作があります。

### 推定の設定

先頭に `Derived cells are re-derived by additive blending.` のように、今の推定の方法が出ます。

| 項目 | 内容 |
| --- | --- |
| 「Method」 | 「Additive blending」(加算合成) か「Depth rotation」(深度からの回転。メッシュとワープデフォーマだけ) |
| 「Angle scale」 | (回転) パラメータの値に掛ける倍率。既定 1 = パラメータの値をそのまま度として使う |
| 「Pivot x」「Pivot y」 | (回転) 回転の中心。親の座標系の値で、初期値は形の中心 |
| 「Pivot depth」 | (回転) 回転の中心の深度 |
| 「Yaw」 | (回転) 縦の軸まわり (左右の振り向き) に使うパラメータ。格子の軸に `AngleX` があれば自動で入る |
| 「Pitch」 | (回転) 横の軸まわり (うなずき) に使うパラメータ。`AngleY` があれば自動で入る |
| 「Apply settings」 | 設定を格子に保存し、方法の記録のないセル (`D`) を作り直す。設定を変えると押せるようになる |
| 「Reset」 | 変えた設定を元に戻す |

- 深度からの回転は、親がワープデフォーマの要素には使えません (親がないか、回転デフォーマである必要があります)。
- 「Yaw」「Pitch」に選べるのは格子の軸のパラメータだけです。

### 推定の実行

| ボタン | 内容 |
| --- | --- |
| 「Infer」 | 格子の方法で作ったセルを作り直す。`A` のセルは変えない |
| 「Infer (overwrite derived)」 | 推定のセルをすべて (ミラーなど別の方法のセルも) 格子の方法で作り直す。方法を変えた後に、古い方法のセルを置き換えるときに使う |
| 「Mark authored」 | 選んだセル (なければ今のセル) を `A` にする。形は変えない。推定で上書きされなくなる |
| 「Mark derived」 | 選んだセル (なければ今のセル) を推定に戻し、格子の方法で作り直す |

- 選んだセルの数は、ボタンの左に `4 selected cells` のように出ます。セルは「Keyforms」の格子で、Shift / Ctrl を押しながら押して選びます。
- 基準のセル (すべての軸が既定値のセル) は推定に戻せません。

### ミラー

メッシュとデフォーマでは、「Mirror」と「Mirror partner」が出ます。

| 項目 | 内容 |
| --- | --- |
| 「Mirror from」 | ミラー元。対の相手 (`左目のワープ (WarpLayer13) (mirror partner)`) か、自分自身 (`顔のワープ (WarpGroup18) (itself, left ↔ right)`。左右対称な 1 つの要素の、片側から反対側を作る) |
| 「Axis」 | 対称軸 (縦の線の x 座標)。空なら既定 (親がなければキャンバスの中心、親がワープなら格子の中央、親が回転デフォーマなら中心) |
| 「Tolerance」 | メッシュの頂点を対応させるときの許容距離。空なら 1 ピクセル |
| 「Overwrite authored cells」 | チェックすると、先の `A` のセルもすべて上書きする。チェックしなくても、キーを追加しただけでまだ形を変えていないセル (基準のセルと同じ形の `A`) は上書きする |
| 「Mirror」 | ミラーを実行する。作ったセルは `M` になり、`Mirrored cells come from 左目のワープ (WarpLayer13).` のようにミラー元が記録される。下に `Mirrored 1 cell from … Kept 1 cell authored (not overwritten).` のように、書いたセルと残した `A` のセルの数が出る。1 つも書かなかったときは理由と「Overwrite authored cells and mirror」(`A` のセルも上書きしてやり直す) が出る |
| 「Partner」「Mirror axis」「Set partner」 | 左右の対の相手 (名前と ID で選ぶ) と対称軸を設定する。対は双方向に張られ、前の相手との対は外れる。「(none, symmetric)」で対を外す |

ミラーの条件:

- **パラメータの対:** 左右で別のパラメータを使う軸 (`EyeLOpen` と `EyeROpen`) は、パラメータどうしが対になっている必要があります。
  自分自身と対にしたパラメータ (`AngleX`) は、値の符号を反転したキー (30 ↔ -30) に対応します。
  パラメータの対は、「Parameters」でパラメータの名前を押して出る編集欄の「Mirror」で設定します ([画面とパネル](screen.md#パラメータ)、[チュートリアルの 9.1](tutorial.md#91-パラメータの対を設定する))。
- **軸:** 先の格子の軸と元の格子の軸が、パラメータの対で 1 対 1 に対応する必要があります。先の要素にも先にキーを追加しておきます。
- **メッシュの頂点:** 先の各頂点について、元の頂点を反転した位置が許容距離の中にある必要があります。ワープの制御点は格子の並びで対応するので、位置は問いません。
- **ワープの大きさ:** 対のワープは、行数と列数が同じである必要があります。

ミラー元のセルを後で編集すると、ミラーしたセルは自動で作り直されます。作り直せなかったときは通知が出ます ([よくある警告](warnings.md#ミラーのやり直しの通知))。

## 深度

インスペクタの「Depth」は、メッシュかワープデフォーマを選んだときに出ます。深度は深度からの回転だけに使い、モデルの表示には影響しません。

| 項目 | 内容 |
| --- | --- |
| 先頭の行 | 点の数と深度の範囲 (`16 control points · 0 – 35.28 px`)。深度がなければ `none` |
| 「Show in viewport」 | ビューポートに点の深度を色の輪で出す (手前ほど赤、奥ほど青、0 は灰色) |
| 「Uniform」+「Set all」 | すべての点を同じ深度にする |
| 「Dome peak」+「Dome」 | 形を囲む楕円の中で、中心が指定の高さの丸い山にする (楕円の縁と外は 0。負の値ならくぼみ) |
| 「Selected」+「Set selected」 | 選んだ点だけを指定の深度にする。メッシュはメッシュ編集モードで選んだ頂点、ワープはギズモで選んだ制御点 |
| 「Clear depth」 | 深度を外す |

- 深度の単位はキャンバスのピクセルで、手前が正です。
- 深度を変えると、`R` のセルは新しい深度で作り直されます。
- `R` のセルが残っている要素の深度は外せません (エラーになります)。先にセルを `A` にするか、「Method」を「Additive blending」にします。
