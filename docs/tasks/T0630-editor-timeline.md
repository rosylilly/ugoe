# T0630: エディタ: タイムラインとモーションの編集

## 目的

エディタでモーション (と表情) を作り、タイムラインで再生・編集できるようにする。

## 受け入れ条件

- [ ] モーション・表情をプロジェクトに持ち、保存・読み込み・`.ugoe` への書き出しができる (プロジェクトの形式を変えるなら `docs/spec/file-formats.md` も)
- [ ] モーション・表情を編集する `Command` (作成・削除・名前・長さ・ループ・フェード、カーブの追加・削除、点の追加・移動・削除、区間の種類 (直線・ベジェ・ステップ) とベジェの取っ手、イベント) と、検証・Undo のテスト
- [ ] タイムラインのパネル: 再生・停止・シーク・ループ、パラメータごとのトラックとキー、今のスライダーの値でキーを打つ操作、カーブの表示と取っ手の編集
- [ ] 表情の作成 (今のパラメータの値から、op の選択) とプレビュー
- [ ] 操作マニュアルにモーションの章を足す
- [ ] `just ci`・`just gen` (差分なし)・エディタのビルドが通る
