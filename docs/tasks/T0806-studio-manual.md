## メモ

- **やったこと:**
  - `docs/manual/studio.md` (日本語。配信者向け): 起動・画面・はじめての配信の準備・見本のプロファイル・シーンとプロファイル・入力 (カメラとマイク)・
    表情とモーション・ホットキー・配信ソフトに出す 3 通り (ブラウザソース・ウィンドウの取り込み (OS ごと)・仮想カメラ (OS ごと))・フレームレートと負荷・
    操作 API (概要と docs/studio-api.md への案内)・パラメータ・設定・困ったとき・制限。文言は `apps/studio/locales/ja.json` (と @ugoe/ui・
    @ugoe/face-tracking の日本語のカタログ) の表記に合わせ、この章は日本語の画面の名前で書くと断った。`docs/manual/README.md` の目次に足した。
  - 画像 12 枚 (`docs/manual/images/studio-*.png`。合わせて約 330KB、256 色に減色): 操作ウィンドウの全体 (1000 幅、既存の画像と同じ)・
    パネルの切り抜き (約 390 幅)・出力 3 つ (透過は市松模様の上に)。T0907 の後の画面。
  - 見本のプロファイル: プロファイルはモデルを絶対パスで持つ (ADR 0028 の 4.) ので、ファイルをコミットせず、`apps/studio/scripts/sample-profile.mjs`
    (`pnpm --filter @ugoe/studio sample-profile <出力> [--lang en] [--force]`) がリポジトリの場所に合わせて書き出す。シーン 4 つ (`avatar.ugoe`・
    `avatar-lit.ugoe` + 夕日・`dress-up` + `long-hair`・`sailor` + クロマキー・`avatar.ugoe` を右下に) とホットキー 14 個。ugoe-cli はスタジオの
    プロファイルの形を知らない (アプリに依存できない) ので、CLI には足さなかった。Vitest (`scripts/sample-profile.test.mjs`) が、ファイルがあること・
    シーンの参照・キーの重複・光源が「夕日」の組と同じことを確かめる。
  - `docs/studio.md` に「実機で確かめていないこと」の一覧 (Tauri のウィンドウ・隠れても止まらない・ウィンドウの取り込み・ブラウザソース・入力・
    ホットキー・操作 API・仮想カメラ) とマニュアルへの案内を足した。マニュアルはこれらを手順として書いている。`apps/studio/README.md` に
    スクリプトとマニュアルの行。
- **確かめ方:** 使い捨てのブリッジ (本物の `Stage`・`Conductor`。T0803 のものをこの worktree に向けた) とヘッドレスの Chrome で、ビルドした `dist/` の
  操作ウィンドウと出力ウィンドウを開き、見本のプロファイルを「プロファイルを開く…」で開いて 4 つのシーンを切り替え (出力が描けること・ホットキーの
  問題 0 件)、表情とモーション・記録の再生のトラッキング・偽のマイクの口パクを動かして撮った。操作 API・ブラウザソース・仮想カメラはブリッジに無いので
  偽の値。日本語と英語の両方 (`--lang en` のプロファイル) で同じ場面を撮り、崩れが無いことを確かめた。スクリプトと画像は
  scratchpad の `T0806/` (`run.sh`・`shots.mjs`・`shots/ja`・`shots/en`)。`just ci` が通る。
- **確かめていないこと:** 実機 (上の docs/studio.md の一覧と同じ)。マニュアルの OBS・OS の画面の名前は docs/studio.md の手順に合わせたもので、
  実物で見比べていない。
- **範囲外の変更:** なし。
- **後続の候補:** マニュアルの英訳 (M8 の範囲外。置き場所は docs/manual/en/)。実機で確かめた結果に合わせてマニュアルを直す。
  プロファイルのパスを、プロファイルのファイルからの相対でも持てるようにする (人に渡せる見本のプロファイルや、モデルと一緒に動かせるプロファイルのため。
  ADR 0028 の 4. の見直し)。配布物から見本のプロファイルを開く口 (ビューアの「サンプル」のような) は無い。
