# T0085: 1.0 の範囲を改め、M7・M11 を完了にする

## 目的

M7 と M11 には完了の判断の節が無い (M9 の T0008・M10 の T0919 のような節)。利用者の決定に合わせて文書を揃える。

- **M7・M11:** 完了にしてよい。M7 に残る T0407 (Unreal のプラグイン) と T0443 (Unity の実機での確認) は、M7 の完了の条件から外す (T0407 は 1.0 の後の候補、T0443 は人の手の確認として残す。扱いを節に書く)。
