## メモ

### やったこと

- **キーボード (`LightMarkers.svelte`・`lighting.ts` の `stepMarker`):** 取っ手を `tabindex=0`・`role="slider"` にし、`aria-label` にキーの説明、
  `aria-valuetext` に方位・高さ / 横・縦・手前・範囲。キーボードで来たフォーカス (`:focus-visible`) のときだけ取っ手の周りに輪を描く。
  平行光源は矢印キーで取っ手を動かす (パネルの丸い面と同じ量 0.05、Shift で 0.2)。点光源は矢印で横・縦 (1%、Shift で 10%)、
  PageUp / PageDown で手前 (2%、Shift で 10%)、`+` / `-` (`=`・`_` も) で範囲 (5%)。キーボードはパネルと同じくすぐ覚える。
- **拡大したときの印 (`lightDial` の `bounds`・`pointHandleOnScreen`):** 平行光源の円がビューポートからはみ出すときは、円ごと画面の内側
  (縁から 14px) に寄せる。画面が円より狭ければ中央。点光源が画面の外なら取っ手を縁に寄せて破線で描く (掴むと光源は掴んだ位置へ)。
  範囲の円は本当の位置。`Player.viewportSize` を足した。
- **点光源の手前と範囲をビューポートで (`rangeFromScreenRadius`・`wheelPointZ`):** 範囲の円の縁 (幅 10px の見えない線、`[data-light=range]`)
  のドラッグで範囲 (手前は保つ)。取っ手の上の Shift + ホイールで手前 (ホイールだけは今までどおりズーム。回し終えて 0.4 秒で覚える)。
  円の内側・外側のドラッグはパンのまま。
- **「既定に戻す」:** 「標準」をそのモデルの設定として覚えるように変えた (`resetLighting` = `setLighting(defaultLighting())`)。
  次に開いたときも標準で始まる。「標準」を覚えていれば押せない。理由: 忘れるだけだと次に開いたときに最後に使った光源で始まり、
  「このモデルを標準に戻した」つもりの利用者を驚かせる。忘れる操作は一覧に分けた。README と `docs/manual/lighting.md` に書いた。
- **覚えたものの一覧 (`MemoryDialog.svelte`・`rememberedModels.ts`):** ツールバーの「覚えたもの」とライティングのパネルの「覚えたもの…」から開く。
  光源と組の入れ物の項目を同じモデル (`sameModel`) ごとに 1 行にまとめ、開いているモデルを先頭・あとは名前順。行ごとに光源・組・両方を忘れる。
  「すべて忘れる…」は一覧の中で確かめてから (`confirm()` は Tauri の webview で出ない場合があるので使わない)。最後に使った光源と
  印・自動で戻すの設定は残す。開いているモデルの分を忘れたら、パネルの「覚えた」の表示を消し、尋ねている組は取り消す。
  `modelMemory.ts` には `entries()`・`clear()` だけを足した (location の扱いには触れていない)。`Player` に `rememberedModels()`・
  `forgetRemembered(model, { lighting, dressUp })`・`forgetAllRemembered()`。
- **モジュールだけがライティングを受けるモデル:** パネルは出さないまま (効かないスライダーを出さないため)、覚えた光源は一覧から忘れられるようにして解決した。
- Vitest: `lighting.test.ts` に 6 件 (円を寄せる・点光源を寄せる・範囲の縁・キーボード・ホイール・`lightingLabel`)、`modelMemory.test.ts` に 1 件、
  `rememberedModels.test.ts` (新規 4 件)。
- 文書: `apps/viewer/README.md` (構成・使い方の表・モデルごとに覚えるの表・「覚えたものの一覧 (T0714)」・ライティングの「既定に戻す」・
  印の節のキーボード・画面の外・範囲と手前)、`docs/manual/lighting.md` (「覚えたものの一覧」・直接動かすの節)、`docs/manual/dress-up.md` (一覧への 1 項目)。

### 確かめていないこと・後続の候補

- Tauri (WebKitGTK) のウィンドウでは動かしていない (`.deb` は作れた)。SVG の要素のフォーカスと `:focus-visible`、Shift + ホイールの
  `deltaX` への置き換えは WebKitGTK で確かめていない。スクリーンリーダーでの読み上げも確かめていない。タッチ操作・高 DPI も未確認。
- 範囲の円の縁が画面の外にあると (範囲が大きい既定の 1.4〜1.5 では多くの場合そう) ビューポートでは掴めない。キーボードの `+` / `-` かパネルで変える。
  縁を画面の端に寄せた小さな取っ手を足す案がある。
- 寄せた平行光源の円はキャンバスの中央を示さない (見た目での区別は付けていない)。
- 一覧の並びは名前順 (入れ物ごとの最近使った順が揃わないため)。覚えた日時を持たせれば新しい順にできる。一覧から覚えた設定を開いたり
  書き換えたりはできない。
- 取っ手にフォーカスがあるときも `F` はフィット (アプリのショートカット) になる。
