# T0646: エディタ: ライティングの操作 (有効化・法線マップ・プレビューの光源)

## 目的

利用者の指摘。ライティングはレンダラとホストにはあるが、エディタから操作できない。エディタでライティングを設定し、確かめられるようにする。

## 受け入れ条件

- [ ] ライティングのパネル: モデルのライティングの有効・無効 (`SetLighting`)。メッシュごとの有効・無効 (`Mesh::lit` を変える Command を足す。Undo のテスト)
- [ ] 法線マップ: 選んだメッシュのテクスチャに、形からの生成 (AI なし。`ugoe-rigging` の bulge。強さ・縁の丸みを選べる) か、画像の割り当てで法線マップを付け・差し替え・外す (`SetNormalMap`)。法線マップの画像を確かめられる
- [ ] プレビューの光源: 環境光・平行光源・点光源をビューポートの上で置き、向き・色・強さを変えて確かめられる。光源はモデルに入らない (ホストが渡す) ので、プレビューの設定としてプロジェクトに残すかを決めて書く
- [ ] ヘッドレスのブラウザで確かめる。操作マニュアルに章 (`docs/manual/lighting.md`)
- [ ] `just ci`・`just gen`・`cargo check -p ugoe-editor` が通る
