# T0635: エディタ: プレビューモード (パラメータのスライダーで仕上がりを確かめる)

## 目的

今のエディタでは、パラメータのスライダーは編集のためのパネル (キーの追加・値の入力) の一部で、インスペクタや物理のタブと画面を分け合っている。
物理・目パチ・呼吸は物理のプレビューなど個別の場所でしか動かず、組み上げたモデルが実際にどう動くか (すべてのパラメータを動かしたときの仕上がり) を確かめにくい (利用者の要望、2026-09-29)。
編集の道具を隠し、パラメータのスライダーを並べて、ランタイムと同じ `Puppet::update` で動かすプレビューモードを作る。

## 受け入れ条件

- [ ] ヘッダー (かツールバー) の切り替えでプレビューモードに入る・出る。プレビュー中は編集の道具・ギズモ・選択を隠し、ビューポートを広く使う。編集のコマンドは送らない
- [ ] すべてのパラメータのスライダーを、パラメータグループごとに並べる (絞り込み、1 つずつ・すべて既定値に戻す)。値を数値でも入れられる
- [ ] 物理・目パチ・呼吸・リップシンク・ポーズを `update(dt)` で動かし、それぞれを有効・無効にできる (T0309 の `set_enabled`)。物理のリセット
- [ ] モーション・表情を選んで再生・停止できる (プロジェクトのもの。T0630)
- [ ] プレビューのスライダーの値は編集の姿 (編集用のスライダーの値) と別に持ち、プレビューを出ると編集していた姿に戻る
- [ ] 可能ならビューアのフェイストラッキング (T0703) をプレビューで使えるようにする (どちらも GPL なので写してよい。共有の部品に切り出すかは決めて書く)。難しければ後続のタスクにする
- [ ] ヘッドレスのブラウザで見本 (`assets/samples/avatar.ugoe` のプロジェクト) を使って確かめ、操作マニュアルにプレビューの章を足す
- [ ] `just ci`・エディタのビルドが通る
