# T0045: ui-audit: Tab の止まりのフォーカスの印を、フォーカスの前と後の画像の差で判定する

## 目的

`just ui-audit` の `focus` の検査は、自分と 2 つ上の祖先の `outline`・`box-shadow` を見てフォーカスの印の有無を決めている (`lib/walk.mjs`)。
地の色や枠の色だけを変える印や、3 つ以上上の祖先に付く印は見逃したり誤って数えたりする。フォーカスの前と後の画像の差で、印が見えるかを判定する
(T0915 の任意の候補。T0918 の候補)。

## 受け入れ条件

- [ ] Tab の止まりごとに、フォーカスの前と後で止まりの周りの画像を撮り、変わった画素の量 (と色の差) で印の有無を判定する。閾値と理由を tests/ui-audit/README.md に書いた
- [ ] 今の CSS の判定と画像の判定が食い違う止まりを 3 つのアプリで洗い、メモに書いた (どちらが正しいかも)
- [ ] 判定を画像に替えた (または CSS の判定と併せた) 後、`just ui-audit` の `focus` の数が前と比べてどう変わったかをメモに書いた。実行の時間の増え方もメモに書いた
- [ ] `just ci` が通る
