# T0623: エディタを空のプロジェクトで起動し、PSD から新規作成できるようにする

## 目的

T0619 の 2 回目の確認で、Import PSD のたびに「PSD のキャンバス (320x400) がモデルのキャンバス (256x256) と違う」という警告が出た。
エディタが起動時にサンプルのモデル (`single_quad`、256x256) を開いているため、PSD がそこに追加されるのが原因。
初めて使う人が迷わないように、空のプロジェクトで起動し、PSD から新しいプロジェクトを作れるようにする。

## 受け入れ条件

- [ ] エディタは空のプロジェクト (メッシュ・パーツなし) で起動する。空のモデルへの Import PSD は、PSD の大きさをキャンバスに使い、警告を出さない (T0605 の既存の規則)
- [ ] File に「New from PSD…」がある: 未保存の変更の確認のあと、新しいプロジェクトを作って PSD を取り込む (1 回の操作)
- [ ] 空のプロジェクトでは、ビューポートとツリーに次の操作の案内 (例: 「File > New from PSD… で始める」) を出す
- [ ] 既存のモデルに取り込む場合の警告の文言を、何が起きるか分かるものにする (キャンバスを変えない・位置は PSD のまま)
- [ ] テストと `docs/editor.md` を更新する
- [ ] `just ci`・`just gen` (差分なし)・エディタのビルドが通る
