# T0627: リギング操作の使い勝手 (優先度 高)

## 目的

操作マニュアル (T0624) を書く過程で、チュートリアルの手順をたどる中で見つかった問題のうち、作業を止めてしまうもの・迷わせるものを直す。詳細は `docs/tasks/T0624-user-manual.md` のメモ。

## 受け入れ条件

- [ ] **パラメータのミラーの対を UI から設定できる** (`Parameter::mirror`。今は `model.json` を手で書き換えるしかない)。チュートリアルの `model.json` を編集する回避策を取り除く
- [ ] **初回のミラーが何もしない問題:** キーの追加でできた `A` のセルがあると、「Overwrite authored cells」を付けないとミラーが何も書かない。何も書かなかったときは理由を表示し、既定の挙動を見直す (例: まだ一度も編集していないセルは上書きしてよい、または初回だけ確認を出す)
- [ ] **要素を名前で選べる:** ミラーの相手・ミラー元・テクスチャなどの選択肢に、ID だけでなく表示名 (日本語のレイヤー名) を出す。デフォーマの既定の ID と名前を分かりやすくする (例: 包んだ要素の名前から付ける)
- [ ] **パーツを選んで包める:** パーツを選んで「Wrap in deformer」すると、その中のメッシュ (とデフォーマ) をまとめて包む
- [ ] **Undo / Redo のショートカット** (Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y、macOS は Cmd)
- [ ] **右の列の配置:** パラメータがインスペクタの下に隠れてスクロールが多い。右の列が横にはみ出す。パラメータとインスペクタを見やすく並べる (タブ・折りたたみ・幅の調整など)
- [ ] 操作マニュアルを更新し、`just ci`・`just gen` (差分なし)・エディタのビルドが通る
