# T0676: エディタ UI: AI・モジュール・着せ替えの画面

## 目的

AI の提案と承認、モジュールのプロジェクト・違いの比較・着せ替えのプレビューの画面を見直す。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [ ] AI の提案の一覧・差分・承認と却下の配置を見直し、何が変わるか・承認するとどうなるかが一目で分かる
- [ ] AI の待ち時間 (送信中・考え中・失敗・取り消し) の見せ方を揃えた
- [ ] モジュールの違いの比較 (T0654〜T0659) の表の配置と、長い一覧での送り・絞り込み
- [ ] 着せ替えのプレビューと警告の出し方 (T0649・T0652) を揃えた
- [ ] 同意・API キーの設定の画面で、秘密の扱いが分かる文と配置になっている
- [ ] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [ ] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [ ] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [ ] `just ci` が通る
