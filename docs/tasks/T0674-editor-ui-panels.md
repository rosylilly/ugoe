# T0674: エディタ UI: パネル (ツリー・インスペクタ・パラメータ・物理・ライティングなど)

## 目的

エディタのパネルの中の配置・ラベル・グループを見直し、パネルの間で同じ種類の欄が同じ形で並ぶようにする。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [ ] ツリー・インスペクタ・パラメータ・物理・ライティング・スロット・グルー・ポーズ・検証の各パネルで、欄の並び (ラベルの位置・幅・揃え)・グループ (Section) の見出し・補足の出し方を揃えた
- [ ] インスペクタで、選んだものの種類ごとに見せる欄の優先度を見直した (よく触る欄が上)
- [ ] 長い名前・多い項目 (パーツ 200 個・パラメータ 100 個) で崩れず、送りが分かる
- [ ] 選択・ホバー・無効・警告の見せ方が、ツリーとビューポートで対応している
- [ ] パネルの中のキーボード操作 (ツリーの矢印・欄の移動・削除) を確かめた
- [ ] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [ ] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [ ] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [ ] `just ci` が通る
