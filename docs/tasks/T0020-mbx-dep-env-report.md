# T0020: mbx の DEP_* の環境変数の不具合を報告し、直ったら回避の設定を外す

## 目的

T0018 で mbx (ビルドのキャッシュ) を入れたとき、ビルドスクリプトのラッパーが `/bin/sh` (dash) を通るため、名前に `:` を含む
`DEP_*` の環境変数が落ちることが分かった。リポジトリでは `.mbx.toml` で回避している。上流 (mbx) に報告し、直った版が出たら
回避の設定を外す。
