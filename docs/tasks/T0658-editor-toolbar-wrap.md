# T0658: エディタのツールバーの折り返し

## 目的

T0522 の確認のスクリーンショット (幅 1040px) で、ツールバーの「Export…」が「Preview」「Undo」と重なり、プロジェクト名も折り返して重なっていた。ボタンが増えた (Open Sample… など) ことによる崩れとみられる。

## 受け入れ条件

- [x] 幅 1024px 前後から広い幅まで、ツールバーのボタンとプロジェクト名が重ならない (折り返す、まとめる、名前を省略するなど)
- [x] ヘッドレスのブラウザで、いくつかの幅のスクリーンショットを撮って確かめる。横のはみ出しが 0
- [x] `just ci`・エディタのビルドが通る

## メモ

- **原因:** ファイルのメニュー (`FileMenu.svelte` の `nav`) は `min-width: 0` で縮むのに、中のボタンは `flex-shrink: 0` で折り返さない
  ため、`nav` の外へはみ出して右の Preview・Undo などに重なっていた。プロジェクト名は縮んで折り返していた。
- **直し方:** `nav` を `flex-wrap: wrap` にし、幅が足りなければファイル操作のボタンとプロジェクト名が 2 行目へ折り返す。ヘッダーの行の
  高さは `36px` 固定から `auto` (最小 36px) にした (`app.css` の `.shell`)。ヘッダーの `nav` 以外 (ugoe・版・Preview・Undo・Redo・
  Agents・Settings・Help) は縮めず折り返さない (`App.svelte`)。プロジェクト名は 16em を超えると「…」で省略し、未保存の印は省略しない。
  名前の title は「名前の全体 + 改行 + 保存先のパス (なければ not saved yet)」。マニュアル (screen.md のヘッダー) に折り返しと省略を
  書いた。見た目は大きく変わらないので、マニュアルの画像は撮り直していない。
- **確かめたこと:** `just ci` (`CARGO_BUILD_JOBS=8`)・`pnpm build`。ヘッドレスの Chrome と本物の `Document` への使い捨ての HTTP ブリッジ
  (scratchpad/T0658/bridge。T0657 のものをパスとポートだけ変えた) で、`ugoe sample dress-up --project` の本体 (未保存の印あり)・長い名前・
  モジュールのプロジェクト (long-hair。Export Module… と Module: Hair の印・長い名前)・プレビュー中を、幅 1024・1040・1280・1440・1600・
  1920 で撮り、ヘッダーのボタン・名前・未保存の印の矩形が互いに重ならないこと、ボタンの文字が折り返さないこと、横のはみ出し 0 を
  確かめた (ヘッダーの高さは 1024 で 55〜72px、1600 以上で 36px)。スクリーンショット: scratchpad/T0658/shots/t0658-*.png。
  vite preview とブリッジは止めた。
- **確かめていないこと:** 実際の Tauri のウィンドウ (WebKitGTK など。文字の幅が違う)。1024px より狭い幅 (さらに折り返して 3 行になる
  はず)。エラーや知らせ・取り込みの警告が出ているときの長い行 (`nav` の中で折り返し、省略される)。
- **範囲外の変更:** なし (apps/editor・docs だけ)。
- **後続の候補:** ボタンが今後も増えるなら、ファイル操作を「File」のドロップダウンにまとめる (1 行に収まる)。
