# T0727: ビューアの CSP を決め、コマンドが読み書きできるパスを絞る

## 目的

コードレビュー (T0724) で、ビューアの webview を守るものが薄いことが分かった。

- `apps/viewer/src-tauri/tauri.conf.json` の `app.security.csp` が `null` (CSP なし)。
- アプリのコマンド (`read_model_file`・`write_json_file`・`write_png_file`・`initial_file`) は、権限 (capabilities) で絞っていない
  (`build.rs` で `AppManifest` を使っていないので、どのウィンドウからも呼べる)。
- `read_model_file` は拡張子が `.ugoe`・`.json`・`.ugoemod` ならどのパスでも読み、`write_json_file` は `.json` ならどのパスにも書く。
  webview で任意のスクリプトが動けば、利用者のホームの `.json` (ほかのアプリの設定など) を読み・上書きできる。

いまは同梱のページだけを読み、`{@html}` も使っていないので、すぐに突ける穴は見つけていない。エディタ (T0685・T0686) と
スタジオ (T0819・T0820) の同じ形の所見と揃えて、守りを足す。

## 受け入れ条件

- [x] `csp` を決める (wasm・WebGPU/WebGL・MediaPipe の wasm とモデル・`blob:`・同梱の `samples/` が動くもの。
  `'wasm-unsafe-eval'` など要るものを README に書く)
- [x] アプリのコマンドを権限で許すものにする (`tauri_build::Attributes::app_manifest` と capabilities の `allow-*`)
- [x] 書き込み (`write_json_file`・`write_png_file`) は、保存のダイアログで選んだパスだけを受ける
  (ダイアログをバックエンドで開く、またはバックエンドが選んだパスを覚えて照らし合わせる)。
  読み込みは、ダイアログ・ドロップ・起動時の引数・覚えた場所 (`path:`) で来るパスに限るかを決め、決めたことを README に書く
- [ ] フェイストラッキング (カメラ)・画像の保存・ドロップ・見本・ライセンスの画面が、手で確かめて動く
- [x] `just ci` が通る

## メモ

- T0008: 3 つのアプリに同じ所見がある (同期のコマンド: T0685・T0726・T0819、CSP とコマンドの許可: T0686・T0727・T0820、一時ファイル経由の保存: T0687・T0728)。
  先に終えたタスクの形 (非同期にする関数・CSP の中身・一時ファイルの書き方) に後のタスクが揃える (docs/workflow/code-review.md#m9-の結果)。
- T0727 (やったこと。**エディタ T0686・スタジオ T0820 はこの形に揃える**。詳しくは apps/viewer/README.md の「CSP とコマンドの許可」):
  - **CSP** (`tauri.conf.json` の `app.security.csp`。オブジェクトの形で書く):
    `default-src 'self'`・`script-src 'self' 'wasm-unsafe-eval'`・`style-src 'self' 'unsafe-inline'`・`img-src 'self' data: blob:`・
    `media-src 'self' blob:`・`connect-src 'self' ipc: http://ipc.localhost`・`object-src 'none'`・`base-uri 'self'`・
    `form-action 'none'`・`frame-ancestors 'none'`。合わせて `"dangerousDisableAssetCspModification": ["style-src"]`。
    - wasm (ugoe-wasm・MediaPipe) に要るのは `'wasm-unsafe-eval'` だけ (`'unsafe-eval'` は要らない)。WebGPU・WebGL2 は指示が要らない。
      MediaPipe のローダーは同じ場所の `<script>` なので `'self'` で足りる。
    - Tauri は style-src に nonce/hash を足し、そうなると `'unsafe-inline'` が無視されて Svelte の `style` 属性が止まるので、
      style-src だけ書き換えを止める。script-src は書き換えさせる (`index.html` のインラインのスクリプトの sha256 を Tauri が足す)。
    - `connect-src` の `ipc:` と `http://ipc.localhost` は Tauri の IPC (前者が Linux・macOS、後者が Windows)。Tauri は自動では足さない。
    - デスクトップの開発 (devUrl) では CSP が掛からない (Tauri は自分のプロトコルで配るページにだけ付ける。tauri 2.12 の `manager/mod.rs` の `get_asset`)。
      確かめるときは `cargo build -p ugoe-viewer --features tauri/custom-protocol` (dist を埋め込む) の実行ファイルで。
    - エディタ・スタジオで足すものの見込み: エディタは `asset:` などを使っていれば img-src/connect-src に、スタジオの出力ウィンドウ
      (OBS のブラウザソースなど外から読むもの) は別の CSP が要るかもしれない (各タスクで確かめる)。
  - **コマンドの許可:** `build.rs` で `tauri_build::try_build(Attributes::new().app_manifest(AppManifest::new().commands(COMMANDS)))`、
    `capabilities/default.json` に `allow-<コマンド名 (_ を - に)>` を並べる。生成される `src-tauri/permissions/autogenerated/` は
    ルートの `.gitignore` に足した (`crates:` の外だが 1 行。エディタ・スタジオも同じ行を足す)。
  - **パスの範囲:** ファイルのダイアログをバックエンドで開く (`open_file_dialog`・`save_file_dialog`。文言とフィルタは引数で受ける。
    tauri-plugin-dialog の Rust の `blocking_*` を `spawn_blocking` の中で呼ぶ)。webview には `dialog:*` の権限を渡さず、
    npm の `@tauri-apps/plugin-dialog` の依存を外した。`lib.rs` の `FileAccess` が、書けるパス (保存のダイアログで選んだもの、1 回だけ) と
    読めるパス (開くダイアログ・ドロップ (`on_webview_event` の `DragDrop::Drop`)・起動時の引数) を覚える。読めるパスは覚えた場所 (`path:`) から
    次の起動でも読み直せるよう、アプリのデータのディレクトリの `readable-files.json` に新しいものから 1000 件覚える
    (webview の localStorage の一覧は信じない)。拡張子が無いときに付けるのはバックエンドに移した (`with_extension`)。
  - テスト: Rust (読めるパス・覚えて読み直す・古いものを忘れる・書けるのは 1 回・拡張子)、`host.test.ts` (ダイアログのコマンドを通す)。
  - 手で確かめたこと (WSL2 の WSLg):
    - 本物のビューア (WebKitGTK 2.52、`--features tauri/custom-protocol`) を見本を引数にして起動し、WebKit の検査器
      (`WEBKIT_INSPECTOR_HTTP_SERVER`) から操作した: 起動時の引数のモデルの読み込み (wasm・WebGL2)・ライセンスの画面・
      「サンプル」→「着せ替え」(モジュール 4 つ)・フェイストラッキングの「開始」で MediaPipe の顔と体のグラフが動くこと
      (カメラは WSL に無く「Invalid constraint」で開けない)。CSP の違反は無し。外への `fetch` は connect-src で止まり、
      選んでいないファイルの `read_model_file`・`write_json_file` と `plugin:dialog|open` は拒まれた。`readable-files.json` に起動時の引数のパスが入った。
    - ビルドした dist を同じ CSP のヘッダー付きで配り、ヘッドレスの Chrome (偽のカメラ) で: 見本・着せ替え・ライセンス・画像を保存
      (ブラウザの経路)・カメラでのトラッキング (MediaPipe で検出が動く) が CSP の違反なしに動いた。
  - 確かめていないこと (受け入れ条件の「手で確かめて動く」を付けていない理由): 本物のアプリでの OS のダイアログでの開く・保存
    (画像の保存・記録の保存)・OS からのドロップ・実物のカメラ (WSL では操作する手段とカメラが無い)。Windows (WebView2・`http://ipc.localhost`)
    と macOS (WKWebView) の実機。
