# T1638: エディタ: パーツ・デフォーマの行のホバーでも輪郭を出し、畳んだ祖先にビューポートのホバーの印を出す

## 目的

T0674 で、ツリーとビューポートのホバーを共有した (ツリーのメッシュの行に乗るとビューポートに破線の輪郭、ビューポートでメッシュに乗るとその行に hover の地)。
残ったもの (T0674 の候補):

- パーツ・デフォーマの行に乗っても、ビューポートに何も出ない (メッシュの行だけ)。
- ビューポートで乗ったメッシュの行が、畳んだ祖先の下にあると、ツリーに何も出ない (見えている行だけ)。

## 受け入れ条件

- [x] パーツ・デフォーマの行に乗ると、その中のメッシュ (子孫) の輪郭をビューポートに出す (メッシュの行と同じ見せ方。数が多いときの扱いをメモに書く)
- [x] ビューポートで乗ったメッシュの行が畳んだ祖先の下にあるとき、いちばん近い見えている祖先の行に印を出す (hover の地か印。見せ方をメモに書く)
- [x] 単体テスト (子孫のメッシュを集める・見えている祖先を探す) と部品のテスト (`ToolOverlay.test.ts`・`TreePanel.test.ts`) がある
- [x] docs/editor.md (選択とホバーの見せ方)・docs/ui.md を直し、画面が変わったところを T0919 のメモに書き足した
- [x] `just ci` が通る

## メモ

- T0041 で起票した (元の候補: T0674 (パーツ・デフォーマの行のホバー)・T0674 (畳んだ祖先の印))。

- **やったこと:**
  - パーツ・デフォーマの行のホバー: `panels/tree/build.ts` に `meshesWithin` (パーツは子孫のパーツを含めて属するメッシュ、デフォーマは子孫の
    デフォーマを含めて親に持つメッシュ。表示の種類に依らず、手前から奥へ。循環しても止まる)。`ToolOverlay` は `Selection.hover` の中のメッシュの
    輪郭を、メッシュの行と同じ `--viewport-edit` の 1px の破線で描く (選んでいるメッシュは除く)。
  - **数が多いとき:** 数で打ち切らず、すべての輪郭を 1 本のパス (本体の要素は別の 1 本) にまとめる (要素の数が増えない)。境界の辺は三角形の列ごとに
    `WeakMap` で覚え、ポインタの移動・再生のたびに数え直さない (描くたびの仕事は境界の頂点を辿って文字列にするだけ)。
  - 畳んだ祖先の印: `nearestVisible` (見えていればその行、畳んだ祖先の下ならいちばん近い見えている祖先)。`TreePanel` がその行に `hoveredWithin` を
    渡し、`TreeItem` は **hover の地の重ねと左端の強調色の縦線 (inset 3px)** を付ける (行そのものの hover と見分ける)。祖先は開かない
    (ポインタの移動でツリーが開いて行がずれないように。選べば今までどおり開く)。
  - テスト: build.test.ts (`meshesWithin`・循環・`nearestVisible`)、ToolOverlay.test.ts (パーツ・デフォーマの行のホバーで 1 本のパスに 2 つ / 1 つの
    輪郭、選んだメッシュを除く、中にメッシュの無いデフォーマ)、TreePanel.test.ts (畳んだ祖先の印が畳むたびに外側の行へ移る・パーツの行のホバーの共有)。
  - 文書: docs/editor.md#選択とホバーの見せ方 (表と説明)、docs/ui.md#エディタのパネル-t0674、docs/manual/screen.md、T0919 のメモ。
