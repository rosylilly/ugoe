# T1638: エディタ: パーツ・デフォーマの行のホバーでも輪郭を出し、畳んだ祖先にビューポートのホバーの印を出す

## 目的

T0674 で、ツリーとビューポートのホバーを共有した (ツリーのメッシュの行に乗るとビューポートに破線の輪郭、ビューポートでメッシュに乗るとその行に hover の地)。
残ったもの (T0674 の候補):

- パーツ・デフォーマの行に乗っても、ビューポートに何も出ない (メッシュの行だけ)。
- ビューポートで乗ったメッシュの行が、畳んだ祖先の下にあると、ツリーに何も出ない (見えている行だけ)。

## 受け入れ条件

- [ ] パーツ・デフォーマの行に乗ると、その中のメッシュ (子孫) の輪郭をビューポートに出す (メッシュの行と同じ見せ方。数が多いときの扱いをメモに書く)
- [ ] ビューポートで乗ったメッシュの行が畳んだ祖先の下にあるとき、いちばん近い見えている祖先の行に印を出す (hover の地か印。見せ方をメモに書く)
- [ ] 単体テスト (子孫のメッシュを集める・見えている祖先を探す) と部品のテスト (`ToolOverlay.test.ts`・`TreePanel.test.ts`) がある
- [ ] docs/editor.md (選択とホバーの見せ方)・docs/ui.md を直し、画面が変わったところを T0919 のメモに書き足した
- [ ] `just ci` が通る
