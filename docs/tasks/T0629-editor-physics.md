# T0629: エディタ: 物理の設定画面

## 目的

エディタで物理 (パラメータへの出力と動的物理) を設定し、その場で揺れを確かめられるようにする。

## 受け入れ条件

- [ ] 物理の設定を編集する `Command` (設定の追加・削除、入力・出力・粒子・係数の変更、衝突体の追加・削除・編集、重力の基準) と、検証・Undo のテスト
- [ ] 物理の設定のパネル: 入力と出力 (パラメータ・デフォーマの角度・オフセット・頂点)、粒子の鎖、係数、衝突体 (円・カプセル) の一覧と編集
- [ ] ビューポートで粒子と衝突体を表示し、衝突体をドラッグで動かせる
- [ ] 再生中の物理のプレビュー (パラメータや頭を動かすと揺れる)。止めると編集中の姿に戻る
- [ ] 操作マニュアルに物理の章を足す
- [ ] `just ci`・`just gen` (差分なし)・エディタのビルドが通る
