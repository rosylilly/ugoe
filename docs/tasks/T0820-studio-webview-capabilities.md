# T0820: スタジオ: WebView の CSP とウィンドウごとのコマンドの許可を絞る

## 目的

T0814 のレビューで見つけた (多層の防御)。スタジオの `tauri.conf.json` は `app.security.csp` が `null` で、アプリのコマンド
(`build.rs` の `tauri_build::build()`) はウィンドウを問わずすべて呼べる。出力ウィンドウ (受け手だけ) からも `api_token`・
`regenerate_api_token`・`approve_api_client`・`open_profile` などを呼べてしまう。ページは同梱したものだけで、外部 API の
クライアントの名前は Svelte が文字として出すので、今すぐ悪用できる穴ではないが、出力ウィンドウやページに何かを差し込まれたときの
被害を小さくしたい。

## 受け入れ条件

- [x] 操作ウィンドウと出力ウィンドウに CSP を付ける (wasm・blob の画像・Tauri の IPC が動くこと)
- [x] `tauri_build::Attributes::app_manifest` (`AppManifest::commands`) と capabilities で、出力ウィンドウが呼べるコマンドを受け手に要るもの
      (`subscribe_frames`・`scene_model`・`scene_module`・`scene_background`・`report_render_stats` など) に絞る
- [x] エディタ・ビューアにも同じことが要るかを確かめ、要るなら起票する
- [x] `just ci` が通る (T0006 の e2e を含む)

## 参考

- `apps/studio/src-tauri/tauri.conf.json`・`capabilities/`・`build.rs`
- ADR 0028 の 6.

## メモ

- T0008: 3 つのアプリに同じ所見がある (同期のコマンド: T0685・T0726・T0819、CSP とコマンドの許可: T0686・T0727・T0820、一時ファイル経由の保存: T0687・T0728)。
  先に終えたタスクの形 (非同期にする関数・CSP の中身・一時ファイルの書き方) に後のタスクが揃える (docs/workflow/code-review.md#m9-の結果)。
- T0820 (やったこと):
  - `src-tauri/src/acl.rs` にコマンドの名前 (`COMMANDS`) と出力ウィンドウが呼べるもの (`OUTPUT_COMMANDS`: `subscribe_frames`・
    `scene_model`・`scene_module`・`scene_background`・`report_render_stats`) を置き、`build.rs` が `include!` して
    `AppManifest::commands` に渡す。`capabilities/output.json` は `core:window:allow-start-dragging` と受け手の 5 つだけ
    (`core:default` も外した。Channel のデータの取得は Tauri が ACL の外で扱う)。`control.json` はそれ以外のコマンドのすべて。
    `acl.rs` のテストが `generate_handler!`・`COMMANDS`・capabilities・CSP の要点の一致を検査する。
  - CSP: `default-src 'self'`、`script-src 'self' 'wasm-unsafe-eval'`、`style-src 'self' 'unsafe-inline'`
    (`dangerousDisableAssetCspModification: ["style-src"]`。Tauri が hash を足すと Svelte の `style` 属性が止まるため)、
    `img-src`/`media-src` に blob (背景・トラッキングのファイル)・`mediastream:` (カメラ)、`connect-src ipc: http://ipc.localhost 'self'`、
    `worker-src 'self' blob:`、`object-src 'none'`・`base-uri 'self'`・`form-action 'none'`。ビューア (T0727 の w3-T0727) に同じ形を送って相談した
    (返事は完了の時点で届いていない。食い違えばオーケストレーターが揃える)。
  - ビルドが作る `src-tauri/permissions/autogenerated/` は生成物として `apps/studio/.gitignore` に入れた。
  - e2e (`tests/e2e/specs/studio.test.mjs`、`crates:` の外の小さな変更): 出力ウィンドウから `api_token` が `not allowed` で断られることと、
    `new Function` が CSP で止まることを確かめる手順を足した。CSP を `null` に戻すと失敗することも確かめた。
  - `just e2e --only studio` は通った (10 件)。この機械では他のワーカーの Xvfb と番号がぶつかり run.mjs の Xvfb が起動できないことがあり、
    そのときは自分で `Xvfb :157` を立てて `--headed` で流した。
  - エディタ・ビューア: どちらも `csp: null` でコマンドの許可も無い。T0686 (エディタ)・T0727 (ビューア) がすでにあるので起票しない。
- 確かめていないこと: Windows (WebView2) と macOS (WKWebView) での CSP (ヘッダで付く) とカメラ・マイク・MediaPipe の GPU の動作。
  開発の起動 (`just studio`、devUrl) は確かめていない。
- 起票の候補: なし (エディタ・ビューアは既存の T0686・T0727)。
