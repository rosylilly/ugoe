# T0118: 公開仕様: アバタープロファイル (英語)

## 目的

VRM のように、どのアプリでも同じモデルが動くための公開仕様として、アバタープロファイル (標準パラメータ・拡張パラメータ・ARKit との対応・向きの約束・メタデータと利用許諾・準拠レベル) を英語で書く。

## 受け入れ条件

- [x] `spec/avatar-profile.md`: 準拠レベルごとの要件、パラメータの ID と値域と意味、トラッキングとの対応の式、上書きの規則、利用許諾の項目と既定値、`profile_version`
- [x] アプリ (トラッキングのアプリ・ゲーム) の実装者向けの節: 何を読み、何を守るべきか (利用許諾の警告など)
- [x] T0306・T0703 で残った符号の未決 (`MouthX`・`JawX`) を、利用者の確認の結果で解消するか、未決として明記する
- [x] `just ci` が通る

## 参考

- `docs/adr/0012-avatar-profile.md`

## メモ

### やったこと

- `spec/avatar-profile.md` (英語、CC BY 4.0): 概要と用語 (アバター・準拠するモデル・アプリ・検証ツール)、向きと左右の約束、標準・拡張・母音のパラメータの値域と意味、準拠レベル、準拠の検査 (エラーと警告、満たしているレベル)、トラッキングの入力・標準の対応の式・上書き・値を決める手順、音声、視線、当たり判定、スロット、メタデータと利用許諾 (値の意味・既定値・未知の値)、アプリの規則 (読むもの・動かし方・利用許諾の表示と警告・未知のデータ)、バージョン。
- 利用許諾の警告は、実装の項目 (`avatar_permission`・`commercial_usage`・4 つの `allow_*_usage`・`credit_notation`・`allow_redistribution`・`modification`) ごとに「いつ警告するか」の表にした。警告は項目を示して先へ進めるようにし、止めることは求めない。
- `MouthX`・`JawX` の符号: 利用者の実際のカメラでの確認は済んでいない (T0703・T0704 のメモ)。英語版に「Open issue」として、今の式 (`mouthLeft − mouthRight`・`jawLeft − jawRight`)、パラメータの意味は決まっていて式の符号だけが未決であること、逆なら上書き (`scale: -1`) で直せることを書いた。日本語版の未決も同じ内容に更新した。
- `spec/README.md` の文書の表の自分の行、`spec/model.md` の avatar-profile だけを指す「planned」3 か所、`spec/bundle.md` の版の表の 1 か所をリンクにした。`docs/spec/public-spec.md` に対応表の節を足し、「まだ公開仕様にない文書」から自分の行を消した。

### 日本語の docs/spec との食い違いと直したこと (実装を正とした)

- `meta.authors`: 日本語版は「1 人以上」。実装は空白以外の文字を含む要素が 1 つ以上。両方に明記した。
- 値域の警告: 日本語版は「標準・拡張パラメータ」。実装 (`standard::range`) は母音も含む。直した。
- `level` が 3 より大きいとき: 実装はエラーにしたうえでレベル 3 までの必要なパラメータを検査する。明記した。
- 書き込み先が中継用の上書き: 実装 (`TrackingMap::for_model`) は書き込まないが、標準の対応の置き換えは起こす。日本語版に書かれていなかった。両方に書いた。
- 当たり判定の名前: 日本語版は `Head`・`Body` だけのように読めたが、実装はほかの名前をエラーにしない。英語版に「アプリは知らない名前を無視する」と書き、日本語版にも足した。
- 頭の角度は 1 度 = パラメータの 1 であることを両方に明記した。上書きの並びの順が結果に影響しないことも明記した。
- 許諾の値の意味 (`only_licensed`・`personal_profit`・`modification` の各値) が日本語版になかった。実装の doc コメントどおりに足した。
- 日本語版の「ライセンスは MIT」を、公開仕様 (英語・CC BY 4.0) が正である旨に置き換えた (T0116 のメモの引き継ぎ)。
- 日本語版に「アプリの規則」の節を足した (英語版の要約)。

### 実装にない規則として書いたもの (見直しの候補)

- `look_at` の角度からパラメータへの対応: 実装がない (ランタイムは `look_at` を使わない)。日本語版の「端の値になる」を、線形の対応 (0 度で既定値、±range で最大・最小、外はクランプ) として SHOULD で書いた。
- `slots` に無いスロットはアプリが利用者に見せない (SHOULD)。
- 目の開閉のトラッキング中に目パチを止められるようにする (SHOULD。ビューアの既定の挙動に合わせた)。

### 残したこと・後続の候補

- ビューアはまだメタデータと利用許諾を表示・警告しない (T0631 の後続の候補と同じ)。英語版の「Showing the license terms」の最初の実装になる。
