# T0049: ui-audit: 文字ではない部品どうしの重なり (選択欄の矢印が隣の欄の下に隠れるなど) を数える検査を足すか決める

## 目的

`just ui-audit` の `overlap` は文字の重なりだけを数える。T0044 で、エディタのグルーの軸を足す行が狭い列 (`*-zoom200`) で
`Select` の矢印を右の数値の欄の下に隠しているのを画像で見つけたが、監査は出さなかった (`ja-light-zoom200-glue-edit.png`)。
押せる部品 (ボタン・欄・選択欄) どうしの重なりを数える検査を足すかを決め、足すなら実装する。

## 受け入れ条件

- [ ] 足すか足さないかを決め、理由をメモと tests/ui-audit/README.md に書いた (誤検出の多さ・意図した重なり (バッジ・ビューポートの上の道具) の扱い)
- [ ] 足すなら: `tests/ui-audit/lib/page-checks.js` に検査があり、単体テストで「選択欄の矢印 (か選択欄の右端) が隣の欄の下に隠れる」形を見つけ、
      意図して重ねた形 (重ねた側に印のある要素) を数えない
- [ ] 足すなら: T1650 で直す前のコードで `-glue-edit` の `*-zoom200` の指摘が出ることを確かめた。3 つのアプリのほかの指摘をメモに書いた
      (直すタスクは起票の候補にする)
- [ ] `just ui-audit-check` と `just ci` が通る
