# T0707: 見本: 法線マップ付きの見本のアバターと、ビューアのサンプルで試せるようにする

## 目的

利用者の要望 (T0705 の後続の候補)。ライティングを使う見本のモデルがなく、ビューアのライティングのパネルをすぐ試せない。
見本のアバターに法線マップを付けた版を用意し、ビューアの「サンプル」から開けるようにする。

## 受け入れ条件

- [ ] 見本のジェネレータ (`ugoe sample avatar`) で、法線マップ付きの版 (例: `assets/samples/avatar-lit.ugoe`) を作れる。法線マップは T0506 の方法で作り、顔や体が不自然にならないよう、パーツごとの強さ (意味ラベルごとの既定の強さなど) と境目の段差を調整する。既存の見本 (`avatar.ugoe`) の出力は変えない
- [ ] コミットしたファイルと生成の結果が一致することをテストで確かめる。ファイルの大きさを抑える
- [ ] ビューアの「サンプル」で、法線マップ付きの版を選べる (または切り替えられる)
- [ ] 描いた絵を目で確かめ (左・右・上からの光)、メモに画像のパスを書く
- [ ] `just ci`・`just test-gpu`・ビューアのビルドが通る
