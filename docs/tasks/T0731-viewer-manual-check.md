# T0731: ビューアの実機での手動確認 (OS のダイアログ・ドロップ・カメラ)

## 目的

T0727 でビューアに CSP とコマンドの許可を入れたが、自動テスト (e2e) では OS のファイルのダイアログ・ファイルのドロップ・カメラは動かせず、
T0727 の実機の受け入れ条件が未チェックのまま残っている。人が実機 (Linux・Windows・macOS のうち手元にあるもの) で確かめ、見つかった問題をタスクにする。

## 受け入れ条件

- [ ] OS のダイアログでモデル (`.ugoe`) と着せ替えのモジュールを開ける
- [ ] ウィンドウへのファイルのドロップで開ける
- [ ] カメラのトラッキングを始められ、MediaPipe が読み込まれる (CSP で止まらない。開発者ツールのコンソールに違反が無い)
- [ ] スクリーンショットの保存ができる
- [ ] ファイルのダブルクリック (OS の「このアプリで開く」) で `.ugoe`・`.ugoemod` を開ける。起動中に開いたときも (macOS は同じウィンドウ、Windows・Linux は新しいウィンドウ。docs/manual-check.md の V08。T0732)
- [ ] 確かめた OS と結果、見つかった問題 (起票したタスク) をメモに書いた。docs/manual-check.md に項目が無ければ足す (足したらこのチェックを付ける)

## 参考

- T0727 のメモ、docs/manual-check.md

## メモ

- T0019 で起票した (元の候補: T0727 の実機の確認)。利用者 (人) が行うタスク。
- T0032 (3 回目の起票のまとめ) から: T0732 の候補。V08 を Linux で確かめて、ファイルマネージャが `.ugoe` を種類で見分けられず関連付けが効かなければ、
  .deb に MIME の定義 (`/usr/share/mime/packages/ugoe.xml`) を入れるタスクを起票する。Windows・Linux の起動中に開いたときの動き (single-instance) は T0733 で変わる。
- T0038 (5 回目の起票のまとめ) から: T0938・T0475 の確かめていないこと (本物の GPU のリセット・GPU プロセスの不調・コンテキストの上限で、
  「GPU の復元を待っています」と作り直し・「作り直す」ボタンが出て、wasm が panic しないか) を docs/manual-check.md の D09 に足した。
  ビューアで確かめられたら D09 の結果に書く (例: スリープからの復帰・ドライバの更新・GPU を多く使うほかのアプリと並べて起こす)。
