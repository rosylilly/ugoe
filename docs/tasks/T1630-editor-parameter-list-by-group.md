# T1630: エディタ: パラメータの一覧をグループごとに区切り、グループをドラッグで並べ替える

## 目的

T1626 で、エディタにパラメータのグループのコマンドと画面 (パラメータのパネルの下の「Groups (N)」の節。▲▼ で並べ替え) が入った。
ところがエディタのパラメータのパネルの一覧そのものはグループで区切らず (区切るのはプレビューとビューアだけ)、グループの並べ替えは ▲▼ だけ (T1626 の候補とやらなかったこと)。
パネルの見直し (T0674) の後に、一覧の見せ方として揃える。

## 受け入れ条件

- [ ] パラメータのパネルの一覧をグループの順に区切って出す (見出しと、グループの無いパラメータの置き場。プレビュー・ビューアと同じ規則)。部品のテストがある
- [ ] グループの並べ替えをドラッグでもできる (`ReorderParameterGroup` を送る。▲▼ とキーボードの操作も残す)。部品のテストがある
- [ ] 一覧の中でパラメータをドラッグしてグループを変えられるようにするかを決め、するなら `set_parameter_group` を送る (しないなら理由をメモに書く)
- [ ] パラメータ 100 個・グループ 10 個で崩れない (`just ui-audit --only editor` の指摘が増えない)
- [ ] docs/editor.md とマニュアルの候補 (T0919 のメモ) を直した
- [ ] `just ci` が通る
