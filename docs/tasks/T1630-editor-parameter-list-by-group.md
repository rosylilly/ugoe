# T1630: エディタ: パラメータの一覧をグループごとに区切り、グループをドラッグで並べ替える

## 目的

T1626 で、エディタにパラメータのグループのコマンドと画面 (パラメータのパネルの下の「Groups (N)」の節。▲▼ で並べ替え) が入った。
ところがエディタのパラメータのパネルの一覧そのものはグループで区切らず (区切るのはプレビューとビューアだけ)、グループの並べ替えは ▲▼ だけ (T1626 の候補とやらなかったこと)。
パネルの見直し (T0674) の後に、一覧の見せ方として揃える。

## 受け入れ条件

- [x] パラメータのパネルの一覧をグループの順に区切って出す (見出しと、グループの無いパラメータの置き場。プレビュー・ビューアと同じ規則)。部品のテストがある
- [x] グループの並べ替えをドラッグでもできる (`ReorderParameterGroup` を送る。▲▼ とキーボードの操作も残す)。部品のテストがある
- [x] 一覧の中でパラメータをドラッグしてグループを変えられるようにするかを決め、するなら `set_parameter_group` を送る (しないなら理由をメモに書く)
- [x] パラメータ 100 個・グループ 10 個で崩れない (`just ui-audit --only editor` の指摘が増えない)
- [x] docs/editor.md とマニュアルの候補 (T0919 のメモ) を直した
- [x] `just ci` が通る

## メモ

- T0038 で起票した (元の候補: T1626 (一覧の区切り・ドラッグでの並べ替え))。UI の品質に関わるので M10。T0674 (パネルの見直し) と同じパネルを触るので、その後に着手する。
- やったこと (claude-worker-T1630):
  - 一覧の区切り: `ParametersPanel.svelte` の一覧を、プレビューと同じ `preview/preview.ts` の `groupParameters` で区切り、折りたためる見出し
    (`Section`。右に区切りのパラメータの数) で出す。グループの無いもの (と定義に無いグループを指すもの) は最後の「Other」(`parameters.ungrouped`)。
    どのパラメータもグループに入っていなければ見出しを出さずに今までどおり並べる (グループの無いモデルで「Other」だけが出ないように)。
    部品のテストは `ParametersPanel.test.ts` (区切りの順・空のグループ・定義に無いグループ・見出しの数・見出しを出さない場合)。
  - ドラッグの並べ替え: `ParameterGroups.svelte` の行をポインタでドラッグして `reorder_parameter_group` を 1 つ送る (ポーズの要素の
    並べ替えと同じ作り。5px で始まり、落とす先を強調色の線で示し、自分の前後には出さない。Esc・ポインタの取り消しでは送らない。▲▼ と
    名前の編集欄の上からは始めない。モジュールのプロジェクトと送っている間はしない)。キーボードの代わりは ▲▼ のまま残し、名前のボタンで
    Alt + ↑ / ↓ でも動かす (`aria-keyshortcuts`。動かした行の名前にフォーカスを戻す)。節の中に「ドラッグか ▲▼、Alt + ↑↓、Esc で取り消し」の
    案内 (`parameters.groups.dragHint`)。落とす先の計算は `groups.ts` の `dropIndexAt`・`dropGroupCommand` (Vitest)、部品のテストは
    `ParameterGroups.test.ts` (ドラッグで前・末尾へ、印、動かない所と Esc では送らない、▲▼ からは始めない、Alt + ↑↓)。
  - 一覧の中でパラメータをドラッグしてグループを変えることは **しない** と決めた。行はスライダー・値の欄・キーの印でほぼ埋まり、ポインタの操作
    と重なってつかむ場所が取れない (つかみの印を足すと 100 個の一覧の幅をさらに狭める)。グループを変えるのは編集欄の「Group」(キーボードでも
    使える)。理由は docs/editor.md#パラメータのグループ にも書いた。
  - UI の監査: `tests/ui-audit` に `manyParameters` の状態 (見本のモデルをパラメータ 100 個・グループ 10 個に増やす。`get_model_json` だけを変える)
    と場面 `-many-parameters`・`-many-parameters-groups` を足した (`crates:` の外だが監査の道具の小さな追加。README・`hosts.test.mjs` も)。
    場面を足したコミットの上で、アプリを変える前に `just ui-audit --only editor --out target/ui-audit-before` (291 場面、すべて 0 件) を取り、
    変えた後の `--compare` は `+0 -0 ~0` (すべて 0 件)。撮った画像も見て、見出しと長い名前が崩れないことを確かめた。
  - `just e2e --only editor` は 15 件すべて通った。

    グループの見出し・「Groups」)、T0919 のメモ (撮り直す画像)。グループの説明の文言 (`parameters.groups.description`) を「この一覧・
    プレビュー・ビューア」に直した。
