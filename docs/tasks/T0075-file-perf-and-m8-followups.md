# T0075: M7 の性能の目標の検査と、M8 の「起票していない後続の候補」をタスクにする

## 目的

利用者の依頼 (2026-10-08) で、次をタスクにして着手する。

1. M7 の性能の目標「1 体を 1ms 以内 (中程度の PC、数千頂点) で評価する」(docs/roadmap.md の M7) を、計測の例 (ベンチマーク) と、遅くなったら気づける検査にする。
2. docs/roadmap.md の M8 の「起票していない後続の候補 (要望があれば起票する)」のうち、次のもの:
   - スタジオ: プロファイルがモデルを相対パスでも持てるようにする (人に渡せる見本のため。ADR 0028 の 4. の見直し)
   - スタジオ: シーンの通知にパーツの ID を載せて、着せ替え直後の番号のずれを無くす (T0135)
   - スタジオ: トラッキングが届いたら次の刻みを早める (T0803)
   - スタジオ: macOS の App Nap を止める (依存か unsafe が要るので利用者の判断)
   - スタジオ: 外部 API の承認を OS の通知にも出す (T0805)
   - バインディング: 受け手の口 (`follow`) を Unity と Godot にも出す (T0133〜T0135)
   - UI: 着せ替えの違いの文をコードと引数で返す (T0665)

マニュアルの英訳は対象外 (利用者の依頼に含まれない)。

### やったこと (claude-worker-T0075)

- 各候補について、今のコード・文書・元のタスク (T0133〜T0135・T0665・T0803・T0805・ADR 0028) を読んで残りを確かめた:
  - **性能:** 計測の例は部分 (`compose_timing`・`curve_timing`・`physics_timing`・`id_lookup_timing`) だけで、`Puppet::update` 全体を
    目標の大きさのモデルで測るものと、遅くなったら気づける検査は無い。→ T0190 (計測の例) と T0191 (検査。判断が要る) に分けた。
  - **プロファイルの相対パス:** docs/studio.md#プロファイルの形式 と ADR 0028 の 4. は絶対パスのまま。→ T0852 (判断が要る)。
  - **シーンの通知のパーツの ID:** `stream.rs` の `Scene` に `parameter_ids` はあるがパーツの ID は無い。docs/studio.md に「ずれうる」とある。→ T0853。
  - **刻みを早める:** docs/studio.md#入力 に「していない」とある。→ T0854。
  - **App Nap:** docs/studio.md#刻みの速さと正確さ に「未対応」とあり、コードに `beginActivity` は無い。→ T0855 (判断が要る)。
  - **承認の OS への知らせ:** 通知のプラグインも `request_user_attention` も使っていない。→ T0856 (判断が要る)。
  - **UI: 違いの文:** `ModuleDifference.text`・`DifferenceItem.text` は英語の文のまま。→ T1677。
  - **バインディング: 受け手の口 (`follow`) を Unity と Godot に:** **済んでいる**ので起票しなかった。Godot は T0449
    (`bindings/godot/src/node/sdk.rs` の `follow`)、Unity は T0455 (`Puppet.Follow`)。適合テストの `FOLLOW_BINDINGS` (`tests/conformance/src/main.rs`)
    に c・wasm・wasm-webgpu・unity・godot がすべて入っている。roadmap にはそう書いた。
- App Nap は、objc2-foundation 0.3.2 (ワークスペースの依存に既にある。仮想カメラのクレートが使う。MIT) の `beginActivityWithOptions_reason`
  が安全な関数 (`endActivity` は `unsafe`) であることを、手元の cargo のレジストリのソースで確かめて、案 A (新しいクレートも `unsafe` も要らない) にした。
- docs/roadmap.md: M7 の性能の行に T0190・T0191、M8 に「後続のタスク」の節を作って起票したものを書き、「起票していない後続の候補」には
  マニュアルの英訳だけを残した。docs/studio.md の「後続のタスクで」の 4 か所に ID を書いた (T0852〜T0855)。
- 番号は各帯の空いている番号から: モデル・ランタイム T0190・T0191 (T0189 は T0068 で起票して取り下げた番号なので飛ばした)、
  スタジオ T0852〜T0856、エディタ (T06xx は使い切り) T1677。
- 依存: T0191→T0190 (同じ計測の例)。T0856→T0855 (どちらもスタジオの `src-tauri/Cargo.toml` と Cargo.lock を触りうる。T0856 で案 A を
  選ぶなら要らない)。ほかは触るファイルが別か、docs/studio.md の別の節だけなので付けていない (T0852〜T0855 は lib.rs の別の所を触りうる)。
