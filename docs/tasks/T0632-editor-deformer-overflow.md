# T0632: エディタ: 親デフォーマからのはみ出しの表示と一覧

## 目的

高可動域のリグでは、パラメータを動かすと頂点や子のデフォーマが親のワープの格子の外に出ることが多い。ugoe は範囲外を外挿で追従させるので壊れはしないが、
外挿は格子の中ほど思いどおりに曲がらない。Live2D の実践では「親デフォーマからはみ出した頂点をハイライト」「デフォーマの検証」で確かめている (参考の記事 3)。

## 受け入れ条件

- [ ] 今のパラメータの値で、親のワープの格子 ([0,1]²) の外にある頂点・制御点・回転の原点を求める関数 (editor-core。ランタイムの評価結果を使う) とテスト
- [ ] ビューポートで、はみ出した点を色で示す表示の切り替え
- [ ] 「検証」パネル: すべてのキーフォームのセル (と、軸の端の組み合わせ) を調べ、はみ出す要素・セル・量を一覧にする。押すとその要素とセルへ移動する
- [ ] 操作マニュアル。`just ci`・`just gen`・エディタのビルドが通る
