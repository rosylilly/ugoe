# T0097: アプリのアイコンの出所

## 目的

T0090 の点検で、アプリのアイコン (`apps/*/src-tauri/icons/`) の出所とライセンスの書き付けが見つからなかった。ほかの画像・モデル・PSD は
assets の README の表に出所がある。公開の前に、アイコンも同じように出所とライセンスを記録する。

## 受け入れ条件

- [ ] 3 つのアプリのアイコン (元の絵と、`tauri icon` などで作った大きさ違いのファイル) の出所 (作者・作り方・使った道具) とライセンスを、
      1 か所の表 (例: 各アプリの README か assets の README) に書いた。出所は利用者に確かめる (分からない・再配布できないものがあれば、
      案 (作り直す・差し替える) と推奨をメモに書いて「判断が要る」で止まる)
- [x] 元の絵 (大きさ違いを作り直せる SVG か大きな PNG) がリポジトリにあるか、無ければどこにあるかを書いた
- [x] docs/release.md#自動の検査 の「外部 SDK・ライセンス」の行から表へ辿れる
- [x] `just ci` が通る

## 参考

- docs/release.md#公開の前の点検、assets/fixtures/README.md・assets/samples/README.md (出所の表の書き方)
- T0090 のメモ (起票の候補)

### やったこと (T0097)

- 表は `docs/release.md#アプリのアイコン` (「同梱物のライセンスの表記」の下) に置いた。3 つのアプリを 1 つの表にまとめるため、
  アプリの README ではなく配布物のライセンスを書く文書にした。`#自動の検査` の「外部 SDK・ライセンス」の行と、ビューアの README の
  アイコンの作り直しの手順から、この表へリンクした。
- 調べて分かったこと (git の履歴・タスクファイル):
  - エディタ: `icon.png` (512x512、紫の円に薄紫の波) は最初のコミット `16554161` (T0001) で入った。T0001 のタスクファイルにも
    コミットのメッセージにもアイコンの記述は無く、作者・作り方は分からない。Tauri の雛形の既定のアイコン (Tauri のロゴ) ではない。
  - ビューア: `icon.png` (512x512、青い角丸の四角に白い顔) は T0701 (`b03ca52c`) で入った。T0701 のメモに「アイコンは自作
    (`icon.png` から `pnpm tauri icon`)」とあるだけで、`icon.png` を何で描いたかは書かれていない。PNG にテキストのメタデータも無い。
  - スタジオ: T0801 (`37bcb15a`) でビューアの `icons/` をそのまま写した (`git log --follow` が写しとして辿り、全ファイルがバイトまで同じ)。
  - 3 つとも大きさ違いは `icon.png` から `pnpm tauri icon` で作った形 (Tauri の CLI が出す名前と大きさの組)。元の絵として残っているのは
    512x512 の `icon.png` だけで、SVG や大きな絵はリポジトリに無い。
- 分からないもの (エディタの作者・作り方、ビューアの絵を描いた道具、3 つのライセンス) は推測で埋めず、表に「利用者に確かめる」と書き、
  `docs/release.md#人がすること` に項目を足した (オーケストレーターの指示)。

### やらなかったこと・利用者の判断が要ること

- 受け入れ条件の 1 つめ (作者・ライセンスを書く) は、利用者に確かめるまで満たせないのでチェックしていない。決めることと推奨:
  - エディタのアイコンを誰が作ったか (利用者が自分で描いた・エージェントが作った・どこかから持ってきた)。分からない・再配布できないなら、
    案 (a) 作り直す (エージェントが SVG で描き、SVG をリポジトリに置いて `tauri icon` で大きさ違いを作る)、(b) 今のまま使う。
    **推奨は、出所が分からなければ (a)**。SVG を置けば大きな絵も作り直せる。
  - 3 つのアイコンのライセンス。案 (a) MIT (`assets/` の画像と同じ。文書・Web サイト・MIT の `bindings/` の例でも使える)、
    (b) アプリと同じ GPL-3.0-only。**推奨は (a) MIT** (アイコンはロゴとして MIT の文書やパッケージにも載せたくなるため)。
- アイコンのファイル自体は変えていない。

### 起票の候補

- スタジオに専用のアイコンを作る (今はビューアとまったく同じなので、タスクバー・Dock で見分けられない)。作り直すなら 3 つとも SVG の元の絵を
  リポジトリに置く。
- `apps/studio/src-tauri/tests/fixtures/red-blue.jpg` (T0808 で Chrome で書いた 16x8 の JPEG) も `assets/` の表の外にある。
  テストのために作った絵で問題は無さそうだが、出所の表のどこかに書くなら同じ節に足す。
