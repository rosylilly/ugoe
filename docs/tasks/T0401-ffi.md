# T0401: C ABI とヘッダ生成

## 目的

docs/portability.md#c-abi-ugoe-ffi-の規約 に従い、バンドルの読み込み・パラメータの設定・更新・頂点の取得の C API を作る。

## 受け入れ条件

- [x] cbindgen で `include/ugoe.h` を生成し、CI で最新かどうかを検査する
- [x] C で書いた小さなサンプルがビルドされ、実行できる
- [x] パニックが FFI の境界を越えない
- [x] `just ci` が通る

## 参考

- `docs/portability.md`

## メモ

- 範囲外の変更 (team-lead 承認済み): `justfile` (`ffi-header`・`ffi-check`)、`scripts/ffi.mjs`、`.github/workflows/ci.yml` (cbindgen 0.29.4 を入れて `just ffi-check`)、`docs/portability.md`・`docs/testing.md` への追記。
  理由: cbindgen は MPL-2.0 で、MIT のクレートの依存 (build・dev を含む) に入れられないため、ワークスペースの外の CLI として版を固定して使う。生成・検査と C の見本の実行にはタスクランナーと CI の変更が要る。
- `just ffi-check` は cbindgen と C コンパイラが要るので `just ci` に含めない (README・docs/testing.md に記載)。未導入や版違いでは入れ方を案内して止まる。ヘッダには cbindgen の版を書かない (版は scripts/ffi.mjs で固定・確認)。
- API の範囲: バンドル・JSON の読み込み、キャンバス、パラメータ (数・ID・番号の検索・範囲・取得・設定)、update、描画可能要素 (静的情報・状態・変更フラグ・マスク・頂点のコピーと借用・UV・インデックス・描画順)、テクスチャのエンコード済みバイト列、名前つきのモーションと表情、リップシンクの音量。`ABI_VERSION` を 1 にした。
- テクスチャのデコードはホストに任せた (PNG のデコーダを FFI に持ち込まない)。
- 後続の候補: 着せ替え (`.ugoemod` の読み込みと付け外し)、ライティング (法線マップと光源)、当たり判定、トラッキング入力、読み込みの警告、パラメータの ID での一括設定、表情の解除。Windows・macOS での C の見本のビルドは確かめていない (CI は Linux だけ)。
- 確認: `just ci`・`just wasm-check`・`just ffi-check`・`cargo clippy -p ugoe-ffi --target wasm32-unknown-unknown` が通る (main 2738b5e+ に rebase 後)。ヘッダは C++ (`c++ -std=c++17`) でもコンパイルできる。
