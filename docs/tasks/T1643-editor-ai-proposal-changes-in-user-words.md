# T1643: エディタ: AI の提案の「採用で変わるもの」を、コマンドの種類名でなく利用者の言葉 (「パラメータを足す × 5」) で出す

## 目的

T0676 で AI の提案のカードを見直したが、「採用で変わるもの」はコマンドの種類の名前のまま出ている。種類ごとの訳 (「パラメータを足す × 5」
「キーフォームを置く × 12」など) にして、採用する前に何が変わるかを読めるようにする (T0676 の候補)。

## 受け入れ条件

- [ ] エディタの翻訳のカタログに、提案に出るコマンドの種類ごとの名前 (英語・日本語。数を取る形) を足し、カードの「採用で変わるもの」がそれを使う
- [ ] カタログに無い種類が来たときの出し方 (例 種類名のまま) を決め、テストがある
- [ ] 部品か表示のテスト (種類ごとの数をまとめた文)。`just ui-audit --only editor` の AI の場面の指摘が増えない
- [ ] docs/editor.md (AI の提案のカード) を直し、マニュアルの画像を撮り直すか、マニュアルの更新の候補をメモに書いた
- [ ] `just e2e --only editor` と `just ci` が通る
