# T0800: スタジオ: ADR と設計書 (範囲・ウィンドウ構成・入力・外部 API の安全性・ライセンス)

## 目的

配信で使う新しいデスクトップアプリ「スタジオ」(apps/studio) の範囲と構成を決める。実装の前に、ビューアとの違いと、外から操作する API の安全性を決めておく。

## 受け入れ条件

- [ ] ADR 0028 (スタジオ): 目的、ビューアとの役割分担 (ビューアは確認用で軽いまま、配信の機能はスタジオに入れる)、ライセンス (GPL-3.0-only)、
      ウィンドウの構成 (操作ウィンドウと、モデルだけを描く出力ウィンドウ)、入力 (カメラ・マイク・ホットキー)、シーンとプロファイル、
      外部 API (ループバックだけ・トークン・利用者の許可)、M8 でやらないこと (仮想カメラ・OBS のブラウザソース・複数人のコラボなど)
- [ ] docs/studio.md: 画面と操作の設計 (操作ウィンドウのパネル構成、出力ウィンドウの設定、シーンの切り替え、ホットキー、API の一覧の骨子)
- [ ] docs/architecture.md と AGENTS.md のリポジトリ構成に apps/studio を書く
- [ ] `just ci` が通る
