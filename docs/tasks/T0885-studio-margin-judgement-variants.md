# T0885: 促しの余裕の見直しの判定を比べる

## 目的

T0883 で、`adjust_margin` は値が `MARGIN_MIN_VALUES` (10) 個そろうまで区切りを延ばし、増やすのを「遅れた値が 5% を超え、かつ 2 個以上」にした。
2 個を求めない (延ばすだけの) 形は、e2e に近い計算機の形の遅れた値の割合をもっと下げる (中央値 約 12% → 約 6%) が、落ち着いた計算機の形でも
届くまでの時間の揺れ (0〜8 ms) で見込みのうちの 1 個がわずかに遅れて余裕が動き、数が変わる。両方を満たす判定があるかを仮の時刻のテストで比べる。

## 受け入れ条件

- [x] 少なくとも次の形を `late_values_spread_over_phases` (と値の多い形・`few_values_from_slow_detection_are_rarely_late` などほかの仮の時刻のテスト) で比べ、
      T0883 のメモと同じ表 (最小 / 中央値 / 最大、全体の割合) をメモに書いた:
  - 区切りの値の数を 20 個にし、2 個を求めない
  - 遅れの判定 (`expected`) に、届くまでの時間の揺れの分の幅 (例: 数 ms) を持たせ、2 個を求めない
  - 今の形 (10 個 + 2 個以上)
- [x] 落ち着いた形の数が今と同じか良く、e2e に近い形が今より良い形があれば採用し、テストの上限を直した。無ければ今の形のままにし、比べた結果だけをメモと docs/studio.md#刻みの速さと正確さ に書いた
- [x] 採用したなら、先に失敗するテスト (e2e に近い形の上限を下げたもの) を書いてから直した。刻みのたびの確保を増やしていない
- [x] `just e2e --only studio` が通る
- [x] `just ci` が通る
