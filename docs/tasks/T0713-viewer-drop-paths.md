# T0713: ビューア: ドロップしたファイルのパスを受け取る

## 目的

T0711 の後続の候補。ドロップしたモデルやモジュールは場所が分からないので、付けていた組を戻せるのはアプリを開いている間だけになっている。
Tauri のウィンドウではドロップしたファイルのパスを受け取れるので、`path:` の場所として覚え、起動し直した後も戻せるようにする。

## 受け入れ条件

- [ ] Tauri 版では、ドロップしたファイルのパスを受け取り、`ModelFile.location` (`path:`) に入れる。ブラウザ版は今のまま
- [ ] モデルとモジュールのどちらのドロップでも、覚えた組を起動し直した後に戻せる
- [ ] Vitest。Tauri のウィンドウでの確認は利用者の確認に残してよい (その旨を書く)
- [ ] `just ci`・ビューアのビルドが通る
