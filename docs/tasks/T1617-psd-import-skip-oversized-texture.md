# T1617: PSD の取り込みで、上限を超える画像のレイヤーを飛ばして警告し、取り込み全体を失敗させない

## 目的

T0560 で、テクスチャの追加・差し替えのコマンドが、一辺が上限 (既定 16384) を超える PNG を `edit.texture_too_large` で拒むようになった。
その結果、PSD の取り込みで上限を超えるレイヤーが 1 枚でもあると、取り込み全体が失敗するようになった (以前は取り込めて、ビューポートで表示できないだけだった)。

T0554 では、メッシュが大きすぎるレイヤー (`TooLarge`) は警告 `psd.layer_too_large` を出してそのレイヤーだけを飛ばす、と決めている。
画像が大きすぎるレイヤーも同じ扱いにして、1 枚のために取り込み全体を失わないようにする (利用者の方針: 上限で使える範囲を狭めず、可用性を下げない)。

## 受け入れ条件

- [ ] PSD の取り込み (新規と既存のプロジェクトへの取り込み、AI の提案で PSD を読む経路) で、上限を超える画像のレイヤーは取り込まず、警告 (`psd.layer_too_large` を使うか新しいコードか決める) を出して、ほかのレイヤーは取り込む
- [ ] 飛ばしたレイヤーの名前と大きさと上限が警告の引数で分かり、エディタの画面に日英で出る
- [ ] 飛ばす代わりに縮小して取り込む案も検討し、選んだ理由を docs/editor.md の取り込みの規則の表に書いた
- [ ] 上限を超えるレイヤーを含む PSD で、取り込み全体が失敗せず、警告が出て、ほかのレイヤーが取り込まれるテストがある (大きな画素を確保しない形で)
- [ ] `just ci` が通る
