# T1653: エディタ: ] [ で選んだ点を見せるパンの判定に、上の帯と右下の道具を入れる (見える矩形で判定する)

## 目的

T1647 で `]` `[` で選んだ点がビューの外にあるとき見える所までパンするようにした (`revealPanOf`。端から 48px の余白)。
余白はビューポートの全体の矩形から測り、左上の道具の並びと説明の帯 (`.strip`)・右下の拡大の道具の高さを見ていない。帯が高いと、
上の端の点が帯の下に隠れたままになる (T1647)。

## 受け入れ条件

- [ ] 判定とパンの量を、ビューポートで実際に見える矩形 (上の帯と右下の道具を除いた範囲。大きさが変わったら測り直す) で求める
- [ ] 純粋な関数のテスト: 見える矩形の内側では動かさない・帯の下に入る点は帯の下の端から余白の所まで動かす・見える矩形が余白の 2 倍より狭い軸は真ん中へ
- [ ] 部品のテスト: 帯の高さを持たせた ToolOverlay (か ViewportController) で、帯の下の点を `]` で選ぶと表示が動く
- [ ] docs/editor.md の「選んだ点を見える所へ」を直した
- [ ] `just e2e --only editor` と `just ci` が通る
