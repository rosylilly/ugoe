# T0608: エディタ: パラメータとキーフォームの編集

## 目的

パラメータを作り、要素 (メッシュ・デフォーマ・パーツ) にキーを追加し、各キーの上で形を編集できるようにする。Live2D のリギング作業の中心となる操作。

## 受け入れ条件

- [ ] パラメータの作成・削除・範囲の変更を UI から行える
- [ ] 選択した要素に、パラメータのキー (例: -30 / 0 / 30) を追加・削除する `Command` がある。キーを追加すると、既存のセルから補間した形で新しいセルを埋める (見た目が変わらない)
- [ ] 現在のパラメータ値がすべての軸でキーの上にあるとき、ビューポートでの編集 (頂点の移動など) がそのセルに書き込まれる。キーの上にないときは編集を拒否し、最も近いキーへ移動する操作を出す
- [ ] 右パネルに、選択した要素のキーの格子 (どのセルがあるか) を表示する
- [ ] コマンドにテストがある
- [ ] `just ci` が通る
