# T0712: 見本: 着せ替えの見本のプロジェクトとアバタープロファイル

## 目的

T0710 の後続の候補。着せ替えの見本 (`ugoe sample dress-up`) は `.ugoe` と `.ugoemod` だけで、エディタでモジュールのプロジェクトの見本として開けない。
また見本の本体はアバタープロファイルを名乗っておらず、スロットの「アプリに見せる」の見本にならない。

## 受け入れ条件

- [ ] `ugoe sample dress-up` に、本体の `.ugoeproj` と、それを参照するモジュールのプロジェクトを出力する形を足す (`--project` など)。出力したプロジェクトをエディタの中核 (`ugoe-editor-core`) で開けることをテストで確かめる
- [ ] 見本の本体にアバタープロファイルを持たせる (準拠レベルの検査を通す)。既存の見本の出力を変えるなら、コミットしたファイルを作り直して理由をメモに書く
- [ ] マニュアル (`docs/manual/dress-up.md`) から見本のプロジェクトに触れる
- [ ] `just ci` が通る
