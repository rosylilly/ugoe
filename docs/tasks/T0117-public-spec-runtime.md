- `spec/rendering.md`: 色の扱い (sRGB のまま・乗算済み)、テクスチャ (乗算の丸め・バイリニア・端でクランプ・ミップなし)、メッシュの色の式、合成モード、マスク (カバレッジ・入れ子・集合としての P/N・係数)、裏面カリング、ライティング (光源・法線の符号化・ヤコビ行列の回転成分での回転・陰影)、画素の許容。統合・アトラス・転送の省略は Implementation notes (informative)。

- `spec/motion.md`: カーブ (ベジェの解き方の要件)、モーションの再生 (2 つの時計・終了時刻・イベントの範囲・フェード)、複数のモーション (優先度は SHOULD)、エフェクトグループ、表情、目パチ (SplitMix64 の手順)、呼吸、リップシンク、ポーズ、パーツの不透明度、フレーム内の順序、許容。

### 互換の基準 (決めた値)

- 評価: 頂点の位置 0.01px、不透明度・色・mask_strength 1e-4、draw_order 1e-3、visible と描画順は一致 (境目は問わない)。
- 描画: 8 ビットで 99% 以上の画素がすべてのチャンネルで 3/255 以内。
- 物理: パラメータは値域の 1e-3、角度の加算量 0.05 度、位置の加算量 0.05px (ステップ数が曖昧にならない dt の列)。
- モーション: パラメータは `1e-4 × max(1, 値域)`、パーツの不透明度 1e-4。目パチの乱数は正確に一致。

### 実装と docs/spec の食い違い (実装を正として日本語版を直したもの)

- `evaluation.md`: 曲線の軸での `W` の並びが「キーの昇順」と書かれていたが、実装は要素ごとに最大 3 つをまとめて末尾に追加する。直した。パーツの上書きの重みを 0〜1 にクランプすること、パーツ・デフォーマ・メッシュの不透明度と色・グルーの `intensity` はクランプしないことを足した。互換の基準の節を足した。
- `rendering.md`: 乗算済みへの変換の丸め、テクスチャの読み方 (バイリニア・クランプ・ミップなし)、不透明度をクランプしないこと、同じマスク用メッシュの三角形が重なるときのカバレッジ、P/N が集合であること (実装の詳細の節にしか無かった) を足した。互換の基準の節を足した。
- `physics.md`: 出力の重み `weight/100` を 0〜1 にクランプすること (入力はしない)、入力の正規化の割合を 1 で頭打ちにすること、力が 0 の区間の静止姿勢の向きを足した。互換の基準の節を足した。
- `motion.md`: 最初が `start` でない・途中に `start` があるカーブは全体を無視すること、カーブ個別の `fade_out` でも終了時刻はモーションのものを使うこと、同じ時刻のイベントの順を足した。互換の基準の節を足した。
