# T0650: エディタ: モジュールのプロジェクトの使い勝手

## 目的

T0648 の後続の候補をまとめる。モジュールのプロジェクトを便利に使えるようにする。

## 受け入れ条件

- [ ] モジュールの名前・要件 (`requires`)・スロットを後から変える画面
- [ ] インスペクタで本体の要素・本体のもの (アバタープロファイル・パラメータなど) の欄を無効にし、「本体のプロジェクトで直す」と示す
- [ ] 本体が変わった (開いた後に本体のファイルが更新された・モジュールの要素が合わなくなった) ことに気づき、読み直すか尋ねる
- [ ] モジュールのプロジェクトのプレビューの着せ替えのパネル (T0649) で、このモジュールが使っているスロットに別のモジュールを付けられないようにする
- [ ] 本体の要素をビューポートでも見分けられるようにする (ツリーは T0648 で済み)。本体の要素を編集しようとしたときの言葉を「本体の要素はここでは編集できません。本体のプロジェクトで直してください」の形に。ID の接頭辞 (合成で付くもの) をインスペクタやテクスチャの名前でも隠す
- [ ] モジュールで使える機能・使えない機能 (パラメータを足す AI の提案など) を画面に示す (新規作成のダイアログ・`Module:` の印のツールチップ)
- [ ] 本体に関わるすべてのエラー (本体が無い・スロットが無い・本体が変わって合成できない) で「Locate base…」などの直し方を出す。読み取り専用で開く形も検討する
- [ ] ヘッドレスのブラウザで確かめる。マニュアルを更新する。`just ci`・`just gen`・`cargo check -p ugoe-editor` が通る
