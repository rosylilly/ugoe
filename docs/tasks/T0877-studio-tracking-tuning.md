# T0877: スタジオ: トラッキングの調整 (首振りの感度・瞼と口の開きの境目)

## 目的

今のスタジオのトラッキングの調整は、キャリブレーション (中立の顔を差し引く。packages/face-tracking/src/calibration.ts) と平滑化だけで、
利用者の顔・カメラ・部屋に合わせて効き方を変える口が無い。たとえば次のことができない。

- 首を少し振っただけでキャラクターの首を大きく振らせる (感度)。中立の近くの揺れを止める (遊び)。
- 細目の人が瞼を完全に開いた・閉じたと見なされるようにする (瞼の閉じの値がどこからどこまでで 0〜1 になるか)。
- 口を少し開けただけで口を大きく開けさせる、または少しの開きを無視する (口の開きの境目)。

モデルの `avatar.tracking` の係数とオフセット (docs/spec/avatar-profile.md#トラッキングの対応の上書き) は、モデルを作る人が決めるもので、配信者が自分の顔に合わせる口ではない。
配信者の側の調整を、キャリブレーションと同じくアプリ (トラッキングの入力を作る側) の責務として足す (docs/spec/avatar-profile.md#実装の範囲)。

## 決まっていること (利用者、2026-10-10)

- **範囲:** まず首振り・瞼・口の開きの 3 つ。ほかの入力 (眉・視線・口の形など) に後で広げられる形にする。
- **保存先:** プロファイルの `input` (平滑化やマイクの感度と同じ。配信者に付く値で、アバターごとには分けない)。

## 作るもの (案。細部は作業者が決めて理由をメモに書く)

- **調整の関数 (packages/face-tracking):** キャリブレーションの後・平滑化の前に、`TrackingFrame` に当てる純粋な関数 (例: `applyTuning(frame, tuning)`)。
  - 頭のヨー・ピッチ・ロール: 軸ごとに感度 (倍率) と遊び (中立のまわりの角度。遊びの中は 0、外は遊びの分を引いて続けてつなぐ)。
  - 瞼 (`eyeBlinkLeft`・`eyeBlinkRight`): 「開いた」と「閉じた」の境目の 2 つの値で、その間を 0〜1 に引き伸ばす (外はクランプ)。左右を一緒に動かすか、別々にできるか。
  - 口の開き (`jawOpen`。`MouthOpenY` = `max(0, jawOpen − mouthClose)` の元): 同じく 2 つの境目。
  - 既定値は今の振る舞いと同じ (倍率 1・遊び 0・境目 0 と 1) で、既定のままなら出力が今とビット単位で同じ。NaN・無限大・範囲の外・下の境目 ≥ 上の境目は、読み込みと UI の両方で弾くか直す
    (AGENTS.md の「NaN と無限大」)。
  - 体 (`body`) と他のブレンドシェイプは変えない。左右の入れ替え (`swapSides`) との順序を決めて書く (利用者から見た左右で調整できるように)。
- **画面 (`TrackingPanel.svelte`):** キャリブレーションの近くに「調整」を足す。各項目の調整と、今の入力の値 (調整の前と後) のメーターを並べ、顔を動かしながら境目を決められるようにする。
  既定に戻すボタン。キャリブレーションの前は、メーターが中立を差し引いていないことが分かるようにする。i18n (日本語・英語)。
- **スタジオ:** プロファイルの `input` に調整を足して読み書きする (apps/studio/src-tauri の `input.rs`・フロントエンド)。知らない項目・壊れた値は既定値に戻して読む (他の `input` の項目と同じ扱い)。
  変えたら自動の保存の対象になる。
- ビューアとエディタでも同じパネルを使っているなら、調整の画面が出てもよい (既定値なら振る舞いは同じ) が、保存はこのタスクではスタジオだけ。ビューアに保存するかはメモに書いて後続の候補にする。
