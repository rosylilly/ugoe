# T1646: エディタ: パラメータの一覧の区切りの開閉を覚え、絞り込みの欄を足す

## 目的

T1630 でエディタのパラメータの一覧をグループで区切ったが、区切りの開閉は開き直すと戻り、100 個のパラメータから探す手段も無い
(T1630 の候補)。よく使うグループだけを開いておけるようにし、ビューア・プレビューのような絞り込みの欄を足す。

## 受け入れ条件

- [ ] 区切りの開閉を覚える。覚える場所 (プロジェクトのエディタの設定か localStorage の `ugoe.editor.*`) を決めてメモに書いた。プロジェクトを開き直しても保たれる
- [ ] パラメータの一覧に絞り込みの欄がある (名前と ID で絞る。絞り込み中は区切りの開閉によらず一致した行を出す。一致が無いときの文)。キーボードで使え、読み上げの名前がある
- [ ] 部品のテスト (開閉を覚える・絞り込み・一致なし)
- [ ] `just ui-audit --only editor` の `-many-parameters` の場面の指摘が増えない。docs/editor.md を直し、マニュアルの更新の候補をメモに書いた
- [ ] `just e2e --only editor` と `just ci` が通る
