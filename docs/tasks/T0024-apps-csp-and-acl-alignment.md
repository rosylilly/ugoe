# T0024: 3 つのアプリの CSP と許可の細部を揃え、ビューアのコマンドの一覧を acl.rs にする

## 目的

エディタ (T0686)・ビューア (T0727)・スタジオ (T0820) が CSP とコマンドの許可を別々に入れたので、細部が揃っていない。

- スタジオは `src-tauri/src/acl.rs` にコマンドの一覧を置き、`build.rs` が `include!` して、`generate_handler!` と capabilities と CSP の要点の
  一致をテストする。ビューアはこの形になっていない (T0727 の候補)。
- スタジオに `frame-ancestors 'none'` が無い。`worker-src`・`font-src`・`mediastream:` は、使っていないアプリでは外すか、3 つで揃える (T0820 の候補)。
- ビルドが作る `src-tauri/permissions/autogenerated/` の gitignore の置き場所がアプリごとに違う。

## 受け入れ条件

- [ ] 3 つのアプリの CSP と capabilities を表にして違いを洗い出し、揃えた (違いを残すものは理由を docs に書いた)
- [ ] ビューアのコマンドの一覧を `src-tauri/src/acl.rs` に置き、`generate_handler!`・`COMMANDS`・capabilities・CSP の一致をテストする (スタジオと同じ形)
- [ ] `autogenerated/` の gitignore を同じ置き場所にした
- [ ] e2e (T0022 の CSP の違反の検査があればそれも) で 3 つのアプリが動く
- [ ] `just ci` が通る
