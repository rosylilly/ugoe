# T0818: スタジオ UI: 設定の流れ (シーン・プロファイル・入力・ホットキー・API) と出力ウィンドウ

## 目的

スタジオを初めて使う人が、モデルを読み込んでシーンを作り、入力とホットキーを割り当て、配信ソフトに取り込むまでの流れを見直す。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [ ] 初回の起動から配信ソフトに取り込むまでの手順を画面でたどり、迷う所・行き止まりを直した (手順をメモに書く)
- [ ] シーン・プロファイル・入力・ホットキー・API の承認のダイアログの配置・ボタンの順・既定のボタンを、エディタ (T0673) と揃えた
- [ ] ホットキーの割り当ての衝突・OS に登録できなかったときの見せ方
- [ ] 出力ウィンドウの枠・ドラッグ (T0813)・透過の状態が、操作ウィンドウから分かる
- [ ] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [ ] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [ ] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [ ] `just ci` が通る
