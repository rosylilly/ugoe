# T0846: スタジオ: 出力ウィンドウの透過が効いているかを調べ、効かない環境で注意を出す

## 目的

スタジオの出力ウィンドウは常に透過で、背景はシーンが決める。T0818 で「出力ウィンドウ」のパネルの「背景」の欄に、配信しているシーンの背景を出すようにしたが、
透過が実際に効いているか (Linux のコンポジタが無い・WebView が透過を描かない・Windows の取り込みが BitBlt で透過を拾わないなど) はスタジオが知らないので、
透過のシーンでも黒い地が配信に乗ることがある (T0818 の候補)。

## 受け入れ条件

- [ ] OS ごとに、透過が効かない場合と、それをバックエンドで知る方法 (例: X11 の `_NET_WM_CM_S<n>` の選択の持ち主の有無、Wayland、Windows・macOS は常に合成) を調べ、
      結果と出典をメモに書いた。知れないものは知れないと書く
- [ ] 知れる場合について、透過 (とクロマキーでない) のシーンを出しているのに透過が効かないとき、「出力ウィンドウ」のパネルの「背景」の欄に注意 (`Notice` か印の三角) と
      代わりの案 (クロマキーの背景・ブラウザソース) を出す。判定の関数の単体テストと部品のテストがある
- [ ] 実機での確かめの手順 (コンポジタの有無・各 OS の取り込み) を docs/manual-check.md に足した
- [ ] docs/studio.md と docs/manual/studio.md (困ったとき) を直した
- [ ] `just ci` が通る (`#[cfg(windows)]` などを触ったら `just cross-check` も)
