### やったこと

- **場面を足した** (`tests/ui-audit/lib/apps.mjs`。すべての組で撮る。README の場面の表と偽のホストの説明を直した):
  - エディタ `-glue-edit` (T0949): 偽のホストの見本のモデルにグルー `SleeveHandGlue` を 1 つ足し (`editor-fixtures.mjs` の `glueModel`。袖と手を
    `ArmWave` の 3 つのキー (-1・0・1) でつなぐ。`ugoe_model::fixtures` と `ugoe sample` は変えていない)、グルーのパネルで選んで強さの軸 (キーの札・
    キーを足す欄・軸を足す行) まで送って撮る。右の列の頭のタブ (sticky) に隠れないよう、その高さだけ戻す。そのため `-tab-glue` は「グルーが無い」の
    案内ではなく 1 行の一覧を撮るようになった。
  - エディタ `-external-change`・`-base-change` (T0953): 偽のホストの `externalChange`・`baseChange` で `check_external_change`・`check_base_change`
    に変化を答えさせる。外での書き換えは「Save」(保存の前の確かめ。上書き・別名で保存も出る形)、本体の変化はモジュールのプロジェクトでウィンドウの
    `focus` を送って開く。どちらも「Later」(Esc) で閉じる。
  - エディタ `-ai-fresh` (T1632): 偽のホストの `editorPageInit` に、`listen` の関数を預かって `window.__uiAuditEmit(event, payload)` で呼ぶ口を足し、
    AI のタブを開いていない間に `mcp-bridge` の `{ kind: "proposals" }` を送る (タブの数 3 と見てほしい変化の点)。
  - エディタ `-tree-hover`・`-tree-hover-collapsed` (T1638): ツリーの「Head」のパーツの行に乗せた場面 (ビューポートに中のメッシュの破線の輪郭) と、
    「Head」を畳んでビューポートの上で場所を変えながら乗せ、畳んだ行に印 (`.hovered-within`) が付いた場面。
  - スタジオ `-inputs` (T0951): 「入力」のパネルまで送った場面 (パネルは既定で開いている。カメラのフェイストラッキングとマイク)。
- **ビューポートの背景色の場面 (T0952) は足さない:** 画素で測る文字を場面ごとに書き出して確かめた (一時的な変更。コミットしていない) ところ、
  3 つのアプリの `en-dark-wide` で画素で測る文字は hover の重ね (`--ugoe-overlay-hover`) の上の文字 (ツリーの行・ボタン) と、エディタの空の
  プロジェクトの案内 (`p.empty-text`) だけだった。エディタのビューポートの地はテーマの `sunken` で、利用者が変えられない (ライト・ダークの組で
  両方を撮っている)。背景色を変えられるビューアのビューポートの知らせは自分の地の札 (`surface`) を持ち、背景色に依らない (画素で測る文字は 0)。
  白・黒の場面を足しても測る文字が変わらないので足さず、「地の札なしで描画の上に文字を置くときに足す」と README に書いた。
- テスト: `hosts.test.mjs` に 2 つ (グルーを足したモデル・外での書き換えと本体の変化の切り替え)。`just ui-audit-check` が通る。
- **`just ui-audit` (3 つのアプリ):** 前 (`target/ui-audit-before`、rebase の前の main) と後 (`--compare`): editor +0 -0 ~0・viewer +0 -0 ~0・
  studio +0 -0 ~0。場面の数は editor 412 → 484、studio 168 → 183。新しい場面の指摘は 0 件 (studio のコントラスト 2 種類 (3) は前からあるもの。T0851)。
  画像を見て、ダイアログ・点・輪郭・縦線・グルーの欄が写っていることを確かめた。
- **main (107b8956) に rebase した後:** エディタとスタジオをビルドし直して `just ui-audit --only editor,studio` を流した。すべての検査で 0 件
  (editor 484・studio 183 場面。新しい場面はすべて撮れた)。`just ci` が通った。
- `just ui-audit` は 3 つのアプリで 10 分を超えるので、前面の 600 秒では終わらなかった (バックグラウンドで流した)。
