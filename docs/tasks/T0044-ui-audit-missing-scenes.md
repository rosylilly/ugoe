## 目的

M10 の見直しのタスクが画面を変えたが、`just ui-audit` の場面に無いため、コントラスト・押せる範囲・名前などの検査が届かない画面が残っている
(T0949・T0951・T0952・T0953・T1632・T1638 の候補)。場面を足し、変更を画像と検査で見られるようにする。
