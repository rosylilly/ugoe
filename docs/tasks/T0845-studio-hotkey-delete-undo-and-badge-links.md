# T0845: スタジオ: ホットキーの削除に取り消しを付け、状態の印からその設定のパネルへ送る

## 目的

T0818 で、スタジオの設定の流れと「いまの状態」の印を直した。残ったもの (T0818 の候補):

- ホットキーの行の「削除」はすぐに消え、戻すには足し直すしかない (docs/ui.md の「取り消せない操作は確かめか Undo」)。
- 「いまの状態」の印 (ホットキー・出力・入力など) は Tooltip で設定の場所を言うだけで、押してもそのパネルへ行けない。

## 受け入れ条件

- [x] ホットキーを削除すると、Toast などで「元に戻す」を出し、押すと同じ位置に同じキーと操作で戻る (OS への登録も戻る)。部品のテストがある
- [x] 設定のパネルを持つ状態の印 (ホットキー・出力ウィンドウ・入力など。どれにするかをメモに書く) を押すと、そのパネルを開いてそこまで送り、
      フォーカスをパネルの見出しへ移す。キーボードで押せる。部品のテスト (か `lib/status.ts` の単体テスト) がある
- [x] `just ui-audit --only studio` の指摘が増えない
- [x] docs/studio.md・docs/manual/studio.md を直し、画面が変わったところを T0919 のメモに書き足した
- [x] `just ci` が通る

## メモ

- T0040 で起票した (元の候補: T0818 (ホットキーの削除の取り消し)・T0818 (状態の印から設定へ))。
- **ホットキーの削除の取り消し:** Toast は操作を持たない (docs/ui.md・`Toaster` は閉じるボタンだけ) ので、パネルの頭に `Notice` (info。閉じられる) で
  「ホットキー「シーンの切り替え: 雑談」を削除しました」と「元に戻す」を出す (`HotkeysPanel.svelte`)。押したボタンは行ごと消えるので、フォーカスを「元に戻す」へ移す。
  「元に戻す」は同じ位置 (後ろの行が減っていれば最後) に同じキーと操作で戻して割り当てを送るので、バックエンドの `sync_hotkeys` が OS に登録し直す。
  戻せるのは最後に削除した 1 つ (次の削除で知らせが替わる)。戻した行のキーのボタンにフォーカスを移す。部品テスト 3 つ (`HotkeysPanel.svelte.test.ts`)。
- **状態の印から設定へ:** 印はすべてボタンにした (どれも右の列に設定のパネルがあるため): トラッキング・口パク → 入力、ホットキー → ホットキー、出力 → 出力ウィンドウ、
  負荷 → フレームレートと負荷、操作 API → 操作 API、ソース → ブラウザソース (OBS) (`lib/status.ts` の `STATUS_PANELS`。印の `panel`)。
  押すと (Enter・Space でも。`<button>`) `revealPanel` が、畳んでいれば開き (`Control.svelte` の `panelsOpen` を `Section` の `bind:open` に)、
  送れるいちばん近い祖先 (右の列・狭い幅では画面) をパネルの頭まで送り (scrollIntoView は body まで動かすので使わない。動きを減らす設定なら一度に)、
  見出しの開閉のボタンにフォーカスを移す。パネルは `data-panel` の `div` で囲んだ。押せると分かるよう、印の枠を操作の部品の色 (`control-border`) にし、
  乗ると Button と同じ明るさの変化。部品のテスト (`StatusBadge.svelte.test.ts`: ボタンで押すと `onopen`・`onopen` が無ければ前の印・印とパネルの対応・
  閉じたパネルを開いて送って見出しにフォーカス・無いパネル)。
- **偽のホストと場面 (tests/ui-audit。範囲の外の小さな変更):** `setHotkeys` で割り当てを替えたプロファイルを送り直すようにし、場面 `-hotkey-removed`
  (「いまの状態」のホットキーの印を押して送り、1 つ目を削除した後の知らせ) を足した。92 場面 → 102 場面。
- **監査:** `just ui-audit --only studio` は前 (`target/ui-audit-before`、main d5ac4e4a) も後も全検査 0 件、`--compare` は `+0 -0 ~0`。
  `-hotkey-removed` の画像 (広い幅・360・960) で、右の列がホットキーのパネルの頭まで送られ、知らせと「元に戻す」が出ているのを見た。
- **e2e:** `just e2e --only studio` は 13 件すべて通った (Status のリストの項目は、中がボタンになっても名前で見つかる)。

  docs/ui.md (T0818 の節に T0845 の 1 項)、apps/studio/README.md、tests/ui-audit/README.md。T0919 のメモに撮り直す画像を書いた。

- **やらなかったこと・確かめていないこと:**
  - 実物の WebView (WebKitGTK・WebView2・WKWebView) での送りの動き (smooth) とフォーカスの印 (ヘッドレスの Chrome の偽のホストと happy-dom だけ)。
  - OS への登録が戻ることは、送る割り当てが削除の前と同じであることで確かめた (バックエンドは割り当てが変わるたびに全部を登録し直す)。実機の登録は見ていない。
