# T0202: 参照レンダラ: マスク

## 目的

マスクアトラス方式のクリッピング (和集合、反転) を実装する。

## 受け入れ条件

- [x] 同じマスク集合を共有する要素で、マスクの描画を使い回す
- [x] 反転マスクのテストがある
- [x] アトラスが足りない場合に、アトラスを増やして描画できる
- [x] `just ci` が通る

## 参考

- `docs/spec/rendering.md#マスク`

## メモ

- 方式の詳細は `docs/spec/rendering.md` の「マスク」→「詳細」に書いた。要点:
  - マスク集合 = マスク用メッシュのインデックスの集合 (並び・重複・反転は区別しない)。ロード時に求める。
  - アトラス 1 枚 (既定 1024²) の各チャンネルを `g × g` に等分し、集合 1 つにセル 1 つ。`g` の上限は `size / min_cell_size` (既定 4)。
    あふれた集合は 2 枚目以降のアトラスに回す。対象要素の画面上の外接矩形を、セルの 1 texel 内側に写す。
  - マスクの有無と反転はユニフォーム (`mask_flags`) で切り替え、パイプラインは分けない。マスクパス用のパイプラインを 1 つ追加した。
- 公開 API の追加: `RendererOptions` / `MaskAtlasOptions` / `Renderer::with_options` / `FrameStats` / `Renderer::last_frame_stats`。
  `Renderer::new` は既定の設定で `with_options` を呼ぶ (既存の呼び出しはそのまま)。
- 仕様の矛盾: 仕様は「カバレッジ = テクスチャのアルファ × 不透明度」と「非表示 (不透明度 0 など) でもマスクとして描く」を
  両方書いていた (不透明度 0 ならカバレッジが 0 になる)。レビューで「× 不透明度」を外すと決め、
  カバレッジ = テクスチャのアルファだけにした。マスク用メッシュは不透明度・`visible` に関係なく同じようにクリッピングする。
  非表示のマスクでもクリッピングするという仕様の元の意図と、Cubism でよくある使い方 (マスク用のアートを見えなくしておく) に合わせるため。
  Cubism のマスクシェーダが実際にアルファだけを使うかは未確認 (仕様に注記した)。
  現状のランタイムは `visible = opacity > 0` なので、「不透明度が正で非表示」のマスクはテストできていない (T0104 でパーツ不透明度が入れば可能)。
- マスク用メッシュの合成モード・色・カリングはマスクに効かない (マスクパスはカリングしない)。
- 小さいアトラス (32²) ではマスクの縁がバイリニア補間でぼける (テストでは縁の画素を検査しない)。
- GPU テストは WSL2 の既定アダプタと `WGPU_BACKEND=gl` の両方で通ることを確認した。
- 後続の候補: 同じマスク集合がフレーム間で変わらないときのマスクパスの省略、Cubism の高精度マスク
  (要素ごとに画面解像度で描く) 相当のオプション。
