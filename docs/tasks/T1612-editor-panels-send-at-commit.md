# T1612: エディタ: スロットの欄・カーブのキーの時刻・グルーの組を doc.send で送り、パネルのドラッグの送り直しを点検する

## 目的

T0693 でパネルの編集を `doc.send` (送る直前に今のモデルからコマンドを組み立てる) の列にしたが、残りがある。

- `SlotsPanel.svelte` の範囲の欄は自前の `busy` で、適用中の確定を捨てる。ID の変更も送る直前に今の ID を引く形にする (T0695・T0693 の候補)。
- `CurveGraph.svelte` のキーの時刻の欄は、適用中に次の確定をすると古い時刻のキーを動かそうとして `NotFound` になる (T0695 の候補)。
- `GlueOverlay` の組の追加・削除は、ドラッグの開始時のグルーから `set_glue` を組み立てる (T0693 の候補)。
- タイムラインなどパネルのドラッグでも、送っている間の `pointermove`・`pointerup` で送り直していないか点検する (T0699 の候補)。

## 受け入れ条件

- [ ] 上の 3 つが `doc.send` で送る直前に組み立て、適用中の確定を捨てない・古い値で失敗しない。それぞれに先に失敗するテストを書いてから直した
- [ ] パネルのドラッグを点検し、送り直しがあれば直した (点検した部品の一覧をメモに書いた)
- [ ] `just ci` が通る
