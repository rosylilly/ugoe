# T0628: リギング操作の使い勝手 (優先度 中・低)

## 目的

操作マニュアル (T0624) の作成中に見つかった問題のうち、回避できるが手間のかかるものを直す。詳細は `docs/tasks/T0624-user-manual.md` のメモ。

## 受け入れ条件

- [ ] キーの値を、最小・最大以外にも数値で入力して追加できる
- [ ] キーを作った後に回転デフォーマの原点を動かすと、今のセルだけが動く。すべてのセルの原点を一緒に動かす操作を用意する
- [ ] デフォーマを外す (子を親に戻して、見た目を保ったままデフォーマを削除する) 操作
- [ ] 形状編集で、メッシュの頂点を複数選んで動かせる (今は 1 点かすべて)
- [ ] プロジェクトを開いたとき、パラメータのスライダーの値を既定値に戻す
- [ ] ヘルプのリンクをブラウザで開く (`tauri-plugin-opener` など)
- [ ] 操作マニュアルの画面写真のヘッダーに出ている、確認用のバックエンドの名前 (`vbridge`) を正しい表示にする
- [ ] 操作マニュアルを更新し、`just ci` が通る
