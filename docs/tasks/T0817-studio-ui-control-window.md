# T0817: スタジオ UI: 操作ウィンドウの配置とレイアウト

## 目的

配信中に素早く操作する画面として、スタジオの操作ウィンドウの配置とレイアウトを見直す。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [ ] 配信中によく使う操作 (シーンの切り替え・表情・ホットキーの状態・トラッキングの状態) が、送らずに見える位置にある
- [ ] 状態の印 (負荷・API・ソース・トラッキング・マイク) を、色だけでなく形と文で示し、意味が Tooltip で分かる
- [ ] 3 つの列の幅の配分と、960px 以下で列ごと送る並びを見直した
- [ ] 誤操作しやすい操作 (シーンの削除・API の許可) に確認か取り消しがある
- [ ] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [ ] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [ ] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [ ] `just ci` が通る
