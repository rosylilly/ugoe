# T0907: UI: 3 つのアプリの見直し (キーボード操作・フォーカス・コントラスト・ライトとダーク・小さい画面)

## 目的

移行の後に、3 つのアプリで見た目と操作が揃っているかを見直す。

## 受け入れ条件

- [ ] キーボードだけで主な操作ができる、フォーカスが見える、文字のコントラストが基準を満たす (docs/ui.md)
- [ ] ライトとダーク、高 DPI、狭い幅で崩れない (ヘッドレスの Chrome のスクリーンショット)
- [ ] 見つかった崩れを直す。直せないものは後続のタスクにする
- [ ] スタジオの操作ウィンドウのヘッダーを組み直す (言語・テーマ・ライセンスをビューアとエディタと同じく「設定」のダイアログにまとめるなど。T0811 でボタンが 2 行に折り返すようになった)
- [ ] これまでのタスクで残った見た目の課題: エディタのビューポートの左上の説明と右上の webgl2 の重なり (T0664)、「書き出し…」の枠が Esc や外のクリックで閉じない (T0665)
- [ ] `just ci` が通る
