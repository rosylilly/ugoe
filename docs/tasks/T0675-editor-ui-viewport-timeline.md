# T0675: エディタ UI: ビューポートとタイムライン

## 目的

ビューポート (道具の並び・HUD・ギズモ) とタイムライン (ドープシート・グラフ) の見た目と操作の分かりやすさを見直す。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [x] ビューポートの道具の並び・HUD・説明の帯の配置を見直し、狭い幅と高 DPI で重ならない
- [x] ギズモ・メッシュの点・選択の色と大きさが、ライトとダークの両方の地とモデルの上で見分けられる
- [x] ビューポートで行う操作に、パネルかキーボードでの代わりの手段がある (docs/ui.md の基準) ことを、操作ごとに一覧にして確かめた
- [x] タイムラインの行の高さ・キーの形・グラフの軸と目盛り・再生の操作の配置を見直した
- [x] 1024×720 で、タイムラインとグラフを出しても主な操作ができる
- [x] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [x] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [x] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [x] `just ci` が通る

- **やったこと:**
  - ビューポートの並び (`ToolOverlay` の `.strip`): 道具のボタンを 1 行目に集め (「Form edit」を FormTool の帯から並びへ。`enabled` は ToolOverlay が持つ)、
    その下にフォーム編集・ギズモ・メッシュ編集・本体の注記の **説明の帯** (`.vp-band`) をテーマの地と枠に載せて縦に積む。前は帯が `top: 40px` に固定で、
    並びが折り返すと重なり、文字 (「キーの上にいない」の注意を含む) がモデルの上に直に載っていた。注意は三角の印と `warning` の色。
    ツールの svg は `.strip` の中でもオーバーレイ全体に広がる (位置の基準にしない)。DOM の順は表示の重ね (物理など) の下のまま。
  - HUD: 右上は「Screenshot」と GPU の知らせだけ。`webgl2` (開発者向け) は設定の「General」の「About the ugoe editor」へ (`SettingsDialog` の `backend`)。
    拡大・縮小・全体を表示をビューアと同じ右下の道具 (`Toolbar` と `IconButton`) にした (前は「Fit」だけでホイールの代わりが無かった)。
    左下の帯 (グルー・違いの知らせ) は右下の道具の幅を空ける (`--viewport-view-tools-width`)。
  - 図の色: `Viewport.svelte` の `--viewport-*` (テーマに依らない) にまとめ、`viewport/tools/**`・`ToolOverlay`・`DifferenceOverlay` の直書きと
    強調色・`surface`・`opacity` を置き換えた。線はライトとダークの地の両方に 3:1 以上、点は白の中と色の縁、選んだ点は琥珀の中と濃い縁、
    光源は暗い縁取り。表は docs/ui.md#ビューポートの上の図 (T0040 の候補「ビューポートの上の図の色のトークン」をここで扱った)。
  - 代わりの手段: 操作ごとの表を docs/editor.md#ビューポートの操作と代わりの手段 に書いた。点のドラッグの代わりに矢印キー (1px・Shift で 10px) を
    メッシュの編集・フォーム編集・ワープの制御点・回転の原点に足した (`tools/keys.ts` の `nudgeOf`・`acceptsNudgeKey`。フォーカスが無いかビューポートの
    中のときだけ。ツリー・スライダー・タイムラインの矢印は奪わない)。テスト: keys.test.ts・FormTool.test.ts・DeformerGizmo.test.ts・ToolOverlay.test.ts。
  - タイムライン: モーションの名前・長さ・ループ・フェードを「Settings…」の `Popover` へ、再生と繰り返しをアイコンのボタン (繰り返しは `pressed`)、
    コマ送りと時刻を 1 組にして、上の段と再生の段を 1024px でも 1 行ずつにした (前は 1440px で 2 行、1024px で 3 行 + 2 行)。表情の上の段も「Settings…」。
    キーの印の形を入る区間の種類 (菱形・円・四角。`timeline.ts` の `shapedKeys`、timeline.test.ts)。グラフの左端に上端と下端の値。
    グラフの左の欄を 4 行 (「Delete curve」を名前の行へ、区間の種類を `Select` へ。CurveGraph.test.ts はキーボードで選ぶ形に直した)。
    頭の段は送らず表を送る (表は 2 行を残す)。行の名前の列は狭いとき 150px まで縮める (`--label-width`、cqw)。
    `+ Event at …` は T0674 の決め方 (文言の「+ 」をやめて `Icon name="plus"`) にそろえた (T0040 の候補)。「New motion」にも同じアイコン。
  - 見つけた崩れ: 見せずに読ませる文字の位置の基準 (T0674 と同じ) を `.motion-editor`・`.expressions` に付けた。
