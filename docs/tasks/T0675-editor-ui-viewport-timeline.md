# T0675: エディタ UI: ビューポートとタイムライン

## 目的

ビューポート (道具の並び・HUD・ギズモ) とタイムライン (ドープシート・グラフ) の見た目と操作の分かりやすさを見直す。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [ ] ビューポートの道具の並び・HUD・説明の帯の配置を見直し、狭い幅と高 DPI で重ならない
- [ ] ギズモ・メッシュの点・選択の色と大きさが、ライトとダークの両方の地とモデルの上で見分けられる
- [ ] ビューポートで行う操作に、パネルかキーボードでの代わりの手段がある (docs/ui.md の基準) ことを、操作ごとに一覧にして確かめた
- [ ] タイムラインの行の高さ・キーの形・グラフの軸と目盛り・再生の操作の配置を見直した
- [ ] 1024×720 で、タイムラインとグラフを出しても主な操作ができる
- [ ] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [ ] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [ ] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [ ] `just ci` が通る
