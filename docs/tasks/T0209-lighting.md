# T0209: 参照レンダラ: ライティング

## 目的

法線マップと光源 (環境光・平行光源・点光源) によるライティングを実装する。変形に合わせて法線を回す。

## 受け入れ条件

- [ ] 光源の API (`Lighting`) をホストから渡せる
- [ ] 変形 (回転・反転) に合わせて法線が回ることを確かめる GPU テストがある
- [ ] 法線マップのないメッシュは法線 (0, 0, 1) として扱う
- [ ] WebGL2 で動く
- [ ] 仕様書の「実装待ち」を更新する
- [ ] `just ci` が通る
