# T0648: エディタ: モジュールのプロジェクトと .ugoemod の書き出し

## 目的

ADR 0024。本体を参照するモジュールのプロジェクトを作り、衣装を組んで `.ugoemod` に書き出せるようにする。

## 受け入れ条件

- [ ] プロジェクトの種類 (本体 / モジュール) と、モジュールのプロジェクトが参照する本体 (`.ugoeproj` か `.ugoe`) とスロット。既存のプロジェクトはそのまま読める (`docs/spec/file-formats.md` を更新)
- [ ] `Document` がモジュールを編集できる (パーツ・デフォーマ・メッシュ・グルー・テクスチャ・物理・ポーズ)。モデル用の `Command` をモジュールでも使えるようにするか、モジュール用に分けるかを決めて書く
- [ ] 本体を下敷きとして読み取り専用で表示し、合成した姿をビューポートとプレビューで見せる。本体のパラメータで動かせる
- [ ] 衣装の PSD の取り込み・自動メッシュ・リギングがモジュールでも使える
- [ ] `.ugoemod` の書き出し (`validate_module` と本体との合成の検証)。新規作成の画面 (本体とスロットを選ぶ)
- [ ] ヘッドレスのブラウザで、衣装の PSD からモジュールを作って書き出し、本体に付けて確かめる。マニュアルの着せ替えの章に節を書く
- [ ] `just ci`・`just gen`・`cargo check -p ugoe-editor` が通る
