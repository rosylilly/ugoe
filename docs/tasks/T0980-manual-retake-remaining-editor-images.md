# T0980: マニュアル: T1662・T0979 などの後に、エディタのマニュアルの画像の残りを撮り直す

## 目的

T1662 (エディタの送る枠の行末の空き 4px)・T0979 (ダイアログの閉じるボタンの位置)・T1670・T1675 (ツリー) などで画面が少し変わったが、
エディタのマニュアルの画像は T0968・T0969・T1671 で撮った後に撮り直していないものが 36 枚ほどある (T1671 の候補)。

## 受け入れ条件

- [ ] `just e2e --update-images --only editor` で撮り直し、アニメーション (呼吸・物理) の違いだけの画像は前のままにして、画面が変わった画像だけを入れた。どの画像を入れたかと、変わった理由 (T1662 など) をメモに書いた
- [ ] 入れた画像をすべて開き、撮った機械の固有のもの (/home・worktree・mbx のハッシュ・乱数の一時フォルダ) が写っていないことを確かめた
- [ ] 画像と説明の文が食い違っていれば、docs/manual の文を直した
- [ ] `just e2e --only editor` と `just ci` が通る
