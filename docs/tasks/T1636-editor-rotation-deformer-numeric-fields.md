# T1636: エディタ: 回転デフォーマの今のセルの角度と拡大率を数値の欄で入れる

## 目的

回転デフォーマの今のセルの角度と拡大率は、ビューポートのギズモの取っ手でしか変えられない。キーボードの代わりと正確な値の入力のために、
インスペクタのキーフォームの節に数値の欄を置く (T0675 の候補)。

## 受け入れ条件

- [ ] 回転デフォーマを選び、キーの上にいるとき、インスペクタのキーフォームの節に角度と拡大率の `NumberField` がある。確定で今のコマンド (ギズモと同じもの) を送り、Undo が 1 回で戻る
- [ ] キーの間にいるとき (セルが無いとき) の欄の見せ方を決め、メモに書いた
- [ ] 部品のテスト (確定で送るコマンドとその値) がある
- [ ] `just ui-audit --only editor` の指摘が増えない。docs/editor.md を直し、画面が変わったところを T0919 のメモに書き足した
- [ ] `just ci` が通る
