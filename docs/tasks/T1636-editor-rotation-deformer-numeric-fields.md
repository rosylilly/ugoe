# T1636: エディタ: 回転デフォーマの今のセルの角度と拡大率を数値の欄で入れる

## 目的

回転デフォーマの今のセルの角度と拡大率は、ビューポートのギズモの取っ手でしか変えられない。キーボードの代わりと正確な値の入力のために、
インスペクタのキーフォームの節に数値の欄を置く (T0675 の候補)。

## 受け入れ条件

- [x] 回転デフォーマを選び、キーの上にいるとき、インスペクタのキーフォームの節に角度と拡大率の `NumberField` がある。確定で今のコマンド (ギズモと同じもの) を送り、Undo が 1 回で戻る
- [x] キーの間にいるとき (セルが無いとき) の欄の見せ方を決め、メモに書いた
- [x] 部品のテスト (確定で送るコマンドとその値) がある
- [x] `just ui-audit --only editor` の指摘が増えない。docs/editor.md を直し、画面が変わったところを T0919 のメモに書き足した
- [x] `just ci` が通る

- T0041 で起票した (元の候補: T0675 (回転デフォーマの数値の欄))。
- **やったこと:**
  - `KeyformInspector.svelte`: 回転デフォーマを選ぶと、状態の行の下に「Angle (this cell)」(°、刻み 1、小数 3 桁) と「Scale (this cell)」
    (下限は `gizmo.ts` の `MIN_SCALE` = 0.001、刻み 0.01) の `NumberField`。確定で `doc.send` からギズモと同じ `set_keyform_cell` を送る
    (原点・反転・不透明度はそのセルのまま)。コマンドは送る直前の最新のモデルから組み立てる (`keyforms.ts` の `rotationCellCommand`。
    角度を確定してすぐ拡大率を確定しても、角度を古い値に戻さない)。1 回の確定が 1 つのコマンドなので Undo 1 回で戻る。
    同じ欄の続けての確定は数値の欄の決まり (`numberFieldCommit`) で 1 つの Undo にまとまる。
  - **キーの間の見せ方 (決めたこと):** 欄は残して空 (`optional` の `null`) にし、押せなくする (`disabled`)。補間した値は書き込むセルが
    無いので数を出さない (0 や補間値を出すと、そこに書けるように見えるため)。理由と「Move to nearest key」は同じ節の状態の行
    (「Between keys.」とボタン) が既に出している。欄を消さないのは、キーへ移ったときに並びが動かないようにするため。
    描画のクローンの節 (`DrawCloneSection`) も「キーの間は押せない」なので、それにそろえた (あちらは 0 を出す。空にはしていない)。

    最新のモデルから組み立てる・軸のあるデフォーマでキーの上のセル・キーの間で空で押せない・メッシュでは欄が無い)、
