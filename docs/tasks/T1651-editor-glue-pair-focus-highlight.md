# T1651: エディタ: グルーのパネルの組の行にフォーカス・ホバーしたとき、ビューポートでその組を強調する

## 目的

T1648 でグルーのパネルに組の一覧 (「Pairs」。`A 2 ↔ B 1`) を置いたが、番号だけではビューポートのどの頂点の組かが分かりにくい。
組の行にフォーカスか、ポインタを乗せたとき、ビューポートのグルーの重ねでその組 (2 つの頂点とその間の線) を強調し、番号と絵を結び付ける。

## 受け入れ条件

- [ ] 組の行 (と行の「×」) にフォーカスかポインタがあるとき、ビューポートのグルーの重ねでその組だけが強調される (色と太さ。色だけに頼らない)。
      離れると戻る。ほかの組は今のまま
- [ ] 強調は表示だけで、Command を送らない (Undo の履歴に残らない)
- [ ] 部品のテスト: 行にフォーカスすると強調する組が決まり、外すと消える。ビューポートの重ねが強調する組を受け取って描き分ける
- [ ] docs/editor.md のグルーの画面 (「組の一覧」) に書いた。マニュアルの更新の候補をメモに書いた
- [ ] `just ui-audit --only editor` (`-glue-edit`) で増えた指摘が無く、`just e2e --only editor` と `just ci` が通る
