# T0641: エディタ: 外でプロジェクトが書き換えられたことに気づく

## 目的

ADR 0023 の 5。`ugoe-mcp` (ファイルを直接扱う形) や別のエディタがプロジェクトを書き換えたときに、エディタが気づいて利用者に知らせ、黙って上書きしない。

## 受け入れ条件

- [ ] 開いているプロジェクトのファイルが外で変わったことを検出する (ファイルの監視、またはウィンドウに戻ったとき・保存の前の確認。WSL 越しのパス (`\\wsl.localhost\...`) やネットワークのドライブでも働く方法を選び、理由を書く)
- [ ] 未保存の変更がなければ「開き直す」を促す (または自動で開き直す設定)。未保存の変更があれば、開き直す・自分の変更で上書きする・別名で保存する、を選ばせる
- [ ] 保存の前に、開いた後で外で変わっていないかを確かめ、変わっていれば確認を求める
- [ ] editor-core にテスト (変更の検出の判定)、ヘッドレスのブラウザで画面を確かめる。操作マニュアルに書く
- [ ] `just ci`・`just gen`・`cargo check -p ugoe-editor` が通る
