# T1635: エディタ: ビューポートの移動と、フォーム編集・ワープの点の選択をキーボードでもできるようにする

## 目的

T0675 のビューポートの見直しで、ポインタだけでできる操作のキーボードでの代わりを表にしたが、作っていないものが残った (T0675 の候補):

- ビューポートの移動 (パン)。
- フォーム編集・ワープの点を 1 つずつ選ぶこと。

## 受け入れ条件

- [ ] ビューポートにフォーカスがあるとき、キーボードで表示を動かせる (矢印など。キーと 1 回の量をメモに書く。入力欄の中では効かない)
- [ ] フォーム編集・ワープの道具で、キーボードで次・前の点を選べ (Tab か `[` `]` など。選んだ点をビューポートと読み上げで分かるように)、選んだ点を矢印で動かせる
      (既にあるなら確かめてメモに書く)。点の移動は今のコマンドを通す
- [ ] 単体テスト (キーと動き・選ぶ点の順) と部品のテストがある
- [ ] docs/editor.md・docs/ui.md (キーボードでの代わりの表)・docs/manual (ショートカット) を直し、画面が変わったところを T0919 のメモに書き足した
- [ ] `just e2e --only editor` と `just ci` が通る
