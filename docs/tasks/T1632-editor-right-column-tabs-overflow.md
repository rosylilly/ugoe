# T1632: エディタ: 右の列の 8 つのタブが既定の幅で 2 行になるのを直す (判断が要る)

## 目的

エディタの右の列のタブ (インスペクタ・物理・ライティング・AI など 8 つ) は、既定の幅 320px で 2 行に折り返す。T0673 はタブを減らす・送る・アイコンにするのは
見た目の大きな判断として見送った (T0673 の候補)。

**判断が要る:** 案:

- A. よく使うタブ (インスペクタ・物理・ライティング・AI など) を並べ、残りを「その他」の `Menu` に送る (選んだタブは並びに出す)。
- B. すべてのタブをアイコンと `Tooltip` にする (名前は見せずに読ませる)。
- C. タブを横に送る (1 行のまま。矢印のボタンか送り)。

推奨は、エディタのタブごとの使う頻度と、日本語の名前の長さ・200% の拡大での幅を見てから書く (A を軸に検討する)。
