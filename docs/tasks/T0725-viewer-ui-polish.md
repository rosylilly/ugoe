# T0725: ビューア UI: 配置・レイアウト・アクセシビリティの見直し

## 目的

ビューアの画面 (モデルの表示・パラメータ・ライティング・モーション・トラッキング・着せ替え) の配置とレイアウトを見直す。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [x] パネルの並びと開閉を見直し、広い幅でトラッキングのパネルを開いたままでも、ライティング・モーションのパネルが低くならない (T0907 の後続)
- [x] 360px・1280px・高 DPI で崩れず、モデルの表示の面積が十分にある
- [x] ファイルを開く・ドロップするまでの空の状態に導線がある
- [x] パラメータの一覧 (多い・長い名前) の送りと絞り込み
- [x] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [x] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [x] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [x] `just ci` が通る

- **やったこと (詳細は docs/ui.md#ビューアの見直し-t0725 と apps/viewer/README.md の右のパネルの段落):**
  - 右の列を 2 段に: 上の段に機能のパネル (トラッキング・着せ替え・ライティング・モーションと表情・ポーズ) を中身の高さのまま並べて段ごと送り
    (右の列の 6 割まで)、下の段にパラメータ (残り、最低 4 割)。パネルごとの高さの上限と中の送りを外した (トラッキングを開くとライティングなどが
    見出しの高さまで潰れていた)。幅 1200px 以上では 2 段を横に 2 列に並べる。720px 未満は今までどおり右の列の全体を 1 つで送る (高さ 55% → 45%)。
  - 拡大・縮小・全体の表示の道具をビューポートの右下に重ねた (モデルを開いているときだけ)。狭い幅ではモデルの名前をツールバーから下の帯に移した。

    テーマの地の札に載せた (ビューポートの地はモデルの背景色なので、ダークのテーマの文字が読めなかった。監査は canvas の上の地を測らないので見つけない)。

    グループの見出しの sticky (広い幅は一覧の中、狭い幅は右の列の送りに対して)、行の `title` に名前の全体と ID。
  - 監査の 2 種類: `role="img"` をビューポートの中の空の要素に移した (nested-interactive)。光源の印は円の輪のまま、`:focus-visible` に透明の outline
    (強制色のモードで輪になり、監査の印の判定にも数えられる)。
  - テスト: Viewport (空の状態の中身・道具の重ね・role="img" の中に操作できる部品が無い)、ParameterPanel (グループの名前での絞り込み・合わないときの文・
