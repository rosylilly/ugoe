# T0120: 公開仕様だけで書いた独立の読み込み器による検証

## 目的

公開仕様が実装から独立して読めることを確かめるため、ugoe の Rust のコードを読まずに、`spec/` だけを見て別の言語 (例: TypeScript) で `.ugoe` を読み、例のファイルの期待値を再現する小さな実装を作る。仕様の抜けや曖昧さを見つけて直す。

## 受け入れ条件

- [ ] 作業者 (エージェント) は `crates/` と `docs/spec/` を読まず、`spec/` だけを参照する (手順として明記する)
- [ ] `.ugoe` の読み込みと、例のファイルの評価 (少なくともワープ・回転・補間・ブレンドシェイプ) で期待値と一致する
- [ ] 見つかった仕様の抜け・曖昧さの一覧と、`spec/` への修正
- [ ] `just ci` が通る (独立の実装のテストを CI に入れるかは決めて書く)
