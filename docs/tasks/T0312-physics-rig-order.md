# T0312: 物理リグの順序付き評価と中継パラメータ

## 目的

Live2D の実践では、物理のグループを「上から順に処理される」前提で連鎖させ、あるグループの出力 (中継用パラメータ) を次のグループの入力にして、
「体が遅れて付いてくる」「弾んでから角度に戻る」「位置 Z に応じて足が曲がる」といった動きを作っている (参考の記事 4)。
今の ugoe は、すべてのリグがフレームの始めのパラメータを読み、出力はすべてのリグを進めた後に書くので、連鎖すると 1 フレーム遅れ、リグの順序に意味がない。

## 受け入れ条件

- [ ] リグを `PhysicsSettings::rigs` の順に進め、前のリグの出力 (パラメータ) を後のリグが **同じステップで** 入力として読む。規則 (ステップの中の順序、出力の補間との関係) を `docs/spec/physics.md` に書く
- [ ] 連鎖 (体の追従 → 弾み → 角度) のテスト。順序を入れ替えると結果が変わること、決定性、動的物理との組み合わせ
- [ ] 中継用のパラメータを示すフラグ (例: `Parameter::internal`) を足す。トラッキングの対応付けは書き込まず、ビューアのスライダーとアプリ向けの一覧では既定で隠す。`validate` と `docs/spec/model.md`
- [ ] エディタの物理のパネルでリグの順序を並べ替えられる (コマンドと Undo)
- [ ] `just ci`・`just gen` (差分なし)・`just wasm-check` が通る
