# T1649: エディタ: 回転デフォーマの原点を数値の欄 (親の座標系の値) で入れる

## 目的

T1636 で回転デフォーマの今のセルの角度と拡大率を数値の欄で入れられるようになったが、原点はギズモのドラッグと矢印キーでしか変えられず、
正確な値を入れられない (T1636 の候補)。

## 受け入れ条件

- [ ] 回転デフォーマを選び、キーの上にいるとき、インスペクタの「Keyforms」の節に原点の X・Y の `NumberField` (親の座標系の値) がある。確定でギズモと同じコマンドを送り、Undo が 1 回で戻る
- [ ] 「Origin: all cells」が入のときは、矢印キーと同じくすべてのセルに同じ差を足す。キーの間 (セルが無いとき) の見せ方は T1636 の角度・拡大率の欄とそろえる
- [ ] 部品のテスト (確定で送るコマンドとその値・すべてのセル)
- [ ] `just ui-audit --only editor` の `-rotation`・`-rotation-between` の指摘が増えない。docs/editor.md (インスペクタの表・代わりの手段の表) を直し、マニュアルの更新の候補をメモに書いた
- [ ] `just e2e --only editor` と `just ci` が通る
