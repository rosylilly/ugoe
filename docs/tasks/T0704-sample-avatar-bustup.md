# T0704: バストアップの PSD から見本のアバターを作り直す

## 目的

T0702 の見本のモデルは全身の絵を切り出したもので、目・口が 1 枚ずつしかなく、動きが不自然でフェイストラッキング (T0703) の細かい確認ができなかった (利用者の確認、2026-09-29)。
利用者が用意したバストアップの PSD (`assets/fixtures/psd-real/comfyui-see-through-bustup-parts.psd`) は、目・口が開き・閉じの別レイヤーになっている (`eyeclose-l/r`、`mouth-open`・`mouth-close`)。
これらを合成で切り替えて、自然に表情が付く見本のモデルを作る。

## 受け入れ条件

- [x] `psd-real/README.md` の表にこの PSD の行を足す (ChatGPT で生成した画像を ComfyUI の See-Through でパーツに分けたもの、MIT、利用者の提供。1MB を超える理由も書く)。`real_world` のテストが通る
- [x] ジェネレータ (`ugoe sample avatar`、T0702) がこの PSD からリグを組む。目は開き (白目・黒目・まつ毛) と閉じ (`eyeclose-*`) を、口は `mouth-close` と `mouth-open` を、パラメータに応じて不透明度と変形で自然につなぐ (途中の値で二重に見えたり消えたりしない)
- [x] 頭の向き (AngleX/Y/Z)・目の開閉・笑い目・視線・眉・口の開閉・口の形が自然に動く。体の向き (BodyAngle) や呼吸があればなおよい。`ugoe validate --profile avatar` を通る
- [x] 各パラメータの端と途中の値で描いた一覧の画像を目で確かめ、メモに書く。ビューアで実際の人の顔の画像・動画を入力して、表情が自然に付くことを確かめる
- [x] ビューアの「サンプル」がこの新しいモデルを開く。前の見本 (全身) を残すかどうかを決めて書く
- [x] 耳飾りの先 (`earwear-l/r`)・後ろ髪・前髪の毛先が、頭と体の動きに遅れて動的物理 (T0305) で揺れる (利用者の追加の依頼、2026-09-29)。物理の設定はバンドルに入り、`validate_physics` を通る。`ugoe::Puppet` で頭を振った途中のコマを描いて目で確かめ、ビューアでも確かめる
- [x] `just ci` が通る

## メモ

### やったこと

- **PSD:** `psd-real/README.md` に行を足した。ImageMagick では平らな 24 レイヤーに見えるが、実際はグループ `body`・`face` (中に `ear-r`・`ear-l`・`mouth`・`eye-r`・`eye-l`) があり、
  `earwear-r`・`eyeclose-r` にレイヤー効果がある (取り込みは無視して警告)。`real_world` のテストは通る。ugoe の描画と ImageMagick の合成画像は PSNR 約 69 dB。
- **ジェネレータ** (`crates/ugoe-cli/src/sample.rs`) をこの PSD 用に書き直した。組み立て方の表は `assets/samples/README.md`。要点:
  - 目: 開いた目 (白目・黒目・まつげ) のワープを、目の下寄り (高さの 70%) の線へつぶす (`EyeLOpen` 0.35 で 22%、0 で 4%)。閉じた目 (`eyeclose-*`) は別のワープ。
    不透明度は閉じた目が 0.36→0.3 で現れ、開いた目が 0.3→0.22 で消えるので、どの値でもどちらかが不透明 (テスト `open_and_closed_layers_never_vanish_or_double` で 0.01 刻みに確かめる)。
  - 閉じた目の絵は上向きの弧 (笑った閉じ目) なので、`EyeLSmile` 0〜0.5 では中ほどを下げた平らな閉じ目、1 で絵のまま。開いた目の笑い目は下まぶたを控えめに押し上げる。
    つぶれた目と笑い目の組み合わせは加算合成だと下まぶたが裏返ったので、そのセルを書いた。
  - 口: 開いた口は閉じた口の幅・半分の高さの隙間から開く (0→0.12 で現れ、1 まで広がる)。閉じた口は 0.12→0.3 で消える。`MouthForm` は両方の口角を閉じた口の高さの 45% で曲げる (開いた口は組み合わせのセルを全部書いた)。
  - 追加: `JawX` (口のワープの下ほど横へ)。
  - **揺れもの (利用者の追加の依頼):** 動的物理のリグ 5 つ (`FrontHair`・`BackHair`・`EarringL`・`EarringR`)。どれも根元を頭の回転デフォーマ (`frame: HeadRotation`) に付け、
    振り子の先の粒子の横の変位を `vertices` で足す。前髪・後ろ髪は出力用のワープ (`FrontHairSwayWarp`・`BackHairSwayWarp`。キーフォームなし) の制御点に、上から下へ 2 乗で増える重み
    (前髪は上 40% が 0・下端 0.5、後ろ髪は上 30% が 0・下端 0.8)。耳飾りはメッシュの頂点に、金具 (上 35%) が 0・先が 1 の重み。レイヤーには耳から離れた所に数画素のごみがあるので、
    耳の横の範囲の頂点だけを耳飾りとした。入力は `AngleX` だけ (横を向く動きはデフォーマを動かさないので根元の平行移動で与える)。`AngleZ`・体の動きは頭のデフォーマを動かすので根元が動く。
    後ろ髪の根元は頭頂ではなく顔の中ほど (頭頂だと `AngleZ` で根元が 60px 以上動き、毛先が首の前まで振れた)。耳飾りは加速度 4 で速く振る (1.5 では遅れすぎて飾りが斜めに伸びて見えた)。
    衝突体は使わない (T0311 の制限があるため。どの鎖も衝突体に届かない)。はじめに作った揺れ用のパラメータ (`HairFront`・`HairBack`) とそれを動かすパラメータの物理はやめた
    (同じ髪を 2 つの仕組みで動かさないため)。パラメータは 27 になった。
  - 眉は PSD のとおり前髪の奥に描く (手前に描くと髪の上に線が浮いた)。そのため眉の動きは前髪の隙間からしか見えない。
  - キャンバスは PSD のまま 1024x1024 (前の見本のような切り詰めはしない)。パラメータ 27、メッシュ 24、デフォーマ 12、物理のリグ 5。レベル 3 (`validate --profile avatar` で `claims level 3, satisfies level 3`)。
  - 補助: `Rig::keyform_at` (任意のセルを読む)・`set_cell` (そのセルの今のキーフォームを変える)・`fade` (キーごとの不透明度)。
- **前の見本 (全身) は残さない:** 置き換えた (`assets/samples/avatar.ugoe` のパスは同じ)。全身の PSD はフィクスチャとして残り、前のジェネレータは T0702 のコミットにある。
  バンドルは約 630KB → 約 1.3MB になった (PSD のテクスチャが大きいため)。`apps/viewer/README.md`・`assets/fixtures/README.md` の大きさを直した。
- ビューアの「サンプル」は同じパスを読むので、コードの変更なしで新しいモデルを開く (ビルドの出力のファイルが `assets/samples/avatar.ugoe` とバイト単位で同じことを確かめた)。

### 目で確かめたこと

- `ugoe render` (Vulkan/dzn) で各パラメータの端と途中の値の一覧を作って見た (`assets/samples/avatar-params.jpg` は 30 コマ)。目は `EyeLOpen` 0/0.2/0.25/0.3/0.33/0.35/0.4/0.5/0.6/0.7 を拡大して見た:
  1→0.4 で細くなり、0.3 以下で閉じた線。0.33 付近の 1 コマだけ、半透明の閉じた目の絵の下側 (灰色の影) が薄く見える (絵に含まれる影で、切り替えの窓を 0.06 に狭めて目立たなくした)。
  口は `MouthOpenY` 0/0.05/0.1/0.15/0.2/0.3/0.45/0.6/1 で、閉じた口 → 細い隙間 → 開いた口と途切れずにつながり、二重に見えない。`MouthForm` ±1、開き 1 との組み合わせ、`JawX`・`MouthX`・すぼめなども見た。
  開いた口の絵は周りに肌の色を含むので、`JawX` や口角を大きく動かすと周りの肌がずれて見える (`JawX` は口の幅の 10% に抑えた)。
  頭 (`AngleX/Y` ±30・`AngleZ` 30)、体、呼吸、髪揺れ ±1、笑顔・驚き・困り顔・視線の組み合わせも見た。
- **揺れもの:** 頭を振るモーション (`AngleX` 0→25→-25→0 を 0.8 秒) と傾けるモーション (`AngleZ` 0→30→0) の JSON を作り、`ugoe render --motion --time` で 0.2〜1.3 秒のコマを物理あり・なしで描いて見比べた
  (`assets/samples/avatar-physics.jpg`)。耳飾りの先が遅れて振れ、金具は耳に付いたまま。前髪は毛先がわずかに、後ろ髪は大きく遅れて揺れ、止めると戻る。
  耳飾りは頭と一緒に傾く (`frame` が頭なので、頭を傾けたまま真下には垂れない。自然に見える範囲)。ビューア (ヘッドレスの Chrome) でも「サンプル」を開いて `AngleZ`・`AngleX` を
  変えた直後と 2.5〜3 秒後のコマを撮り、揺れてから落ち着くことを確かめた。
- **ビューア:** ヘッドレスの Chrome (SwiftShader、webgl2) でビルドした `dist/` を開き、「サンプル」で新しいモデルを開いた。素材は T0703 と同じ Wikimedia Commons の動画・写真 (CC BY-SA 3.0 / CC BY 2.0、リポジトリの外)。
  - 瞬きの動画 (Blinking) をフレームごとの静止画にして入れた: 目を開いた (`EyeLOpen` 0.85) → 半分 (0.64) → ほぼ閉じ (0.33) → 閉じ (0.24、`EyeLSmile` 0.78) の順にモデルの目が閉じ、閉じたときは平らに近い閉じ目になった。
  - あくびの写真で `MouthOpenY` 0.85 → 大きく開いた口。舌を丸める動画で 0.26〜0.30 → 小さく開いた口。オバマ氏の肖像写真で `MouthForm` 0.93 → 口角の上がった閉じた口。
  - 視線 (Va et vient) で `EyeBallX` ±0.9、20° 回した写真で `AngleZ` 19.6 → 頭が傾く。
  - 分かったこと: MediaPipe の `eyeSquint` (→ `EyeLSmile`) は真顔でも 0.45〜0.6、瞬きで 0.7〜0.8 になる。はじめは開いた目の笑い目を強くしていて、真顔でも目が細く、瞬きのたびに笑った閉じ目になったので、
    開いた目の笑い目を弱め、閉じた目は笑い目 0.5 まで平らに保つようにした。キャリブレーションなしの瞬きの `EyeLOpen` は 0.24 程度までしか下がらないが、0.3 以下で閉じるので閉じて見える。

### 並行作業との関係・範囲外の変更

- T0310 (main に入った M3 の受け入れテスト) の `crates/ugoe/tests/m3_puppet.rs` の `avatar_sample_follows_arkit_tracking` が、新しい見本の物理 (揺れ) で最後の
  「中立に戻すと元の見た目に戻る」の検査 (1 フレーム後に完全に戻る) に失敗した。オーケストレーターの承認を得て、このテストでは物理を読み込まないようにした
  (トラッキングからパラメータへの対応付けだけを見るテストなので。コメントに理由を書いた)。そのため `crates:` に `crates/ugoe (tests only)` を足した。
  見本の物理は `sample.rs` の `physics_sways_earrings_and_hair_after_a_head_shake` が確かめる (`Puppet::set_physics` が検証を通して読み込み、頭を振ると耳飾り約 12px・前髪約 5px・後ろ髪約 18px
  遅れ、前髪は後ろ髪の半分未満、6 秒後には物理のない評価との差が 0.5px 未満に戻る。静止しているときは物理のない評価と同じ)。
