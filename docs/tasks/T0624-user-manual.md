# T0624: エディタの操作マニュアル

## 目的

T0619 の確認で、パラメータの作成などの操作方法が分からないという声があった。
利用者 (リガー) 向けの操作マニュアルを用意する。開発者向けの設計文書 (`docs/editor.md`) とは別に、画面の操作の手順として書く。

## 受け入れ条件

- [x] `docs/manual/` に日本語のマニュアルがある。最初の章は `assets/fixtures/character.psd` を使ったチュートリアルで、次を順に通す: PSD から新規作成 → 画面の見方 → メッシュの確認と編集 → デフォーマで包む (顔のワープ・頭の回転) → パラメータの作成 (`AngleX` / `AngleY`、`EyeLOpen` など) → キーの追加 → キーの上での形の編集 → 斜めのセルの自動推定 → 左右のミラー → 深度からの回転 → 保存と `.ugoe` の書き出し → `ugoe render` での確認
- [x] 後半は機能別のリファレンス: 各パネル (ツリー・ビューポート・インスペクタ・パラメータ)、ツールとキーボード操作、マスク、推定の記号 (A / + / R / M / D)、よくある警告とその意味
- [x] 手順は実際のエディタで確かめて書く (ヘッドレスのブラウザでの確認でよい)。画面の画像を入れる場合は小さな PNG にし、`docs/manual/images/` に置く
- [x] T0623 (空のプロジェクトで起動・New from PSD) の挙動に合わせる。T0623 が先にマージされていなければ、その前提の箇所を明示する
- [x] README とエディタのヘルプ (メニューなど) からマニュアルへのリンクがある
- [x] `just ci` が通る

## メモ

- **書いたもの** (`docs/manual/`): `README.md` (目次・起動・表記・今の制限のまとめ)、`tutorial.md` (1 章: `character.psd` で
  取り込み → 画面 → メッシュ → 顔のワープ・頭の回転・目のワープで包む → パラメータ 5 つ → キー → キーの上での形の編集
  (ワープの格子・回転の取っ手) → 斜めの自動推定 → 目のミラー → 深度からの回転 → 保存・書き出し → `ugoe render`)、
  リファレンス `screen.md` (ヘッダー・ツリー・ビューポート・インスペクタ・パラメータ)、`tools.md` (道具とキーボード操作の一覧)、
  `masks.md`、`inference.md` (記号 A / + / R / M / D、Inference・ミラー・深度の各項目)、`warnings.md` (出る場所と、
  取り込み・編集・推定のメッセージの意味と対処)。画像は `images/` に 5 枚 (1000px 幅・64 色、各 26〜52 KB)。
- **リンク:** ルートの `README.md` と `docs/README.md` の一覧、エディタのヘッダーの「Help」(`App.svelte`。押すとマニュアルの
  GitHub の URL を出す)。Tauri v2 は opener プラグインがないと `target="_blank"` のリンクを開かない (はず) ので、URL を
  選んで写せる形にした。実際の Tauri のウィンドウで開くかは確かめていない。
- **T0623・T0626 との関係:** 書いている途中で T0623 (空のプロジェクトで起動・「New from PSD…」) と T0626 (OS の
  ファイルダイアログ) が main に入ったので、rebase して両方の挙動に合わせて書き直し、確認もやり直した (パスの入力欄の
  手順と「T0623 より前」の併記は消した)。
- **確かめたこと:** ビルドした画面 (`vite build`、`just wasm`) をヘッドレス Chrome (SwiftShader の WebGL2・Playwright) で開き、
  Tauri の IPC を本物の `ugoe_editor_core::Document` / `Project` / `import_psd` に中継する使い捨ての HTTP ブリッジ
  (スクラッチ領域、リポジトリ外。空のプロジェクトで起動し、新規・PSD から新規・開く・保存・書き出し・取り込み・座標変換を
  実装) につなぎ、ファイルダイアログは `window.__UGOE_FILE_DIALOGS__` の差し替えで固定のパスを返して、チュートリアルの
  1〜12 をすべて画面の操作で行った。空のプロジェクトの案内、「New from PSD…」(名前 `character`・自動の Fit)、
  「Saved to …」「Exported to …」の表示、書き出しのダイアログの既定の名前 (`character.ugoe`) も確かめた。取り込み (320×400・警告なし・ID `Layer8` など)、頂点の移動・追加・
  削除・Retriangulate、8 メッシュの選択と「Warp」・「Rotation」・名前の変更、回転の中心と取っ手のドラッグ (AngleZ = 30 で
  角度 -17°)、5 つのパラメータの作成、◆ と Home / End でのキーの追加 (格子 `+ A + / A A A / + A +`)、端の 4 セルの
  ギズモでの編集と斜めのセルの値 (基準 + 左右の差 + 上下の差)、目のワープの上の列を Shift + クリックで選んで閉じる、
  パラメータの対なしでのミラーのエラー、`model.json` の書き換え → Open → 「Set partner」→「Overwrite authored cells」→
  「Mirror」で `M M`、Dome 40 (`0 – 35.28 px`) → Depth rotation → 端 4 セルの Mark derived (`R`) → Infer (overwrite
  derived) ですべて `R`、Save・Export、`ugoe info` と `ugoe render --param AngleX=30 --param EyeLOpen=0 --param
  EyeROpen=0` で振り向いて目を閉じた絵。マスク (顔の影 → 顔) の表示と Help の表示も確かめた。
- **確かめていないこと:** 実際の Tauri のウィンドウでの操作と OS のダイアログ (見た目・ボタンの名前)、Help のリンクが Tauri で
  開くか、マスクの「Add」「Invert」「Combine」の操作 (表示だけ確認)、メッシュどうしのミラー。
- **気づいた UX の問題 (後続の候補):**
  1. **パラメータの左右の対 (`Parameter::mirror`) を設定する画面がない。** `EyeLOpen` ↔ `EyeROpen` も `AngleX` の自分自身との
     対も設定できないので、ミラーが実質使えない (チュートリアルは `model.json` の書き換えで回避)。パラメータの編集欄に
     「Mirror」(相手のパラメータ / 自分自身 / なし) の選択を足し、`set_parameter_mirror` を送る。標準の ID (`EyeLOpen` など)
     で作ったときは対を自動で提案するとなおよい。
  2. **初めてのミラーが黙って何もしない。** 先の要素にキーを加えただけのセルは `authored` なので、「Overwrite authored cells」
     なしの「Mirror」は 1 セルも書かず、エラーも出ない。書いたセルの数を出すか、書くセルがないときに理由を出す。キーの追加で
     できたセル (まだ一度も手で編集していないセル) を上書きしてよい扱いにするのも手。
  3. **デフォーマの ID が `Warp`・`Warp_2`・`Rotation` になり、名前を変えても ID は変わらない。** 「Mirror partner」の選択欄と
     「Mirror from」は ID だけを出すので、どれがどれか分からない。PSD の日本語のレイヤーも `Layer8` になり、インスペクタの
     先頭・「Texture」の選択欄も ID。選択欄に名前 (と ID) を出す。「Wrap in deformer」に名前の入力欄を付け、ID を名前から作る。
  4. **パーツを選んで包めない。** 頭のメッシュ 8 つを Ctrl + クリックで 1 つずつ選ぶ必要がある。パーツを選んだら、その中の
     メッシュ (とデフォーマ) を包む対象にする。
  5. **パラメータのパネルがインスペクタの下にあり、要素を選ぶとスクロールしないと見えない。** キーの追加 (◆) はパラメータの
     パネルで行うので、往復が多い。パネルの高さを分けるか、折りたたみを付ける。右の欄が横にはみ出す (「Mirror from」の選択欄)。
  6. **キーの値ちょうどにスライダーを合わせにくい。** 最小・最大は Home / End で合うが、途中の値 (例: 0.5) は数値の入力欄がない。
     値の入力欄か、「+ 値」でキーの値を入力できるようにする。
  7. **回転の中心をキーの追加後に動かすと、今のセルの中心だけが動く。** 中心は全セル共通で動かしたいことが多い。
     全セルに同じ移動を加える操作 (Shift など) を足す。
  8. **デフォーマを消すと子も消さないといけない (子が残ると拒否)。** 「包むのをやめる」(子を親へ戻して見た目を保つ) 操作がない。
  9. **目を閉じる形を作る道具が粗い。** フォーム編集は 1 点か Shift で全点しか動かせず、メッシュの一部をまとめて動かせない
     (T0608 の後続の候補と同じ)。ワープで包む手順にした。
  10. **開く (Open) の後もスライダーの値が前のプロジェクトのまま残る。** 開いたら既定値に戻す。
  11. **Undo / Redo のキーボードショートカット (Ctrl + Z / Ctrl + Shift + Z) がない。**
  12. **パラメータの対をファイルで直すときの手順が重い** (保存 → 外部のエディタで書き換え → 開き直す)。1 が入れば不要。
  13. Help のリンクは Tauri で開けない可能性が高い。`tauri-plugin-opener` を入れて外部ブラウザで開く (依存とライセンスの確認が要る)。
