# T0624: エディタの操作マニュアル

## 目的

T0619 の確認で、パラメータの作成などの操作方法が分からないという声があった。
利用者 (リガー) 向けの操作マニュアルを用意する。開発者向けの設計文書 (`docs/editor.md`) とは別に、画面の操作の手順として書く。

## 受け入れ条件

- [ ] `docs/manual/` に日本語のマニュアルがある。最初の章は `assets/fixtures/character.psd` を使ったチュートリアルで、次を順に通す: PSD から新規作成 → 画面の見方 → メッシュの確認と編集 → デフォーマで包む (顔のワープ・頭の回転) → パラメータの作成 (`AngleX` / `AngleY`、`EyeLOpen` など) → キーの追加 → キーの上での形の編集 → 斜めのセルの自動推定 → 左右のミラー → 深度からの回転 → 保存と `.ugoe` の書き出し → `ugoe render` での確認
- [ ] 後半は機能別のリファレンス: 各パネル (ツリー・ビューポート・インスペクタ・パラメータ)、ツールとキーボード操作、マスク、推定の記号 (A / + / R / M / D)、よくある警告とその意味
- [ ] 手順は実際のエディタで確かめて書く (ヘッドレスのブラウザでの確認でよい)。画面の画像を入れる場合は小さな PNG にし、`docs/manual/images/` に置く
- [ ] T0623 (空のプロジェクトで起動・New from PSD) の挙動に合わせる。T0623 が先にマージされていなければ、その前提の箇所を明示する
- [ ] README とエディタのヘルプ (メニューなど) からマニュアルへのリンクがある
- [ ] `just ci` が通る
