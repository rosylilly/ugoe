# T0311: 動的物理: 衝突のすり抜けと節の伸びを防ぐ

## 目的

T0310 (M3 の受け入れテスト) で見つかった問題を直す。
衝突体の押し出しは距離拘束の後に法線方向へ粒子を動かすので、節が伸びる (例: 30px → 39.6px)。`deformer_angle` の出力は向きだけを渡し、描く節の長さは元のままなので、描かれた関節が衝突体にめり込む。
また、静止の姿で衝突体に入っている髪は、最初の落ち着かせで衝突体の反対側 (下側) に押し出され、剛体の鎖では戻れない。

## 受け入れ条件

- [ ] 押し出しの後も節の長さを保つ (親のまわりの回転で外に出すなど)。描かれる関節が衝突体の中に入らないテスト
- [ ] 1 ステップで衝突体をすり抜けない (連続的な判定か、進んだ向きの側へ押し出す)。静止の姿で衝突体に入っている場合の扱いを決め、`validate_physics` か取り込み時の警告で知らせる
- [ ] `fixtures::dynamic_hair` の肩のカプセルが静止の姿で髪に入っていないようにする
- [ ] 決定性のテストを保ち、動的でない物理の結果を変えない
- [ ] `docs/spec/physics.md` を更新し、`just ci`・`just wasm-check` が通る
