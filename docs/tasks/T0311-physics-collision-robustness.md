# T0311: 動的物理: 衝突のすり抜けと節の伸びを防ぐ

## 目的

T0310 (M3 の受け入れテスト) で見つかった問題を直す。
衝突体の押し出しは距離拘束の後に法線方向へ粒子を動かすので、節が伸びる (例: 30px → 39.6px)。`deformer_angle` の出力は向きだけを渡し、描く節の長さは元のままなので、描かれた関節が衝突体にめり込む。
また、静止の姿で衝突体に入っている髪は、最初の落ち着かせで衝突体の反対側 (下側) に押し出され、剛体の鎖では戻れない。

## 受け入れ条件

- [x] 押し出しの後も節の長さを保つ (親のまわりの回転で外に出すなど)。描かれる関節が衝突体の中に入らないテスト
- [x] 1 ステップで衝突体をすり抜けない (連続的な判定か、進んだ向きの側へ押し出す)。静止の姿で衝突体に入っている場合の扱いを決め、`validate_physics` か取り込み時の警告で知らせる
- [x] `fixtures::dynamic_hair` の肩のカプセルが静止の姿で髪に入っていないようにする
- [x] 決定性のテストを保ち、動的でない物理の結果を変えない
- [x] `docs/spec/physics.md` を更新し、`just ci`・`just wasm-check` が通る

## メモ

- やったこと
  - 衝突を「押し出し」から「親のまわりの回転 (掃引)」に変えた (`collider::constrain_segment`)。区間をステップの始めの向きから距離拘束の後の向きへ
    近い側に回し、最初に当たる手前で止める (刻み `min(10 度, 最小半径 / radius)` で調べ、二分法 16 回で詰める)。区間の長さが変わらないので、
    `deformer_angle` で描く関節は粒子の上にあり、1 ステップで衝突体をすり抜けない。当たりは粒子 (半径 + `collision_radius`) と区間の線分
    (衝突体そのもの) で判定する。始めの向きで当たっていれば最も近い当たらない向きから回し、どの向きでも当たるときだけ従来の押し出しに戻る。
  - `Chain::step`・`Chain::settle` のフックの引数を `(&Segment, &mut Vec2)` にした (`Segment { index, parent, from }`)。静止姿勢に置くときの
    始めの向きは粒子の初期位置の区間の向き。
  - 静止姿勢で衝突体に入っている場合: 髪は衝突体の手前で止まり、衝突体に沿って置かれる (反対側に抜けない)。
    `PhysicsSystem::rest_pose_collisions` (`RestPoseCollision { rig, particle, collider }`) で知らせる。`validate_physics` はエラーしか返さず
    (エラーがあると `read_bundle` が読み込みに失敗する)、衝突体の位置はデフォーマの評価が要るので、ランタイムの検査にした。
  - `fixtures::dynamic_hair_settings` の肩を静止姿勢の髪の右側 (ワールド `(163,150)`–`(198,170)`) に移した。頭を右へ振ると当たる。
  - 動的でない物理 (`physics_hair`) と衝突体のない動的物理の結果が main とビット単位で同じことを、300 フレームの軌跡を比べて確かめた
    (一時的なテストで確認し、コミットはしていない)。決定性のテストはそのまま通る。
  - 頭を振る場面で、描かれる関節と肩の距離の最小値は 9.7px (半径 + 衝突半径 = 10)。残りは出力の補間 (最大 1 ステップの遅れ) の分。
  - 仕様書: `docs/spec/physics.md#衝突体` を書き直し、「静止姿勢で衝突体に入っている場合」を追加。`docs/manual/physics.md`・ugoe-physics の README も更新。
- 範囲外の変更 (team-lead の承認済み): `crates/ugoe/tests/m3_puppet.rs`。フィクスチャの肩の座標を直書きしていたので新しい座標に合わせ、
  T0310 のメモのとおり描かれる関節の許容を「肩の円そのもの」から「半径 + 衝突半径 - 1px」に厳しくした。このため `crates:` に `ugoe` を足した (テストのみ)。
- 後続の候補
  - `rest_pose_collisions` を `ugoe validate`・取り込み・エディタ (物理のパネル) の警告につなぐ。
  - 刻みより細い部分をかすめる当たりは見逃し得る (深い食い込みは見逃さない)。必要なら円・カプセルと回転する線分の解析的な判定にする。
  - 衝突体の位置をフレームの中のステップで補間する (今は 1 段目の位置で固定。衝突体が速く動くと始めの向きで当たり、最も近い向きへ回すことになる)。
