# T0008: コードレビュー: 横断の所見のまとめと後続の整理

## 目的

M9 の各レビューのタスクがメモに残した「横断」の所見 (複数のクレートやアプリにまたがるもの) と、起票された後続のタスクを整理する。
同じ種類の問題が複数の場所にあれば 1 つのタスクにまとめ、規約や手順に足すべきことを文書に反映する。

## 受け入れ条件

- [ ] 各レビューのタスクのメモの「横断」を読み、種類ごとにまとめた表を docs/workflow/code-review.md の末尾 (「M9 の結果」) に書いた
- [ ] 重複した後続のタスクを 1 つにまとめた (まとめた側を残し、もう一方は理由を書いて閉じる)
- [ ] 繰り返し見つかった種類の誤りを、AGENTS.md・docs/workflow/code-review.md の観点・lint や検査のスクリプトで防げるかを検討し、防げるものはそうするか起票した
- [ ] docs/roadmap.md の M9 に、後続のタスクの一覧と M9 の完了の判断を書いた
- [ ] `just ci` が通る
