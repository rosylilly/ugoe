# T0601: エディタのコマンド群

## 目的

パーツ・デフォーマ・メッシュ・キーフォームを追加・削除・変更するコマンドを実装する。

## 受け入れ条件

- [x] 各コマンドに、成功・失敗・Undo のテストがある
- [x] パラメータの削除時に、そのパラメータを参照するキーフォームの軸も削除する
- [x] コマンドの適用後のモデルが常に `validate` を通る
- [x] `just ci` が通る

## 参考

- `docs/editor.md#コマンド`

## メモ

- コマンド一覧と、削除時の連鎖 / 拒否の規則は `docs/editor.md#コマンド` に書いた。
  - パラメータの削除: 軸を既定値のキー (なければ最も近いキー、等距離なら小さい方) の断面に畳む。`mirror` とエフェクトの参照も外す。
  - パーツ・デフォーマの削除: 子が残っていれば拒否 (`EditError::HasChildren`)。パーツはポーズから取り除く。
  - メッシュの削除: マスクの参照から外し、グルーと当たり判定を削除する。
- `Document::apply` は「適用前になかった検証エラー」が生じたら拒否する。不正なモデルを読み込んだ場合でも、エラーを直す編集はできるようにするため (厳密に「検証を通ること」を求めると、何も編集できなくなる)。
- `EditError` の `DuplicateParameter` / `ParameterNotFound` は、種類を持つ `DuplicateId` / `NotFound` にまとめた (外部の利用者は `to_string()` だけなので影響なし)。
- ID の生成は `ugoe_editor_core::ids`。
- T0108 (キーフォームの由来・`mirror`) への追従: 軸を畳むときは `origins` も同じセルを残し、
  深度からの回転の `yaw` / `pitch` が消したパラメータなら外す (推定の設定そのものは残す)。
  `set_mesh_keyform` で編集したセルは `authored` にする。メッシュ・デフォーマの削除では、相手の `mirror` を外す。
  パラメータの自分自身とのミラー (符号の反転) は T0108 の仕様に合わせて許す。
- 後続の候補: パラメータグループの追加・削除、ID の変更 (参照の一括書き換え)、メッシュのトポロジー (`uvs` / `indices`) の変更、ワープの `rows` / `cols` の変更、デフォーマの 1 セル編集。
