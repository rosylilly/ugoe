# T0618: 親が異なる左右の対のミラー

## 目的

今のミラーは、ミラー元の親の座標系で反転した値を、そのままミラー先に書き込む。そのため、左右の対の親が異なる場合 (例: 左右の髪が別々のデフォーマの下にある、片方だけ付け替えた) には、正しく反転できない。自動のミラーのし直しも、警告を出して止まる (T0615 のメモ)。

左右の髪やアクセサリーは別々のデフォーマの下に置くことが多いので、親が異なっても使えるようにする。

## 受け入れ条件

- [ ] 親が異なる対では、ミラー元の点をキャンバス座標に写し (既定の姿勢 = 各キーのセルの姿勢)、対称軸で反転し、ミラー先の親の座標系に戻して書き込む (T0615 のランタイムの API と、editor-core の逆写像を使う)。親が同じ対は、今の方式と同じ結果になる
- [ ] 対称軸はキャンバス座標で解釈できる (要素ごとの `mirror_axis` の扱いを仕様で明確にする)
- [ ] 頂点の対応付けも、親が異なる場合はキャンバス座標で行う
- [ ] 片方だけ付け替えた対で、ミラー元の編集によって自動でミラーし直され、警告が出ないテストがある
- [ ] 親が異なる対を付け替えたとき、または頂点が対応しなくなったときは、付け替えの時点で警告を出す
- [ ] `docs/spec/keyform-inference.md#ミラー` を更新する
- [ ] `just ci` が通る
