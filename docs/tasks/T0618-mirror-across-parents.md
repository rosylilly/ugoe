# T0618: 親が異なる左右の対のミラー

## 目的

今のミラーは、ミラー元の親の座標系で反転した値を、そのままミラー先に書き込む。そのため、左右の対の親が異なる場合 (例: 左右の髪が別々のデフォーマの下にある、片方だけ付け替えた) には、正しく反転できない。自動のミラーのし直しも、警告を出して止まる (T0615 のメモ)。

左右の髪やアクセサリーは別々のデフォーマの下に置くことが多いので、親が異なっても使えるようにする。

## 受け入れ条件

- [x] 親が異なる対では、ミラー元の点をキャンバス座標に写し (既定の姿勢 = 各キーのセルの姿勢)、対称軸で反転し、ミラー先の親の座標系に戻して書き込む (T0615 のランタイムの API と、editor-core の逆写像を使う)。親が同じ対は、今の方式と同じ結果になる
- [x] 対称軸はキャンバス座標で解釈できる (要素ごとの `mirror_axis` の扱いを仕様で明確にする)
- [x] 頂点の対応付けも、親が異なる場合はキャンバス座標で行う
- [x] 片方だけ付け替えた対で、ミラー元の編集によって自動でミラーし直され、警告が出ないテストがある
- [x] 親が異なる対を付け替えたとき、または頂点が対応しなくなったときは、付け替えの時点で警告を出す
- [x] `docs/spec/keyform-inference.md#ミラー` を更新する
- [x] `just ci` が通る

## メモ

- **逆写像の置き場所:** 親の座標系 ↔ キャンバス座標の写像 (ランタイムの `WorldTransform`) とニュートン法の逆を、
  editor-core の `space.rs` から `ugoe_rigging::ParentWorld` (`crates/ugoe-rigging/src/world.rs`) へ移した。
  `ugoe-rigging` は `ugoe-runtime` に依存する (層の規則で許されている)。editor-core の `space.rs` は薄い包みに
  なり、エラーは `SpaceError` に写す (既存のテストは変更なしで通る)。こうすると `mirror_keyforms` だけで
  親が異なる対を扱え、CLI や AI からも使える。`deformer_edit.rs` の逆写像 (歩幅を半分にするニュートン法、
  まだモデルにないデフォーマの写像) は別物なので残した。
- **姿勢:** 元のセル `s` は「元の格子の軸のパラメータを `s` のキー、残りを既定値」、先のセル `t` も先の格子で同様
  (自分自身と対にした `AngleX` なら元は +30、先は −30 の姿勢)。親の祖先が格子の軸にないパラメータで動くと、
  そのパラメータが既定値以外の姿では対称にならない (仕様に書いた)。
- **対称軸 (親が異なる対):** キャンバス座標の縦の直線。`mirror_axis` / `axis` を指定していれば、既定値の姿勢で
  元の基準のセルの点の重心の高さの 1 点をキャンバスへ写した x (付け替えが `mirror_axis` を写し直すのと同じ近似)。
  指定がなければキャンバスの原点。親の既定値 (ワープの 0.5 など) は、別々の親の中心がふつう対称軸でないので使わない。
  許容距離はキャンバスのピクセル (既定 1px。指定値は元の親の単位からピクセルに換算)。
- **回転デフォーマ:** 原点は点として写し、角度・拡大率は `F·W·F` (キャンバス座標のワールド変換の反転) に先の
  ワールド変換が一致するように解く (親の拡大率の違いは拡大率で補う)。角度は −θ から ±180° 以内を選ぶ。
- **親が同じ対:** 以前と同じコードの道筋 (親の座標系で反転) で、結果はビット単位で同じ
  (`same_parent_pairs_keep_the_parent_space_formula`、既存の `tests/mirror.rs` も変更なし)。
- **付け替えの警告:** コマンドの前後で親が変わったメッシュ・デフォーマ (付け替え・`CreateWarpDeformer` などで包む)
  について、対の相手とのミラー (相手をミラー元にし `mirror` のセルを持つ格子) を `check_mirror` (書き込まない版)
  で試し、前はできて後はできなくなったら `RederiveWarning` を返す (自動の作り直しの警告と同じ組は重ねない)。
  典型は、同じワープの下で `mirror_axis` を省略した対の片側を外へ出したとき (ワープの中心がキャンバスの原点に
  なければ、対称軸が変わって対応しなくなる)。
- **T0615 のテストの変更:** `reparenting_a_mirror_target_keeps_its_cells_and_source` は、片側だけ付け替えた後の
  ミラー元の編集で警告が出ることを確かめていた。キャンバス座標を経由するようになったので、警告なしにミラーし直され、
  付け替えずに編集した結果をキャンバス座標へ写したものと一致することを確かめるように変えた。
- **テスト:** `crates/ugoe-rigging/tests/mirror_parents.rs` (別々のワープの下のメッシュ、回転 × ワープ・キャンバス
  直下の組み合わせ、親が異なるワープ・回転デフォーマの対、明示した対称軸、許容距離、扱えない親。結果はランタイムで
  評価した姿が左右対称になることで確かめる)、`inference_tests.rs` の末尾 (新しいワープで片側を包む、
  中心のずれた対の付け替えの警告と `SetMirrorPair` での直し方、ミラー元の付け替えで警告が 1 つ、対のない要素・
  前から壊れていた対では警告しない)。
- **後続の候補:**
  - ミラー元を付け替えても、依存する格子の `mirror_source.axis` (元の親座標系で記録した値) は写し直さない。
    付け替えで `mirror_axis` と同じように写し直すとよい (今は警告で分かる)。
  - 親が異なる対の写像は、セルごとに親の祖先だけのモデルを評価し直す (コンパイルは要素ごとに 1 回)。格子が大きい
    場合に重ければ、姿勢が同じセルをまとめられる。
