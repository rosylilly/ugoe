# T0916: UI 品質: デザインの見直し (トークンと部品の見た目)

## 目的

3 つのアプリの見た目の土台 (デザイントークンと @ugoe/ui の部品の見た目) を見直し、画面の密度・階層・状態の見せ方を揃える。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [x] トークン (余白の段・文字の段と行の高さ・色・角丸・影・境界線) を見直し、使われていない・重複したトークンを整理した。変えたものは docs/ui.md の表とコントラストの比を更新した
- [x] 部品の状態 (通常・hover・押下・フォーカス・選択・無効・エラー・読み込み中) の見せ方を、すべての部品で揃えた (見本の画面 `pnpm --filter @ugoe/ui gallery` で確かめる)
- [x] アイコンの大きさ・線の太さ・揃えの規則を決め、3 つのアプリで揃えた
- [x] 密度 (`compact`) の使い分けを docs/ui.md に書いた (エディタの密な行・ビューアとスタジオの余裕のある画面)
- [x] アプリの CSS に残った自前の色・余白の直書きを、トークンに置き換えた (または残す理由を書いた)
- [x] `just ui-audit` で 3 つのアプリに新しい崩れが無い
- [x] `just ci` が通る

## メモ

- **やったこと:**
  - トークン (`packages/ui/src/tokens.css`): hover と押下の重ね (`--ugoe-color-hover` 6%・`-active` 12%・`--ugoe-overlay-*`)、
    `--ugoe-opacity-disabled`・`--ugoe-focus-offset`・`--ugoe-icon-size` (16 / 18px)・`--ugoe-icon-stroke`、分類の色 `--ugoe-color-hue-*` (6 色。
    どの地にも 4.5 以上) を足した。`-soft` の 3 色を `surface` に混ぜる形に (強調色とそろえた)、本文の行の高さを 1.4 → 1.5 に。
    `.ugoe-icon` (線のアイコン) と、文字の欄の `aria-invalid` の印を tokens.css に置いた。使われていないトークンは無かった。
    `tokens.test.ts` で、ダークの 2 か所の宣言の一致・ライトとダークの名前の一致・未使用と未宣言のトークンが無いことを確かめる。
  - 部品: hover / 押下 / 無効 / フォーカスの離れをすべての部品で同じトークンに (前は部品ごとに地を sunken・surface にする・文字色だけ・何もしない、
    無効は薄くする・控えめな文字の 2 通り)。`Button`・`IconButton` に `busy`、`NumberField` に `invalid` を足し、`Icon` を公開した
    (閉じる・上下・再生・停止・コマ送り・キー・設定など)。見本の画面に実行中・誤り・hover / active の色を足した。テストを足した。
  - アプリ: エディタの CSS の余白・文字・角丸の直書き (約 140 か所) をトークンに。エディタのボタンの中の文字の記号 (×・▲・▼・↻・◀・▶・■・◆・▾・▸) と
    ビューア・スタジオの手描きの SVG を `Icon` に。エディタの直書きの色 (ツリーの種類・キーの由来・イベントの印・再生位置) を `hue-*` と `danger` に。
    エディタの根元の行の高さを部品の 1 行に、文 (`p`・`li`・`dd`・`.ed-hint`) を本文の行の高さに (前はブラウザの normal で、説明の段落が詰まっていた)。
    スタジオのシーンの一覧の操作の並びとシーンの編集の「モジュールを足す」「配置を戻す」の `small` を外した (T0915 の振り分け)。
  - docs/ui.md: 色の表 (hover・active・hue と比)、余白・文字・角丸の表、「アイコン」「密度の使い分け」の節、状態の表 (トークンと部品の列)、
    「トークンと部品の見直し (T0916)」(残した直書きと理由の表)。移行の対応表 (`--bg` など) は消した。packages/ui/README.md に `Icon`。
- **`just ui-audit` (`--compare target/ui-audit-before`):** 3 つのアプリとも +0 (新しい崩れ無し)。行の高さを直した後のエディタは
  -1 (ポーズのタブの `h3.add` の重なりが消えた)・`button.item` の 24px 未満が 8 → 4 か所。基準線 (この作業の前、main 548d29fb):
  エディタ 重なり 5 (33)・24px 未満 8 (558)・Tab 1・ARIA 1 (10)、ビューア Tab 1・ARIA 1 (28)、スタジオ 0。T0915 のメモの基準線より
  エディタの重なりが 1 → 5 種類に増えている (ポーズのタブ。T1626 などで増えたもの。この作業のものではない)。
- **見た目の確かめ:** `just ui-shots` (見本の画面。両方のテーマ・密度・言語) と ui-audit の画像を見た。hover と押下はヘッドレスの撮影では
  撮れないので、比の計算 (docs/ui.md の色の表) だけで確かめた。実物の WebView では見ていない (T0919)。
- **やらなかったこと:** 押せる大きさ・重なり・Tab の止まり・ARIA の件数 (T0674・T0675・T0673・T0725 の範囲)。ビューポートの上の図の色
  (描画の中身。docs/ui.md の例外)。文言の先頭の「+ 」(「+ リグ」など。文字の記号だが文言の一部なので残した)。
- **起票の候補:**
  - エディタのボタンの文言の先頭の「+ 」(`+ Rig`・`+ Key` など 10 ほど) を `Icon name="plus"` にするか、記号を外すかを決めてそろえる。
  - ポーズのタブの文字の重なり (`button.name "Wave"` と説明・`span.count`・`span.pick` がチェックボックスのラベルに重なる。T0915 の基準線の後に増えた)。
  - `Select` にも `invalid` を足す (いまは `NumberField` と文字の欄だけ)。
  - ビューポートの上の図の色 (ギズモ・物理・グルー・光源) を、ビューポートの図のための色のトークン (テーマに依らない) にまとめる。
