# T0916: UI 品質: デザインの見直し (トークンと部品の見た目)

## 目的

3 つのアプリの見た目の土台 (デザイントークンと @ugoe/ui の部品の見た目) を見直し、画面の密度・階層・状態の見せ方を揃える。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [ ] トークン (余白の段・文字の段と行の高さ・色・角丸・影・境界線) を見直し、使われていない・重複したトークンを整理した。変えたものは docs/ui.md の表とコントラストの比を更新した
- [ ] 部品の状態 (通常・hover・押下・フォーカス・選択・無効・エラー・読み込み中) の見せ方を、すべての部品で揃えた (見本の画面 `pnpm --filter @ugoe/ui gallery` で確かめる)
- [ ] アイコンの大きさ・線の太さ・揃えの規則を決め、3 つのアプリで揃えた
- [ ] 密度 (`compact`) の使い分けを docs/ui.md に書いた (エディタの密な行・ビューアとスタジオの余裕のある画面)
- [ ] アプリの CSS に残った自前の色・余白の直書きを、トークンに置き換えた (または残す理由を書いた)
- [ ] `just ui-audit` で 3 つのアプリに新しい崩れが無い
- [ ] `just ci` が通る
