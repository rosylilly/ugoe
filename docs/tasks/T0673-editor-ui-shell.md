# T0673: エディタ UI: 外枠 (ヘッダー・ツールバー・パネルの配置・ダイアログ・設定)

## 目的

エディタの外枠の配置とレイアウトを見直す。初めて開いた人が、どこで何をするかを迷わない画面にする。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [x] ヘッダー・ツールバー・左右のパネル・ビューポート・タイムラインの配置と大きさの既定を見直した (よく使う操作が近く、まれな操作が奥にある)。1024px でヘッダーが 2 行に折り返す件を解消するか、理由を書いた
- [x] パネルの分割と開閉・大きさの変更がキーボードでもでき、大きさが保存される
- [ ] 空の状態 (プロジェクトなし・パーツなし・パラメータなし) に、次にやることへの導線がある
- [x] ダイアログ (新規・書き出し・設定・外からの変更・基準の変更など) の配置・ボタンの順・既定のボタン・Esc の挙動を揃えた
- [x] エディタにアプリのライセンス (third-party-notices) を出す口を足した (ビューア・スタジオと同じく「設定」から)
- [x] 読み込み中・保存中・エラーの見せ方を揃えた
- [x] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [x] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [x] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [x] `just ci` が通る

- **やったこと:**
  - ヘッダー: ファイルの操作 (New・New from PSD…・New Module…・Open…・Open Sample…・Save・Save As…・Import PSD…) を `@ugoe/ui` の `Menu` の「File」に
    まとめ (New Module・Open Sample の説明は項目の説明の行)、Save・Export…・Undo・Redo・プロジェクト名だけを左に、Preview・Agents・Settings・Help を
    右に残した。版はヘッダーから設定の「General」へ。保存・別名で保存・開くのショートカット (Ctrl / Cmd + S・Shift + S・O。入力欄とダイアログの中では
    効かない。`shortcuts.ts` の `fileShortcut`) を足し、メニューの項目にも出した。**1024px・200% の拡大でもヘッダーは 1 行** (前は 2 行・3 行)。
  - 列の大きさ: 左右の列の幅・タイムラインの高さを、右の列の上下の配分と同じく区切りで変えて覚える (`lib/ui/Splitter.svelte`・`lib/layout.ts` の
    `SizeRange`)。ポインタ・矢印・Home・End、Enter とダブルクリックで既定。区切りにフォーカスの輪を出す (T0915 の振り分け)。窓の幅の割合でも抑えて
    ビューポートを潰さない。タイムラインの開閉は前から覚えている (`TimelinePanel` の `open` を App に bind した)。
  - 右の列: パネルの `<h2>` (タブと同じ名前) を見た目では隠した (`ugoe-visually-hidden`)。中身を `role="tabpanel"` で包んだ。設定の「General」の `<h3>` も同じ。
  - 空の状態: 空のプロジェクトのビューポートに文と「New from PSD…」(primary)・「Open…」・「Open Sample…」のボタン (編集の道具は隠す)。パラメータの
    無いモデルのパラメータ一覧に文と「Add parameter」。
  - ダイアログ: 並び・primary・danger・Esc は前からそろっていたので、表にして docs/editor.md#ダイアログ に書いた。新しいモジュールとモジュールの設定は
    名前の欄の Enter で決定 (`<form>` の送信)。ライセンスに閉じるボタン。
  - ライセンス: `LicenseDialog` を `lib/` へ移し (文言は `license.*`)、設定の「General」の「About the ugoe editor」から開く (版も出す)。プレビューの中の口はそのまま。
  - 読み込み中と失敗: ファイルの読み書きの間 (選んだ後) はヘッダーに「Saving…」などの文 (`role="status"`。`FileMenuFlow.activity`、fileMenu.test.ts)。
    編集の失敗 (`doc.error`) を右の列の上の赤い文から、閉じられる `Notice` の `danger` (見出し・本文・直し方) に。表は docs/editor.md#読み込み中と失敗の見せ方。
