# T0673: エディタ UI: 外枠 (ヘッダー・ツールバー・パネルの配置・ダイアログ・設定)

## 目的

エディタの外枠の配置とレイアウトを見直す。初めて開いた人が、どこで何をするかを迷わない画面にする。
基準は docs/ui.md (T0915 で足す「UI の品質の基準」を含む)。直せないもの・大きいものは後続のタスクにする (milestone は M10)。

## 受け入れ条件

- [ ] ヘッダー・ツールバー・左右のパネル・ビューポート・タイムラインの配置と大きさの既定を見直した (よく使う操作が近く、まれな操作が奥にある)。1024px でヘッダーが 2 行に折り返す件を解消するか、理由を書いた
- [ ] パネルの分割と開閉・大きさの変更がキーボードでもでき、大きさが保存される
- [ ] 空の状態 (プロジェクトなし・パーツなし・パラメータなし) に、次にやることへの導線がある
- [ ] ダイアログ (新規・書き出し・設定・外からの変更・基準の変更など) の配置・ボタンの順・既定のボタン・Esc の挙動を揃えた
- [ ] エディタにアプリのライセンス (third-party-notices) を出す口を足した (ビューア・スタジオと同じく「設定」から)
- [ ] 読み込み中・保存中・エラーの見せ方を揃えた
- [ ] T0915 の監査 (`just ui-audit`) で、範囲の画面のコントラスト・はみ出し・押せる大きさ・名前の無い部品が 0 件 (残すものは理由を docs/ui.md に書く)
- [ ] 見直しの前と後のスクリーンショット (ライト・ダーク × 日英 × 広い幅・狭い幅) を比べ、メモに要点を書いた
- [ ] 画面が変わったところを、マニュアル (docs/manual/) の文と画像の更新の候補として T0919 のメモに書き足した
- [ ] `just ci` が通る
