# T1664: エディタ: ビューポートでグルーの組にポインタを乗せると、パネルの組の行を強調して一覧をその行へ送る

## 目的

T1651 で、グルーのパネルの組の行にフォーカス・ポインタを置くと、ビューポートでその組を強調するようにした (パネル → ビューポート)。
逆向き (ビューポートの組の線・頂点 → パネルの行) が無いので、絵で見つけた組が一覧のどの行かが分からない。双方向に結び付ける。

## 受け入れ条件

- [ ] ビューポートのグルーの重ねで組の線か頂点にポインタを乗せると、パネルのその組の行を強調し (T1651 の行の強調と同じ見た目)、
      一覧がその行を見える所まで送る (送るのはポインタが止まったとき・行が見えていないときだけなど、一覧が暴れない条件を決めてメモに書いた)。
      離れると戻る。ビューポートの側でもその組を強調する (T1651 の `highlightedPair` に合わせる)
- [ ] 強調は表示だけで、Command を送らない。「Add pairs」「Remove pairs」の道具の操作 (押して組を足す・外す) を妨げない
- [ ] 部品のテスト: 重ねの組に乗せると強調する組が決まり、パネルの行が強調されて送られる。離すと消える
- [ ] docs/editor.md のグルーの画面 (「組の強調」) と docs/manual/dress-up.md のグルーの節に逆向きの強調を書いた
- [ ] `just ui-audit --only editor` (`-glue-edit` を含む組) で増えた指摘が無い。`just e2e --only editor` と `just ci` が通る
