## メモ

### やったこと

- `src/player.test.ts` の偽の WebPuppet (Proxy) を状態付きにした (モジュールの読み込み・付け外し、モーションの再生と終わり、パラメータの値、
  トラッキング・受け手の口の呼び出しの記録)。`requestAnimationFrame` を捕まえて `step(now)` でフレームのループを 1 回ずつ進め、
  localStorage はテストごとに空の偽物 (`vi.stubGlobal`) にした。T0914 のテストはそのまま通る。
- 足したテスト (24 件):
  - 着せ替えの組: 起動し直して開いたときに尋ねて場所から戻す・`autoRestore`・読み直せないときに覚えた組を残す・同じモデルを開き直したとき・
    戻す前に開き直したとき (尋ねている・戻さなかった)・合わなくなったモジュールが外れたとき覚え直す・別のモデルへ替えて戻ったとき
    (このセッションの中身から戻す)・着せ替えを操作したら尋ねるのをやめて覚え直す・開けなかったとき (モジュールと尋ねている組が残る)
  - モーション: 開いたときに待機・終わったら待機へ戻る・繰り返し (同じ優先度)・止めたとき・始まらなかった理由とその消去・待機の自動再生の切り替えと
    モデルごとの選択
  - ドライバとトラッキング: `driven` (ドライバ・トラッキング・再生中のモーション)、スライダーの無視、入力を 1 回だけ渡す、止めたら既定値へ、
    モーションの優先 (`set_motion_over_tracking`)、`set_tracking_kept` を渡し直す時
  - 受け手のモード: モデルを読む前・WebPuppet を作っている間に届いたフレームを読み終えた後に順に適用 (前のシーンは捨て、次のシーンは待たせる)、
    `seq` が飛んだら物理のリセット、シーンを続けたとき、`followScene` の後でモデルを読んだときは描く前に適用、溢れた数と描画の負荷の知らせ、
    覚えた組と光源を使わず覚えない、受け手の口が無いときのエラー
  - 光源: ドラッグの途中は描くだけで覚えず確定で覚える、途中で別のモデルを開くと前のモデルの設定として覚える、忘れた後に覚え直さない
- **直したバグ:** 同じモデルをモジュールなしで開き直すと、いまの組を覚え直していた。戻すか尋ねている間・「今回は戻さない」の後・戻せなかった後は
  いまの組が空なので、覚えていた組が消えていた (ビューアの README の「尋ねている間は覚え直さず、『今回は戻さない』でも覚えている組は変えない」
  に反する。尋ねている組は画面に残るのに `dressUpRemembered` が偽になる)。付けているものが変わったとき (合わなくなって外れた) だけ覚え直すようにした
  (`load`。先に失敗するテストを入れてから直した)。
- `just ci` は通った。

### やらなかったこと

- 表情 (`setExpression` など)・ビューの操作 (`zoomBy`・`panBy`)・`capture`・覚えたものの一覧 (`rememberedModels`) は、Player を通すテストを足していない
  (薄い受け渡しで、部品の関数のテストがある)。
- 偽の WebPuppet は wasm の振る舞いの一部しか真似ない (スロットの公開・依存の検査・モーションの時間などは無い)。
