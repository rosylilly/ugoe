# T0607: エディタ: デフォーマの作成とギズモ

## 目的

選択したメッシュやデフォーマを包むワープデフォーマ・回転デフォーマを作り、ビューポートのギズモで制御点・原点・角度を編集できるようにする。

## 受け入れ条件

- [ ] 選択した要素の外接矩形からワープデフォーマ (行数・列数を指定) を作り、子の座標を新しい局所座標系に変換して付け替える `Command` がある。見た目 (評価結果) が変わらないことをテストする
- [ ] 回転デフォーマを作り、子を付け替える `Command` がある (同じく見た目が変わらない)
- [ ] ビューポートで、ワープの制御点 (複数選択と一括移動)、回転デフォーマの原点・角度・拡大率をギズモで編集できる。編集は現在のパラメータ値のキーフォームに書き込む (キーの上にいないときの扱いは T0608 と揃える)
- [ ] `just ci` が通る
