# T0633: エディタ: 描画順を変えるための複製 (形を共有する)

## 目的

顔を大きく振ると、横髪や耳と輪郭の前後関係が入れ替わる。描画順をキーフォームで切り替えると、入れ替わる瞬間にちらつくので、
Live2D の実践では同じパーツを複製して輪郭を「サンドイッチ」し、マスクで片方ずつ見せている (参考の記事 2・3)。複製は元と同じ変形を手で付け直す必要があり、手間と食い違いの元になる。

ugoe ではモデルの形式を変えずに、グルー (`weight = 0`・`intensity = 1` で、複製の頂点を元の頂点に一致させる) で形を共有できる。
これをエディタの 1 つの操作にし、複製には描画順・マスク・不透明度だけを持たせる。

## 受け入れ条件

- [x] コマンド「描画用の複製を作る」: 元のメッシュと同じ UV・三角形・テクスチャの複製を作り、全頂点を元に一致させるグルーを張る。複製のキーフォームは既定の形 1 つ。元の頂点の追加・削除・三角形の変更に複製とグルーが追従する (または、ずれを検出して直す操作)
- [x] ランタイムで複製が元と同じ位置に描かれるテスト (パラメータを動かしても、動的物理があっても)
- [x] インスペクタで複製と元を相互にたどれ、複製の描画順・マスク・不透明度を編集できる
- [x] 操作マニュアルに「前後関係が入れ替わる部分の作り方」(複製・反転マスク・描画順のキー) を書く
- [x] `just ci`・`just gen`・エディタのビルドが通る

## メモ

- やったこと:
  - `ugoe-editor-core` に `draw_clone` モジュールと `Command::CreateDrawClone` / `SyncDrawClone` を追加 (enum の末尾)。
    複製と元の対応はグルーの ID の規則 (`DrawClone_<複製の ID>`) だけで表し、モデルの形式は変えていない。
  - 追従は特定のコマンドに結び付けず、`Document::apply_with_report` の適用後 (推定のやり直しの前) に、UV・三角形・テクスチャ・親が
    変わった元の複製を合わせ直す。頂点の編集・三角形の作り直し・メッシュの再生成・親の付け替え (デフォーマの作成を含む) に追従する。
    複製の形の編集は `EditError::DrawCloneShape` で拒否。`regenerate_mesh` は描画用の複製のグルーを理由に拒否しないようにした。
  - ずれの検出 (`draw_clone::is_in_sync`) と、それをフロントエンドで写した `drawClone.ts`。インスペクタの「Draw clone」の節で
    作成・相互の選択・今のセルの不透明度と描画順・Resync。
  - テスト: パラメータ (回転・ワープ・メッシュ自身のキー・ブレンドシェイプ)、グルーでつながった元、動的物理 (`dynamic_hair` を
    `Puppet` で 90 フレーム: 頂点の加算量を受ける `Ribbon` と角度の加算量を受ける `Strand`) で、複製が元と 1e-3 px 以内で一致すること。
    グルーの強さを 0 にすると落ちることを確かめた。
  - ヘッドレスの Chrome (リポジトリ外の IPC の橋渡し) で、作成→複製が選ばれる→描画順・不透明度の入力→元へ移る→元に頂点を足すと
    複製が追従 (評価の差 0)→複製の三角形の作り直しは拒否→複製の親を変えると「Resync」が出て、押すと直る、を確認した。
- 決めたこと:
  - 複製は元と同じパーツ・親に、`meshes` の元の直後に置く。パーツは変えてよい (ずれとは見なさない)。親は元に合わせる
    (親デフォーマの不透明度を元と同じにするため)。
  - `weight = 0`・`intensity = 1` のグルーは `pb + (pa - pb) * 1` なので、丸めで 1 ulp 程度の差がありうる (評価の式はランタイムのまま)。
    動的物理の加算量はグルーの前に加わるので複製にも伝わる (`docs/spec/evaluation.md` の 5. に 1 行追記)。
- 範囲外の変更: `docs/spec/evaluation.md` のグルーの節に 1 行の注記を足した (実装は変えていない)。
- 後続タスクの候補:
  - メッシュの不透明度をセルごとに編集する欄は、今は複製の節にしかない。普通のメッシュにも「Keyforms」の節で出すとよい。
  - ツリーで複製に印 (`clone`) を付ける (T0632 などとの衝突を避けて今回は入れていない)。
  - グルーを画面から張る・消すコマンド (`AddGlue` など) はまだない。できたら、元を使うグルーを後から足したときに複製のグルーを
    後ろへ回す (今は `sync_draw_clone` かずれの表示で直す)。
