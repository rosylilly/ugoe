# T0636: エディタ: プレビューでのフェイストラッキング

## 目的

エディタのプレビューモード (T0635) で、ビューアと同じ MediaPipe のフェイストラッキング (T0703) を使い、組み上げたモデルに表情が付くかを編集の場で確かめられるようにする。
T0635 では、ビューアのトラッキング (約 1300 行)・MediaPipe の同梱 (約 9 MiB)・モデルの取得と検証・カメラの権限をエディタへ持ち込む大きさから、切り出した。

## 受け入れ条件

- [ ] トラッキングの部品 (MediaPipe の呼び出し・頭の向き・平滑化・キャリブレーション・記録と再生・パネル) を、ビューアとエディタで共有する場所 (例: `packages/`、GPL-3.0-only) に切り出すか、写すかを決めて書く
- [ ] エディタのプレビューでトラッキングを開始・停止でき、T0635 のコントローラの差し込み口でパラメータを書く。トラッキング中の目パチの扱いはビューアと同じ
- [ ] MediaPipe の wasm とモデルの同梱 (ビルド時の取得と SHA-256 の検証)、カメラの権限 (Linux・Windows・macOS)、ライセンスの表記
- [ ] ヘッドレスのブラウザで、記録した値の列か画像・動画の入力で確かめる。操作マニュアルを更新する
- [ ] `just ci`・`just licenses`・エディタとビューアのビルドが通る
