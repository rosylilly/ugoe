# T0952: ui-audit: 1600px の広い幅の組と、ビューポートの上の文字のコントラストの検査を足す

## 目的

T0725 で見つかったが `just ui-audit` では見つけられなかったもの (T0725 の候補):

- ビューアのビューポートの知らせ (空・準備中・失敗) は、ビューポートの地 (モデルの背景色) の上に載っていて、ダークのテーマで読めなかった。監査は canvas の上の地を測らない。
- ビューアは幅 1200px 以上で右の列を 2 列に並べるが、監査の組 (1280・360 など) の中では撮れる幅が限られ、1600px ほどの広い幅を撮らない。

## 受け入れ条件

- [x] `just ui-audit` に 1600px ほどの組がある (3 つのアプリか、要るアプリだけ。理由をメモに)。tests/ui-audit/README.md の組の表を直した
- [x] canvas の上に重ねた文字のコントラストを測る検査 (canvas の画素を地として測る) か、ビューポートの地を暗くした場面のどちらかがあり、
      T0725 の前の画面 (main e9ef06f9 のビューアの知らせ) なら指摘が出ることを一度確かめてメモに書いた
- [x] 今の main で、足した検査・組の指摘が 0 件 (出たら直すか、理由を docs/ui.md に書く)
- [x] `just ci` が通る

## メモ

- T0040 で起票した (元の候補: T0725 (canvas の上の文字のコントラスト)・T0725 (1600px の組))。
- **やったこと:**
  - **canvas の上の文字を画素で測る** (`tests/ui-audit/lib/page-checks.js`・`audit.mjs`): 前は文字の祖先をたどって最初の不透明な地 (ページの地) で
    止まり、その間に挟まる canvas を見ていなかった (T0725 の前のビューアの知らせはページの地 = ダークの地で測られて通っていた)。
    不透明な地の祖先の中に文字に重なる canvas・video・img がある文字と、祖先に `background-image` (画像・グラデーション・hover の重ね) がある文字は、
    すべての文字を透明にした画面を撮り (PNG をページの中で `createImageBitmap` で読む。依存は増やしていない)、文字の行の矩形の画素ごとに比を求め、
    下から 1 割の比を文字の比にする。モーダルのダイアログの後ろの文字は inactive として数えない (画素で測ると幕の下の文字が出たため)。
    ログに `by pixels` の数を出す。単体テスト 2 つ (`pixelContrast`) を `just ui-audit-check` に足した。
  - **1600px の組:** ビューアとスタジオに `en-light-xwide`・`ja-dark-xwide` (1600×900)。ビューアは 1200px 以上の 2 列の配置、スタジオは中央の列 (1fr)
    だけが伸びる。エディタは広い幅が 1440px で、列の幅を区切りで変えて覚えるので足していない (README の組の表と docs/ui.md に理由)。
  - 文書: tests/ui-audit/README.md (組の表・検査の表・「canvas・画像の上の文字」)、docs/testing.md、docs/ui.md (「コントラストと色」に canvas の上の文字は
    テーマの地の札に載せる、の 1 行と、「canvas の上の文字と 1600px の組 (T0952)」の節)。
- **T0725 の前で指摘が出ること:** main e9ef06f9 の worktree に今の tests/ui-audit を写して `just ui-audit --only viewer` を流した。
  `p.hint` (「.ugoe か model.json をドロップするか…」) が 2.07 < 4.5 (fg #a1a1aa、地の画素 rgb(230, 231, 235)) で、ダークの `-empty`・`-samples-menu`
  の 10 の場面に出た (ライトは text-muted #5f5f68 で届く)。
- **今の main (rebase 後 5445e9a2 の上) の `just ui-audit`:** ビューア 0 件 (70 場面、1600px の組を含む)。スタジオはコントラスト 2 種類 (3)、エディタは
  コントラスト 1 種類 (12)。ほかの検査はすべて 0 件。1600px の組の指摘は 0 件。見つかったものはどちらも範囲 (tests・docs) の外なので直さず、
  docs/ui.md の「残したもの」に理由を書いた:
  - エディタのビューポートの右上の `webgl2` (`span.muted`) が地の札なしでモデルの描画 (髪) に重なり 4.31 (狭い幅・200% の拡大のライト)。T0675 (作業中) の範囲。
  - スタジオのシーンの一覧の選んだ行に hover したとき、ダークで accent-soft + hover の重ねの上の text-muted (モデルの名前・Kbd の `+`) が 4.29
    (`ja-dark-narrow-approved`。承認のボタンを押した後のポインタが行の上に来る)。hover の重ねのトークン (T0916) の決め方に関わる。
- **確かめていないこと:** 実物の WebView での表示。画素で測るのはヘッドレスの Chrome (swiftshader) の描画なので、GPU やドライバで canvas の色が変わる場合は見ない。
- **main への追従 (T0674・T0675・T0845 の後):** docs/ui.md の衝突は T0675 の節と T0952 の節を両方残して解いた。T0675 で `webgl2` が設定へ移り、
  `just ui-audit --only editor` のコントラストは 0 件 (174 場面。残る 24px 未満 4 種類は T0675 のメモにある `-gizmo` の場面のもの)。
  スタジオは前と同じ 2 種類 (3)。docs/ui.md の T0952 の節を今の結果に直した。
