# T0634: エディタ: 物理のテンプレート (体の追従・弾み)

## 目的

フェイストラッキングのアプリの多くは体の向きを出さないので、顔の角度から物理で体を遅れて追従させ、弾ませる設定が定番になっている (参考の記事 4・2)。
順序付きの連鎖 (T0312) と加算の出力 (T0313) を使い、定番の設定をテンプレートとして 1 回の操作で作れるようにする。

## 受け入れ条件

- [ ] テンプレート: 「体の追従」(AngleX/Y/Z → BodyAngleX/Y/Z、遅れと戻り)、「弾み」(中継用パラメータを挟んで角度に弾みを足す)、「首の追従」。標準パラメータの ID で作り、ないパラメータは作るか飛ばすかを選べる
- [ ] コマンドの列として適用し、1 回の Undo で戻る。テストで、顔を振ったときに体が遅れて付いてくること
- [ ] 操作マニュアルの物理の章に、テンプレートの使い方と中身の説明を書く
- [ ] `just ci`・`just gen`・エディタのビルドが通る
