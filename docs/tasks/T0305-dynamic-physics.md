# T0305: 動的物理の実装 (2 段階の評価)

## 目的

デフォーマ・頂点への物理の出力、衝突体、重力の基準を実装し、評価を 2 段階にする。

## 受け入れ条件

- [ ] 揺れ用パラメータなしで、回転デフォーマの鎖が揺れるテストがある
- [ ] 衝突体の外に粒子が押し出されるテストがある
- [ ] 基準のデフォーマを傾けると重力の向きが変わるテストがある
- [ ] 動的物理を使わないモデルでは評価のコストが変わらない
- [ ] 決定性のテストがある
- [ ] `docs/spec/evaluation.md` の「実装待ち」を更新する
- [ ] `just ci` が通る
