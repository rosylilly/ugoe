# 描画仕様

対応するコードは `crates/ugoe-render`。参照シェーダは `crates/ugoe-render/src/shaders/drawable.wgsl`。

ここに書く式は **すべてのレンダラの正** です。wgpu の参照レンダラも、ゲームエンジン向けの独自レンダラもこれに従います。

## 前提

- テクスチャは **乗算済みアルファ (premultiplied alpha)** の RGBA8 として扱います。PSD などの非乗算画像は、取り込み時またはアップロード時に変換します。
- 色空間: 現時点では sRGB の値をそのまま (リニア化せずに) 合成します。Cubism と同じ見た目にするためです。
  > 未決: リニア合成モードを選べるようにするか。
- 描画先は乗算済みアルファの RGBA として扱います。

## 描画可能要素ごとのシェーディング

`c` をテクスチャから読んだ色 (乗算済み)、`M` を乗算色、`S` をスクリーン色、`α` を不透明度とします。

```
rgb = c.rgb * M
rgb = rgb + S * c.a - rgb * S           // スクリーン合成を乗算済みの空間で行う
out = vec4(rgb, c.a) * α
out = out * mask_coverage               // マスクがある場合
```

## 合成モード

`src` をシェーダの出力 (乗算済み)、`dst` を描画先とします。

| モード | RGB | A | wgpu の BlendState |
| --- | --- | --- | --- |
| `normal` | `src + dst * (1 - src.a)` | `src.a + dst.a * (1 - src.a)` | color: One / OneMinusSrcAlpha、alpha: One / OneMinusSrcAlpha |
| `additive` | `src + dst` | `dst.a` | color: One / One、alpha: Zero / One |
| `multiply` | `src * dst + dst * (1 - src.a)` | `dst.a` | color: Dst / OneMinusSrcAlpha、alpha: Zero / One |

## マスク

判断の経緯と、根拠にした調査は [ADR 0009](../adr/0009-clipping-mask-semantics.md) にあります。
基準は Cubism との一致ではなく、リガーにとって便利かどうかです。

### マスクの参照

メッシュは `masks` に、マスクとして使うメッシュへの参照 (`MaskRef { mesh, invert }`) を並べます。

- `invert = false` の参照を **通常マスク**、`invert = true` の参照を **反転マスク** と呼びます。1 つのメッシュで両方を同時に使えます。
- 通常マスクの結合方法は `mask_mode` で選びます。既定は `union` (和集合) で、`intersection` (共通部分) も選べます。反転マスクは常に和集合で結合します。

### マスクの効き具合

画面上の各点で、マスク用メッシュ `i` の **カバレッジ** `c_i` を次のように決めます。

```
c_i = α_i × k_i
  α_i : メッシュ i のテクスチャのアルファ (メッシュの外側では 0)
  k_i : メッシュ i 自身のマスク係数 (メッシュ i がマスクを持たなければ 1)
```

**マスク用メッシュの不透明度・表示状態 (`visible`)・乗算色・スクリーン色・合成モード・裏面カリングは、カバレッジに影響しません。**
不透明度 0 のメッシュや、パーツごと見えなくなっているメッシュも、形どおりにマスクとして効きます。

`k_i` によって、マスクは **入れ子を継承** します。たとえば黒目を白目でクリップし、瞳孔を黒目でクリップすると、瞳孔は白目からはみ出しません。
マスクの参照が循環する場合 (自分自身を含む) は、モデルの検証でエラーにします。

マスクを持つメッシュのマスク係数 `k` は次のとおりです。`P` は通常マスク、`N` は反転マスクの集合です。

```
pos = 1                      (P が空)
    = 1 − Π_{i∈P} (1 − c_i)  (mask_mode = union)
    = Π_{i∈P} c_i            (mask_mode = intersection)
neg = 1 − Π_{j∈N} (1 − c_j)  (N が空なら 0)
m   = pos × (1 − neg)
k   = 1 − s × (1 − m)        (s = mask_strength、キーフォームで補間した値。0〜1 にクランプ)
```

描画時の色は、[描画可能要素ごとのシェーディング](#描画可能要素ごとのシェーディング) の `mask_coverage` に `k` を使います。

- `mask_strength` を 1 未満にすると、マスクの外側 (反転マスクでは内側) も `1 − s` の割合で見えます。反転マスクで透かした部分の透け量の調整や、マスクのフェードに使います。
- 「すべてのマスクが見えなくなったらクリッピングを解除する」といった特別な挙動はありません。

### マスク専用メッシュ

`mask_only = true` のメッシュは、色としては描画せず、マスクとしてだけ働きます。
ランタイムの出力では常に `visible = false` になります。マスクに使うためのアートを、不透明度 0 などの回避策なしに用意するためのものです。
マスクとして誰からも参照されていないマスク専用メッシュは、何の効果も持ちません (エディタは警告を出す)。

### 精度

- マスクの数に上限はありません。
- 参照レンダラは既定で、各マスクをその **画面上の大きさ以上の解像度** で描きます。これにより縁がぼやけません。
- 性能のために解像度を下げる設定は、レンダラのオプションとして持ちます (モデルのデータには含めない)。

### 実装方式 (参照レンダラ)

1. ロード時に、各メッシュが読むマスクの **内容** (アトラスの 1 チャンネルに描く値) を決める。同じ値になるメッシュどうしは内容を共有する。
2. フレームごとに、内容を読む要素の画面上の外接矩形を求め、入れ子のマスクへ伝播する。
3. 各内容に、外接矩形の画素数以上の大きさのセル (アトラスの矩形とチャンネル) を割り当てる。入れ子のレベルごとに別のアトラスを使う。
4. マスクパスで、アトラスを 1 でクリアし、各内容を担当チャンネルに **乗算合成** (dst × src) で描く。レベルの小さいアトラスから描く。
5. 本描画パスでは、アトラスの矩形・チャンネル・読み方と `mask_strength` をユニフォームで渡し、係数 `k` を求めて色に掛ける。

WebGL2 でも動くように、ストレージバッファ・コンピュートシェーダ・浮動小数点の描画先は使いません。使うのは RGBA8 の描画先、
乗算合成とチャンネルごとの書き込みマスク、シザー矩形だけです。

詳細 (参照レンダラの決めごと。独自レンダラは同じ結果になれば別の方式でもよい):

- **内容**: `P`・`N` は、参照を通常・反転に分けて重複を除いた集合です (`masks` の並びと重複は区別しない)。内容は次の 2 種類です。
  - `Product(S)` = `Π_{i∈S} (1 − c_i)`。
    - `N` が空で、`mask_mode = union` または `P` が 1 つ: `Product(P)` を **1 から引いて** 読む (`pos = 1 − Π(1 − c)`)。
    - `P` が空: `Product(N)` を **そのまま** 読む (`1 − neg`)。
    - このため、ある集合を通常マスクの和集合として使う要素と、同じ集合を反転マスクとして使う要素は、同じセルを共有します。
  - `Clip(P, mode, N)` = `m` そのもの (そのまま読む)。通常と反転の併用と、2 つ以上の通常マスクの共通部分に使います。
    `mode` は `P` が 2 つ以上のときだけ区別します。
- **マスクパスの手順**: アトラスは RGB の 3 チャンネルに内容を描き、A を作業領域に使います。チャンネルはクリア時に 1 です。
  マスク用メッシュ `i` を描くと、書き込み先に `1 − c_i` を掛けます (乗算合成、他のチャンネルには 1 を出す)。
  メッシュの外では何も掛けない (`c = 0` と同じ) ので、`Π(1 − c)` はメッシュを描くだけで作れます。
  - `Product(S)`: `S` の各メッシュをチャンネルに描く。
  - `Clip`、和集合: 作業領域を 1 で埋め、`P` の各メッシュを作業領域に描き (`Π(1 − c)`)、チャンネルに `1 − 作業領域` を掛ける (全面描画、
    合成 `dst × (1 − dst.a)`、書き込みマスクでそのチャンネルだけ)。これで `pos` が掛かる。
  - `Clip`、共通部分: `P` の各メッシュについて、作業領域を 1 で埋め、メッシュを作業領域に描き (`1 − c`)、チャンネルに `1 − 作業領域` (= `c`) を掛ける。
    メッシュの外ではチャンネルに 0 が掛かるので `Π c` になる。
  - `Clip` の反転マスク: `N` の各メッシュをチャンネルに直接描く (`1 − neg` が掛かる)。
  - 全面描画はシザー矩形 (セル) の範囲だけに効きます。作業領域は内容ごとに埋め直すので、同じセルの他のチャンネルの内容と干渉しません。
- **カバレッジ**: マスクパスでは `c_i = テクスチャのアルファ × k_i` を出します。`k_i` はメッシュ `i` 自身のマスク係数で、
  本描画と同じ式 (自身の内容・読み方・`mask_strength`) で求めます。マスク用メッシュの不透明度・色・合成モード・カリングは使いません。
- **入れ子のレベル**: 内容のレベルは、そのマスク用メッシュのマスクの依存の深さ (`CompiledModel::mask_depth`) の最大値です。
  マスク用メッシュ自身の内容のレベルは必ずそれより小さいので、レベルごとに別のアトラスに描き、レベルの小さいアトラスから描けば、
  描いている最中のアトラスを読むことはありません。
- **外接矩形**: 内容を読む要素 (表示されていて三角形を持つもの) の頂点を画面 UV (0..1、左上原点) に写した外接矩形です。
  入れ子では、内容の外接矩形とマスク用メッシュ `i` の外接矩形の共通部分を、`i` 自身の内容の外接矩形に加えます (レベルの大きい順に伝播する)。
  最後に画面で切り詰め、画素の境界まで外側に広げます。面積が 0 になる (画面外など) 内容は描かず、それを読む要素も描きません。
  自身の内容が描かれないマスク用メッシュは、内容のセルの範囲に画素を持たないので描きません (カバレッジ 0 と同じ)。
- **精度とセル**: セルの内側は、外接矩形の画素数 (描画先のテクスチャの大きさで数える) を `downscale` で割って切り上げた texel 数です。
  外接矩形を画素の境界に広げているので、既定 (`downscale = 1`) では texel と画素が一致し、マスクは画面と同じ解像度で描かれます。
  セルは内側の周りに 1 texel の縁を持ちます。縁にもマスクは描かれるので、外接矩形の端でもバイリニア補間は正しい値を読みます。
- **アトラスの割り当て**: セルをチャンネルごとに棚詰め (高いセルから) で詰めます。アトラスの一辺は 2 の冪で、
  最大のセルが収まる大きさ (256 以上) から始め、レベルの数より多くのアトラスが要るなら上限まで倍にします。
  上限でも収まらなければアトラスを増やします。一辺はフレームをまたいで大きくするだけで、小さくはしません (作り直しを避けるため)。
  一辺の上限は `MaskAtlasOptions::max_size` (既定 4096) とデバイスの `max_texture_dimension_2d` の小さい方で、
  これより大きいセルは縮小して描きます。
- **外接矩形 → セル**: 外接矩形をセルの内側に (縦横別々の倍率で) 写す `atlas_uv = offset + screen_uv * scale` を、
  マスクパスでは書き込み先 (`target_rect`)、読む側では `mask_rect` ユニフォーム (`xy = offset`, `zw = scale`) で渡します。
  マスクパスではシザー矩形をセル全体にして、隣のセルに書き込まないようにします。
- **読み方**: `m = mask_params.x + dot(texel, mask_channel)` (`mask_channel` は符号付きの one-hot。1 から引いて読むなら
  `x = 1`、チャンネル `−1`)。`k = 1 − mask_params.y × (1 − m)` で、`mask_params.y` は `mask_strength` です。
  マスクを持たない要素は `mask_params.y = 0` (係数 1) とし、中身を読まない 1x1 のダミーを束縛します。
- 解像度を下げる設定は `RendererOptions::mask_atlas` (`MaskAtlasOptions { max_size, downscale }`) です。
  `downscale = 2` なら縦横 1/2 の解像度で描き、アトラスが小さくなる代わりに縁がぼやけます。

## 裏面カリング

`culling = true` の要素は、キャンバス座標 (Y 下向き) で **反時計回り** に並んだ三角形を表とします。
ここでの「反時計回り」は、キャンバスを Y 下向きのまま表示したときに画面上で反時計回りに見えることを指します。
式で書くと、三角形 `(p0, p1, p2)` がキャンバス座標で

```
(p1.x - p0.x) * (p2.y - p0.y) - (p2.x - p0.x) * (p1.y - p0.y) < 0
```

を満たすとき表です (Y 下向きの座標系なので、画面上の反時計回りは符号付き面積が負になります)。

ビュー変換で Y 軸が反転するときは、レンダラが表裏の判定を補正します。参照レンダラは
`view_proj` の左上 2x2 (線形部分) の行列式で判定します。

- 行列式 < 0 (通常のビュー。キャンバスの Y 下向きをクリップ座標の Y 上向きへ反転する): クリップ座標で反時計回りを表とする (`FrontFace::Ccw`)
- 行列式 ≥ 0 (Y 軸を反転しないビュー): クリップ座標で時計回りを表とする (`FrontFace::Cw`)

どちらの場合も、表裏はキャンバス座標での向きだけで決まり、ビューには左右されません。

## ビュー変換

`ugoe_render::View::view_proj` はキャンバス座標からクリップ座標への 3x3 行列 (列優先) です。どこを表示するか (フィット・ズーム・パン) はホストが決めます。

## GPU リソースの方針

- 頂点バッファは要素ごとに `positions` を毎フレーム書き込みます。UV とインデックスは静的なので、ロード時に一度だけ書き込みます。
  - 参照レンダラは全要素の位置・UV・インデックスをそれぞれ 1 本のバッファにまとめ、要素ごとにバッファのスライスを束縛して描きます。WebGL2 は `base_vertex` を使えないためです。
- ユニフォームは、要素ごとの値を動的オフセット付きの 1 つのバッファにまとめます。要素の間隔は `min_uniform_buffer_offset_alignment` に揃えます。
- 本描画のパイプラインは `合成モード × カリングの有無` の組み合わせで作り、キャッシュします。カリングありのパイプラインは、表とする向き (上の「裏面カリング」) ごとに別に作ります。
  マスクの有無と読み方はユニフォームで切り替えるので、パイプラインは分けません (組み合わせを増やさず、描画順どおりに切り替えるため)。
  マスクパス用のパイプラインは固定の 5 つです (マスク用メッシュの乗算合成・作業領域を埋める全面描画・作業領域をチャンネル R/G/B に掛ける全面描画。どれもカリングなし)。
- マスクパスのマスク用メッシュのユニフォームも、要素ごとのユニフォームと同じバッファの後ろ (内容ごと) に置きます。
- テクスチャは `Rgba8Unorm` (sRGB 形式ではない) で作ります。値をリニア化せずに合成するためです。サンプラはバイリニア・端でクランプです。
- 描画先はクリアせずに上に重ねます (`LoadOp::Load`)。クリアや背景の描画はホストが行います。
- 1 つの `Renderer` の `encode` は、1 回の `Queue::submit` につき 1 回だけ呼びます (バッファを `Queue::write_buffer` で書き換えるため)。
- 非表示 (`visible = false`) の要素は描きません。描く要素 (と、そのマスク用メッシュ) のテクスチャが登録されていなければエラーを返し、コマンドを積みません。
