# 着せ替えモジュール仕様

判断の経緯は [ADR 0014](../adr/0014-composable-modules.md)。

> 実装待ち: データ定義と合成は T0111、ファイル形式は T0113、エディタでの作成は M4 以降に起票します。

## スロット

本体のモデルは `Model.slots` にスロットを公開します。

| フィールド | 内容 |
| --- | --- |
| `id` | スロットの名前 (例: `Hair`、`Outfit`、`HeadAccessory`)。モジュールはこの名前だけで取り付け先を指定する |
| `anchor` | 取り付け先。デフォーマの ID またはキャンバス (`None`) |
| `draw_order` | このスロットに入るメッシュの描画順の範囲 `[min, max]`。モジュールの描画順 (0〜1000) はこの範囲に写される |
| `replaces` | モジュールを取り付けたときに非表示にする本体のパーツの ID (例: 既定の髪) |
| `parameters` | このスロットのモジュールが使ってよい本体のパラメータの ID。標準パラメータは常に使える |

1 つのスロットには、同時に 1 つのモジュールを取り付けます。

## モジュール

モジュールは、次のものを持つ部分的なモデルです。

- パーツ・メッシュ・デフォーマ・テクスチャ・マスク・グルー・物理 (ADR 0011 の動的物理を含む)
- `slot`: 取り付け先のスロットの名前
- `requires`: 対応する本体の条件 (アバタープロファイルのレベル、必要なスロットとパラメータ)

モジュールの中の ID は、モジュールの中でだけ一意です。合成時に `<モジュールの名前>/<ID>` の形に付け替えます。
モジュールの最上位のデフォーマは、スロットの `anchor` の子として取り付けます。

モジュールのマスクは、モジュールの中のメッシュと、本体がスロットで公開するメッシュ (`Slot::mask_sources`) だけを参照できます。

## 合成

```
compose(base: Model, modules: [(slot, Module)]) -> Model
```

1. モジュールごとに `requires` と、スロットが存在することを検査する。
2. モジュールの ID を付け替え、デフォーマをスロットの `anchor` の下に取り付ける。
3. 描画順をスロットの範囲に写す: `order' = min + (max − min) × order / 1000`。
4. スロットの `replaces` のパーツの不透明度を 0 に固定する。
5. 合成したモデルを検証 (`validate`) してから、ランタイムがコンパイルする。

組み替えは、合成とコンパイルをやり直して行います。パラメータの値は、合成の前後で同じ ID のものを引き継ぎます。

## 旧ランタイムでの扱い

スロットとモジュールは任意機能 `modules` ([ADR 0013](../adr/0013-forward-compatibility.md)) です。知らないランタイムはスロットを無視し、本体だけを表示します。
