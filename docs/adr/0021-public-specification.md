# 0021: 公開のモデル仕様 (英語版を正とし、CC BY 4.0 で公開する)

- 状態: Accepted (2026-09-29、利用者の判断)
- 日付: 2026-09-29
- 関連: ADR 0012 (仕様の公開。ライセンスの未決をこの ADR で決める)、ADR 0013 (前方互換)、ADR 0018 (ライセンス)、ADR 0020 (マイルストーンの順序)

## 背景

ADR 0012 で、アバタープロファイルの仕様を実装から独立して読めるように書き、自由なライセンスで公開すると決め、ライセンスの種類を未決にしていた。
いまの仕様書 (`docs/spec/`) は日本語で、実装者 (このリポジトリのエージェントと人間) 向けに書かれ、実装の型名やタスク ID を含む。ugoe 以外のランタイムやツールがモデルを読み書きするには、それだけで読める公開の仕様が要る。

## 決定

- **公開の仕様は英語版を正とする。** 置き場所はリポジトリの `spec/` (`docs/` とは別)。`docs/spec/` の日本語の仕様書は開発用として残し、両者が食い違ったら英語版が正。
- **公開の仕様のライセンスは CC BY 4.0。** `spec/LICENSE` に置く。コード (`crates/`) の MIT、アプリの GPL-3.0-only とは別。仕様に載せる JSON Schema と例のファイルも CC BY 4.0 とし、実装に取り込むときの扱いを `spec/README` に書く。
- 公開の仕様に含めるもの: モデルのデータ (`model.json`) とバンドル (`.ugoe`) の形式、評価 (変形・補間) と描画の規則のうち互換に必要なもの、物理・モーション・エフェクト、前方互換 (機能の宣言とフォールバック)、アバタープロファイル、JSON Schema、適合性を確かめるための例のファイル。
- 含めないもの: エディタのプロジェクト形式 (`.ugoeproj`)、エディタのコマンド、AI の提案の形式 (ツールの内部。必要になったら別に決める)。
- 公開の仕様にはバージョンを付け、`schema_version` とアバタープロファイルの `profile_version` との対応を示す。1.0 より前は草案 (Draft) として公開する。

## 検討した代替案

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| 日本語と英語の両方を正にする | 日本語の利用者に読みやすい | 2 つを同じに保つ手間が倍になり、食い違いの元になる |
| 日本語だけ | 手間が最小 | 海外の実装者が読めない |
| MIT / CC0 | コードと同じ・制約がない | MIT は文書向けの条文ではない。CC0 は出典の表示を求められない |

## 結果

- 他の実装者は `spec/` だけを読めば、モデルを読み書きできるようになる (を目指す)。
- 仕様の変更は `docs/spec/` (日本語、開発用) と `spec/` (英語、公開) の両方に反映する必要がある。反映漏れを CI で見つける仕組み (例: 両者の見出しや表の項目の対応の検査) を M5 で検討する。
