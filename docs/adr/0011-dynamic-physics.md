# 0011: 揺れ用パラメータのいらない物理 (動的物理)

- 状態: Accepted
- 日付: 2026-09-28
- 関連: [spec/physics.md](../spec/physics.md)、[spec/evaluation.md](../spec/evaluation.md)、T0301

## 背景

Cubism の物理演算は、出力先がパラメータだけである。そのため髪を揺らすには、まず「揺れた形」を持つパラメータ (`HairFront` など) をキーフォームで作り込み、そのパラメータを物理で動かす必要がある。
揺れの表現力はこの作り込みに縛られ、作業量も多い。体との衝突 (髪が肩をすり抜けない) や、頭の傾きに合わせた重力方向も表現しにくい。

## 決定

1. **物理の出力先を増やす。** 従来のパラメータに加えて、次の 3 つを出力先にできるようにする。
   - **回転デフォーマ**: 粒子チェーンの各区間を、対応する回転デフォーマの角度に足し込む (揺れもの用のボーンのように使う)。
   - **デフォーマの平行移動**: 回転デフォーマの原点をずらす。
   - **頂点**: ワープデフォーマの制御点やメッシュの頂点を、重み付きで粒子に追従させる (スカートの裾や胸などの柔らかい揺れ)。
2. **衝突体を持つ。** 円とカプセルの衝突体を、デフォーマに取り付けて体と一緒に動かす。粒子は衝突体の外に押し出される。
3. **重力と風の向きを、基準のデフォーマの座標系で指定できるようにする。** 例: 頭の回転デフォーマを基準にすると、頭を傾けたときに髪の垂れる向きが自然に変わる。既定はキャンバスの座標系 (従来どおり)。
4. **評価を 2 段階にする。** パラメータからデフォーマを評価し (1 段目)、そのワールド座標で物理を進め、物理の出力をデフォーマや頂点に加えてから、影響を受けた部分を評価し直す (2 段目)。パラメータへの出力は従来どおり 1 段目の前に書き込む。
5. 決定性は保つ。固定ステップで積分し、乱数を使わない。

## 検討した代替案

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| パラメータ出力だけのまま (Cubism と同じ) | 実装が単純 | 提案の核心である「揺れ用パラメータを作らなくていい」を満たせない |
| スケルトンとスキニング (頂点を複数のボーンの重みで動かす) を導入する | 揺れもの以外の表現にも使える | データモデルが大きく変わる。まずは既存のデフォーマを出力先にし、スキニングは必要になったら別の ADR で検討する |
| 汎用の剛体・布シミュレーションを組み込む | 表現力が最も高い | 重く、決定性や移植性を保ちにくい。2D アバターに必要なのは振り子チェーン + 衝突 + 頂点の追従で十分 |

## 結果

- 揺れ用のパラメータとキーフォームを作らずに、髪やアクセサリーを揺らせる。
- 評価の順序が変わるため、ランタイムのコストは増える (物理を使う部分の再評価)。物理を使わないモデルのコストは変わらない。
- 旧ランタイムは新しい出力先を知らないので、ADR 0013 の任意機能として扱い、読めない場合は「揺れなし」に劣化させる。
