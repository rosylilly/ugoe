# 0015: ライティング (法線マップ)

- 状態: Accepted
- 日付: 2026-09-28
- 関連: [spec/rendering.md](../spec/rendering.md#ライティング)、[ai-integration.md](../ai-integration.md#法線マップの生成)

## 背景

ゲームでは、シーンの光源 (夕日・たいまつ・スポットライト) にキャラクターが反応すると、背景となじむ。
2D のリグ付きキャラクターでこれができると、ゲームで採用する理由になる。

## 決定

1. **テクスチャに法線マップを添えられるようにする。** 法線マップはテクスチャと同じ UV 空間の接空間法線とする。
2. **参照レンダラにライティングを実装する。** 環境光と、平行光源・点光源 (キャンバス座標 + 奥行き) を扱う。光源はホストがフレームごとに渡す。モデルごと・メッシュごとにライティングの有無を選べる。
3. **変形に合わせて法線を回す。** メッシュの変形 (UV 空間から画面空間への写像) に合わせて、法線の向きを三角形ごとに補正する。
4. **法線マップを自動で作れるようにする。** アルファの形から「ふくらみ」を推定する決定的な方法を基本とし、AI による深度推定から作る方法も用意する (ADR 0010 の深度と共通にする)。
5. 法線マップは任意機能 (ADR 0013) とし、知らないランタイムはライティングなしで描く。

## 検討した代替案

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| 色の乗算だけで明るさを変える (乗算色) | 既存の機能で済む | 光の方向を表現できない |
| 3D モデルとして扱う | 物理的に正しい | 2D アバターの表現 (原画の線や塗り) を損なう |

## 結果

- ゲームのシーンの光源に反応する 2D キャラクターを作れる。
- 法線マップの分だけテクスチャの容量が増える。使わないモデルには影響しない。
- WebGL2 でも動く範囲 (フラグメントシェーダでの計算) で実装する。
