# 0019: ビューア (apps/viewer) のライセンスは GPL-3.0-only

- 状態: Accepted (2026-09-28、ユーザーの判断)
- 日付: 2026-09-28
- 関連: T0701、ADR 0018 (ライセンスと 1.0 の範囲。この ADR はその補足)

## 背景

T0701 で、`.ugoe` を開いて表示し、パラメータを動かして確かめる Tauri アプリ `apps/viewer`
(Rust のクレート `ugoe-viewer`、npm パッケージ `@ugoe/viewer`) を作った。
ADR 0018 で GPL-3.0-only と決めたのはエディタ (`apps/editor`) だけで、ビューアのライセンスは決まっていなかった。

## 決定

- **ビューア (`apps/viewer`) は GPL-3.0-only** にする。エディタと同じ扱いで、`scripts/check-licenses.mjs` の
  `EDITOR_CRATES` に `ugoe-viewer` を入れ、依存は GPL-3.0 と両立するライセンスであればよいとする。
- ランタイム・ライブラリ・ツール (`crates/`) は MIT のままにする。ゲームやアプリに、ソースの開示なしで組み込めなければならないから。
  アプリ (エディタ・ビューア) は組み込まれるものではないので GPL にする。
- 両方とも GPL なので、エディタのコードをビューアに写してよい。ただし、アプリ同士で import はしない。
  共有する部品が要るときは、共有の場所に切り出す。

## 検討した代替案

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| ビューアを MIT にし、アプリの依存に限って MPL-2.0 を許す | 組み込みの見本として制約なく写せる | Tauri 自体が MPL-2.0 のクレート (ビルド時だけの `cssparser`・`cssparser-macros`・`selectors`・`dtoa-short` と、バイナリに入る `option-ext`) に依存するので、ライセンスの検査に例外の区分が要る。エディタのコードも使えない |

## 結果

- ビューアはエディタと同じ規則で検査される。Tauri が依存する MPL-2.0 のクレートも問題にならない。
- ランタイムを組み込む見本としてビューアのコードを写す人は、GPL-3.0 に従う必要がある。
  MIT の見本が要るときは、`crates/` の SDK の例 (`examples/`) などで用意する。
