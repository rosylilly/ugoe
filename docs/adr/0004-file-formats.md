# 0004: 独自ファイル形式 (プロジェクト JSON とバンドル `.ugoe`)

- 状態: Accepted
- 日付: 2026-09-28

## 背景

Live2D のファイル形式と互換性を持たないことは決めている ([vision.md](../vision.md))。そのうえで、編集用と配布用の形式をどう設計するか。

## 決定

- 編集用は **ディレクトリ形式のプロジェクト** (`.ugoeproj/`)。JSON と PNG で構成する。
- 配布用は **チャンク形式のバイナリ** (`.ugoe`) 1 ファイル。
- どちらも中身は `ugoe-model` の型を serde でシリアライズしたものである。形式ごとに別のデータモデルを持たない。

詳細は [spec/file-formats.md](../spec/file-formats.md)。

## 理由

- プロジェクトをテキストにしておくと、git で差分が見られ、AI エージェントが直接読み書きできる。
- 配布は 1 ファイルのほうが扱いやすく、読み込みも速い。
- データモデルを 1 つにしておくと、変換のバグが生まれない。

## 結果

- 1.0 までは互換性を保証しない。その後はスキーマのバージョンとマイグレーションで互換性を管理する。
