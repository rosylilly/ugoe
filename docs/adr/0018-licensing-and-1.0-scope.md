# 0018: ライセンスと 1.0 の範囲

- 状態: Accepted
- 日付: 2026-09-28
- 関連: ADR 0012 (公開仕様のライセンス)、ADR 0013 (1.0 の基準の機能)、ADR 0017 (配布の前提)

## 背景

ADR 0012・0013・0017 で、次の 2 点を未決として残していた。

- プロジェクトのライセンス。仕様の公開と、crates.io・npm などへの配布の前提になる。
- 1.0 の時点で「基準の機能」に含めるもの。基準の機能は宣言なしで使え、1.0 以降の機能だけが機能の宣言とフォールバックの対象になる。

## 決定

### ライセンス

| 対象 | ライセンス |
| --- | --- |
| ランタイム・ライブラリ・ツール (`crates/` のすべてのクレート。`ugoe-cli` を含む) | **MIT** |
| エディタ (`apps/editor/`: Tauri のバックエンド `ugoe-editor` とフロントエンド `@ugoe/editor`) | **GPL-3.0-only** |
| 文書と仕様 (`docs/`。アバタープロファイルなどの公開仕様を含む) | **MIT** (リポジトリの既定) |

- ランタイムとライブラリを MIT にするのは、ゲームやアプリ (商用・クローズドソースを含む) に制約なく組み込めるようにするため。
- エディタを GPL-3.0 にするのは、エディタの派生物がオープンであり続けるようにするため。エディタは MIT のライブラリを使うが、その逆 (ライブラリがエディタに依存する) は依存方向のルールで起こらない。
- **MIT のクレートが依存するクレートは、寛容なライセンスで使えるものに限る。** コピーレフトのライセンス (MPL・LGPL・GPL など) のクレートを MIT のクレートの依存に入れると、利用者に義務が生じる。エディタの依存は GPL-3.0 と両立するものであればよい。
- この方針は `scripts/check-licenses.mjs` (`just licenses`) で検査し、CI で強制する。

### 1.0 の範囲

- **1.0 は、AI 連携を除く、現在定義しているすべての機能を含む。** ロードマップの M1〜M4 がこれに当たる。M5 (AI 連携) は 1.0 以降に行う。
- したがって ADR 0013 の「基準の機能」は、`docs/spec/file-formats.md` に現在挙げている機能 (キーフォームの由来・マスクの共通部分・動的物理・ライティング・着せ替え・アバタープロファイル) をすべて含む。これらは機能の宣言を必要としない。
- 機能の宣言とフォールバックの仕組み自体は 1.0 までに実装し、試験用の機能で動作を確かめる (T0109・T0115)。1.0 以降に追加する機能が、最初の宣言の対象になる。
- AI 連携の結果 (深度の推定など) は、ファイル形式の上ではツールが焼き込んだふつうのデータになるので、1.0 の形式の範囲に収まる。

## 結果

- ライセンスが決まったので、配布 (T0403 など) と仕様の公開を進められる。
- 新しい外部依存を追加するときは、ライセンスの検査を通す必要がある。
- 1.0 の前に M1〜M4 のすべての機能を実装することになるので、1.0 までの範囲は大きい。1.0 より前はファイル形式の互換性を保証しない (ADR 0004)。
