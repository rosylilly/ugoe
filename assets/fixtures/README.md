# テスト用アセット

コードで組み立てられないテスト入力 (PSD や画像など) だけを置きます。

- 1 ファイル 1MB 以下
- 追加したら、下の表に出所とライセンスを書く

| ファイル | 内容 | 出所 / ライセンス |
| --- | --- | --- |
| `layers.psd` | 64x48 の 8 ビット RGB の PSD。入れ子のグループ (`体` / `顔`)、非表示のレイヤー (`目`)、不透明度 50% のレイヤー (`メモ`、キャンバスの外にはみ出す負の位置、レイヤー効果のキー付き)、クリッピングされたレイヤー (`影`、塗りの不透明度 80%、乗算)、無圧縮と PackBits のチャンネル、調整レイヤー (`レベル補正`) を含む。合成画像は背景レイヤーと同じ (正しい合成ではない) | ugoe の自作 (`crates/ugoe-psd/tests/common/mod.rs` のライターで生成。`UGOE_UPDATE_FIXTURES=1 cargo test -p ugoe-psd` で作り直す) / MIT |
