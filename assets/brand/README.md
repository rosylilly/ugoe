# アプリのアイコン

エディタ・ビューア・スタジオのアイコンの元の絵 (SVG) を置きます。3 つとも同じ形 (少し傾けた白い顔。動かす 2D の人形) で、
背景の色と印でアプリを見分けます。

| ファイル | アプリ | 形 | 出所 / ライセンス |
| --- | --- | --- | --- |
| `editor.svg` | エディタ | 紫の角丸の四角に白い顔と、輪郭の上下左右の 4 つの頂点のハンドル (リギング) | ugoe の自作 (T1002 でテキストエディタで手で書いた。外部の画像・フォント・アイコン集は使っていない) / MIT |
| `viewer.svg` | ビューア | 青の角丸の四角に白い顔 | 同上 |
| `studio.svg` | スタジオ | 赤の角丸の四角に白い顔と、右上の配信中の印 (白い輪に赤い点) | 同上 |

- 図形は `viewBox="0 0 512 512"` の中の四角・楕円・2 次ベジェの線だけで、文字やフォントは使いません。色は SVG に直接書きます
  (エディタの紫は UI の強調色 `--ugoe-color-accent` (`packages/ui/src/tokens.css`) に近いもの)。
- 16・32 px でも、背景の色と白い顔 (目の 2 つの点) が見分けられるように、細い線や小さな文字を入れません。エディタのハンドルと
  スタジオの印は 32 px より大きいときの手がかりで、小さいときは色で見分けます。
- アプリの `src-tauri/icons/` のファイル (`icon.png`・`icon.ico`・`icon.icns`・大きさ違いの PNG) は、この SVG から
  `just app::icons` (Tauri の CLI の `tauri icon`) で作ります。SVG を変えたら作り直し、差分を目で確かめてからコミットします。
  出所とライセンスの表は [docs/release.md#アプリのアイコン](../../docs/release.md#アプリのアイコン)。
